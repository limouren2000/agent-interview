# 9.10北京爱学习java开发日常实习面经

> 爱学习 · Java开发 · 日常实习 · 面试时间 2026-09-10 · 发帖 2026-09-10 · 作者 失去 · 来源：[小红书](https://www.xiaohongshu.com/explore/6aa269d8000000002b013c01)

## 速览

- **重点**：为什么选 Java 17 及新特性，并发和线程池执行流程，Spring Boot 核心原理，MQ 使用场景和消费幂等，ES 里 BM25 与 KNN，以及为什么用 SQLite 而不是 MySQL，还有数据库调优。无手撕。
- **难度**：爱学习 Java 开发日常实习，约 20 分钟后转入闲聊。轮次和结果未注明。作者称最近习惯面 Agent，这场面试官主要拷打 Java。
- **题量**：16 问，无手撕。

## 面经正文

1. 先做一下自我介绍。
2. 你的项目为什么选择 Java 17？
3. Java 17 有哪些新特性？你项目里用了哪些？
4. 你项目里哪些地方用到了 Java 并发？你怎么理解并发控制？
5. 为什么要使用线程池？相比直接创建线程有什么好处？
6. 线程池的执行流程是什么？
7. Spring Boot 的核心原理是什么？
8. 为什么要使用 MQ？MQ 适合哪些场景？
9. MQ 如何解决消息重复消费问题？也就是怎么保证消费幂等？
10. ES 中 BM25 和 KNN 的原理分别是什么？
11. 用过 MySQL 吗？
12. 为什么项目选择 SQLite，而不是 MySQL？选型是怎么考虑的？
13. 两个项目都是独立开发的，你的项目开发流程和开发习惯是什么？
14. 做过数据库调优吗？一般是怎么做的？
15. 作为 Java 开发实习生，你觉得自己的优势是什么？
16. 如果入职后给你分配一个任务，需要用到你不会的技术，你会怎么办？
