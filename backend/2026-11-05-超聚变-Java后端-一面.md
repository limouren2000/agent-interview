## 面经正文

以下为内容整理，只保留问题含义和过程，不是逐字原文。题目按原顺序归类如下。

开场与项目：自我介绍；对 C/C++ 的了解；印象深的项目及其中问题与处理；Agent 项目中的职责、问题与解决，以及为何不直接用现成开源工具；市级智能视频分析如何落地、方案来源、属增量还是全新；实习期如何快速熟悉资料文档；代码是否由 AI 辅助、日常如何用 AI、怎样应对生成幻觉并保证正确。

Java：JVM 内存结构，新对象存放位置与生命周期，以及何时进入老年代；新生代为何用复制而非标记整理，并简述两种算法；synchronized 的锁升级，与 volatile 的差别，volatile 能否解决 i++，若不能应如何处理；异常体系；try 与 finally 都有 return 时返回哪一个；项目里 Lua 的用途。

网络与设计：TCP 三次握手与四次挥手、为何是三次、TIME_WAIT 过多如何排查；每秒约十万点击/搜索要实时展示前十热词如何设计、如何用 Redis 有序集合优化、还可从哪些方面提升读写；为约 100MB 本地缓存做更快的读写并淘汰最久未用如何设计、LRU 思路及双向链表实现。若 Hit@5 从 0.93 降到 0.85 如何排查。

方向与培养：若用 Agent 做 BMC 故障管理、诊断日志，Skill 会如何设计。BMC、BIOS 与工具开发三个方向各自职责、语言技术；应届是先分方向还是统一培养后再分；是否有导师、新人从何入手。
