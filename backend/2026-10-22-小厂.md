## 速览

- **重点**：接口和抽象类的区别与选用，HashMap 的 put 流程、哈希冲突和树化，受检与非受检异常，synchronized 和 ThreadLocal，JVM 堆与虚拟机栈，以及 MySQL 的 Buffer Pool、Redo / Undo / Binlog 顺序、崩溃恢复、ACID、隔离级别、幻读和 MVCC。手撕是三数之和。
- **难度**：小厂面经，岗位、轮次和结果均未注明，题目以 Java 和 MySQL 为主，按问题归入 backend/。
- **题量**：31 问，另有手撕 1 道。

## 面经正文

1. 先做一个简单的自我介绍，介绍一下实习经历和项目经历。
2. 你在浪潮实习了两个月，为什么这么快就离职了？
3. 你在浪潮实习期间主要负责哪些工作？平时开发的流程是什么样的？
4. 你觉得低代码开发和传统 Java 后端开发有什么区别？
5. Java 中接口和抽象类有什么区别？
6. 在实际开发中，什么情况下会选择接口，什么情况下会选择抽象类？为什么？
7. 能不能结合你自己的项目，举一个使用接口或者抽象类的例子？
8. HashMap 的底层数据结构是什么？一次 put 操作大致经历哪些流程？
9. HashMap 为什么会产生哈希冲突？发生哈希冲突后是怎么处理的？
10. HashMap 在什么情况下会将链表转换成红黑树？
11. Java 中受检异常和非受检异常有什么区别？
12. RuntimeException 及其子类属于受检异常还是非受检异常？
13. Java 进行文件 IO 操作时，为什么需要关闭资源？
14. 进程和线程有什么区别？
15. synchronized 修饰普通实例方法和静态方法时，分别锁住的是什么？
16. ThreadLocal 了解吗？有没有在实际项目中使用过？
17. 结合你的 铁路购票项目，说一下 ThreadLocal 具体用在什么地方，保存了哪些信息？
18. JVM 中 Java 堆和 Java 虚拟机栈有什么区别？分别存储哪些数据？
19. MySQL 和 Redis 有什么区别？在实际项目中分别承担什么作用？
20. MySQL 的 Buffer Pool 是什么？主要有什么作用？
21. MySQL 中有哪些重要的日志？介绍一下 Redo Log、Undo Log 和 Binlog。
22. 假设一个事务还没有提交，但是 Redo Log 已经刷盘，此时 MySQL 突然崩溃，重启之后会发生什么？
23. 如果 MySQL 根据 Redo Log 恢复了未提交事务修改的数据，如何保证事务的正确性？
24. Undo Log、Redo Log、Buffer Pool 和 Binlog 之间是什么关系？
25. 执行一条 UPDATE 或 INSERT 语句时，Buffer Pool、Undo Log、Redo Log 和 Binlog 的处理顺序是怎样的？
26. MySQL 事务的 ACID 四大特性分别是什么？
27. MySQL 有哪四种事务隔离级别？
28. MySQL 的可重复读隔离级别能否解决幻读问题？为什么？
29. 能不能举一个具体的例子说明什么是幻读？
30. MySQL 的 MVCC 机制了解吗？它是如何利用版本链实现数据可见性的？
31. MySQL 中有哪些锁？你了解哪些锁机制？
