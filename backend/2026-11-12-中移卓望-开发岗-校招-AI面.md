# 中移卓望开发岗AI面面试题

> 中移卓望 · 开发岗 · 校招AI面 · 发帖 2026-11-12 · 作者 turbo · 来源：[小红书](https://www.xiaohongshu.com/explore/6af51c1d000000001802a39d)

## 速览

- **重点**：Java 多态与工具注册后的特殊参数设计；JDK 垃圾回收器、CMS 碎片导致大对象分配失败的处理；MyBatis 与 Hibernate、下划线到驼峰映射；JS 深浅拷贝及循环引用；二次注入、Linux 查找并结束 Java 进程、MySQL 主从延迟和无主键表回放变慢。也问了 MCP 调用链路与超大返回的资源管控，以及 Agent 常用设计模式和报销流程该怎么搭。
- **难度**：中移卓望开发岗校招 AI 面，结果未注明。岗位是普通开发岗，题目以 Java / 数据库 / 工程为主，收入 backend/。
- **题量**：16 问。

## 面经正文

1. 请介绍 Java 的多态性，并结合你的实际开发经历，描述一个使用多态的业务场景。

2. 新增工具实现类完成注册后，调度侧逻辑无需改动。如果其中某个工具的 execute方法，需要传入其他工具都不需要的特殊参数，你会如何设计处理？

3. JDK 内置的经典垃圾回收器有哪些？简述它们的核心差异以及各自适合的业务场景。

4. CMS 基于标记-清除算法，会产生内存碎片。如果 CMS 运行期间，因为内存碎片，大对象分配失败，请描述对应的完整处理流程。

5. MyBatis 和 Hibernate 两类 ORM 框架的主要区别是什么？

6. MyBatis 需要开发者手写 SQL，框架负责参数与结果集映射。MyBatis 在结果集映射阶段，如何实现数据库下划线字段到 Java 驼峰属性的自动转换？

7. JavaScript 中深拷贝与浅拷贝的核心区别是什么？分别列举两种常用实现方案。

8. 使用 `JSON.parse(JSON.stringify())` 做深拷贝存在类型兼容局限。如果待拷贝对象包含循环引用，该方式会出现什么现象？

9. 请介绍基于 Model Context Protocol（MCP）的智能体开发。描述从客户端发起调用到 MCP Server 执行的完整链路，以及链路里的核心处理环节。

10. MCP 会对工具返回内容做裁剪、序列化后回传给大模型。当工具返回二进制大文件或者超大结构化数据时，MCP 依靠什么机制管控资源，防止上下文窗口溢出？

11. 什么是二次注入？为什么数据入库时已经做了转义处理，数据从数据库读出再次使用时，依然存在注入风险？

12. 在 Linux 环境下，如何查找指定 Java 进程的 PID，并结束该进程？`kill` 和 `kill -9` 的区别是什么？

13. MySQL 主从延迟的常见诱因有哪些？

14. 无主键表会造成从库回放变慢，请说明无主键表在从库回放 binlog 时，性能远低于有主键表的底层原因。

15. 在 AI Agent 项目开发中，你用到过哪些经典设计模式？这些模式分别解决什么问题？

16. 开发一个跨多系统、自动完成报销全流程的 Agent，你会优先选用上面哪一种设计模式搭建核心执行链路？
