# 滴滴国际化后端实习一面凉经

> 滴滴国际化 · 后端 · 实习一面 · 结果：挂 · 面试时间：国庆节前 · 发帖 2026-10-17 · 作者 raystorm · 来源：[小红书](https://www.xiaohongshu.com/explore/6ad2e83a000000000200ed96)

## 速览

- **重点**：实习项目的安全审计设计，针对密钥泄露、恶意代码和 Prompt Injection 的检测与防护，以及审查模型被注入后如何处理；乐观锁与并发控制；SSE 与轮询降级、按游标补发；Coding Agent 托管平台的功能和架构，以及为什么选择 Codex；GPT 与 Claude 在编程场景下怎么选；MCP 和 Skill 的区别。手撕是合并两个升序数组，保留重复元素，且不能直接调用排序函数。
- **难度**：滴滴国际化后端实习一面，已挂。作者称是国庆节前面的，节后 HR 捞二进宫时得知被挂。
- **题量**：14 问加 1 道手撕。

## 面经正文

1、自我介绍。
2、实习项目中的安全审计是怎么调研和设计的？主要考虑哪些安全风险？
3、针对密钥泄露、恶意代码和 Prompt Injection，分别怎么检测和防护？
4、如果负责安全审查的 LLM 本身遭遇提示词注入怎么办？禁用工具调用后如何完成审查？
5、什么是乐观锁？与悲观锁有什么区别？为什么选择乐观锁？
6、乐观锁具体是怎么实现的？多人协作还有哪些并发控制方案？
7、项目中为什么使用 SSE？主要解决什么问题？
8、SSE 断线后如何根据游标补发遗漏事件？由谁触发补发？
9、SSE 不可用时为什么降级为轮询？如果服务端或网关出现故障，轮询还有用吗？
10、内部协作系统同时设计 SSE 和轮询兜底，是否存在过度设计？
11、Coding Agent 托管平台主要实现了哪些功能？为什么选择 Codex？
12、Agent 托管平台整体架构是怎样的？任务如何分发和执行？
13、平时主要使用哪些大模型？GPT 和 Claude 在编程场景下各有什么优缺点，如何选择？
14、MCP 和 Skill 有什么区别？
15、手撕算法：给定两个升序数组，合并为一个升序数组，要求保留重复元素，不能直接调用排序函数。
