## 速览

- **重点**：一面是 Java / SpringBoot、类与对象、继承多态、接口、建表 SQL、OSI 与协议分层、数据库三大范式，并问了 Agent 组成、记忆和 MCP。二面是 HR 综合问题，包括实习表现、协作、薪资、家庭情况和体检相关询问。
- **难度**：格力电器应用软件设计秋招一面、二面，均约 10 分钟，已 OC。标签同时有秋招和格力电器校招，按同作者其他 27 届秋招帖记为秋招。一面题目以 Java / 网络 / 数据库为主，收入 backend/。
- **题量**：一面约 14 问加反问，二面约 17 问加反问。

## 面经正文

投递时间线：9.22 投递，10.11 收到性格测评，10.12 早上完成测评，晚上七点半收到面试通知，10.13 一面（线上）

总共就10 min，会议刚开始就明确说了10 min 左右，问了其他 uu 也是10 min（估计是海面）

一面面经（10min）：
1、自我介绍
2、实习期间使用的技术栈 / 框架？（Java、SpringBoot）
3、简单描述一下 SpringBoot 的基本概念
4、类和对象的关系是什么？
5、描述一下继承和多态
6、接口和类之间有什么差别？
7、数据库创建表的 sql 语句如何写？
8、OSI 七层模型？
9、TCP、UDP、IP、HTTP 分别在哪一层？
10、数据库原理学过吗？（这里根本没搞懂想问什么，我就说了解数据库的三大范式）
11、把三个范式说一下
12、智能体（Agent）的组成部分？
13、它的记忆如何实现？
14、介绍一下 MCP
反问环节：
1、哪些部门？部门业务？
2、后续流程（本轮通过的话还有 hr 面）

一面总结：
问的问题都太简单了，面试官没开摄像头，不过非常友好，回答过程中一直嗯嗯嗯的回应

二编：一面结束当晚19:45收到次日线下二面通知，去广州的酒店线下面

二面面经（10min）：
1、一分钟的自我介绍
2、上一段实习遇到的难题是如何解决的？
3、如何点评自己在实习中的表现？
4、跟领导、同事协作如何？有遇到分歧点或者印象比较深刻的事情吗？
5、会有需求反复修改或者沟通最后妥协的情况吗？
6、为什么上段实习不继续下去？上段实习有转正 offer 吗？上家公司开出的薪资是多少？期望薪资是多少？
7、有没有压力比较大的情况或者遇到比较棘手的情况？
8、有没有出现过不在公司还追着你去解决异常的情况？
9、上家公司的工作氛围是能接受的对吗？
10、你觉得自己比较向往的企业应该具备哪些条件会让你很愿意加入？
11、有没有在网上了解过格力的工作内容强度薪资这些？
12、你觉得自己跟岗位比较匹配的所掌握的软件、开发工具、语言是哪些？
13、身高体重？哪里人？父母工作情况？是否独生子？是否单身？父母对定居城市有什么要求吗？
14、还有收到其他 offer 吗？推进比较快的除了格力还有其他企业吗？
15、兴趣爱好、娱乐消遣活动？
16、有无挂科？有无奖学金？英语四六级情况？
17、是否有重大疾病、是否有违法经历、是否有大面积纹身烧伤等？
18、反问环节

二面总结：
hr 小姐姐很友善，问的问题没有一直往下追问，结果在一周内会通知
