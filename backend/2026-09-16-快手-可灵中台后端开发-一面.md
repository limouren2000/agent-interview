## 面经正文

1. 你的购票系统技术栈是 Java 吧？有没有了解过 Java 并发编程相关的内容，比如多线程、JVM 内存模型或者线程池？具体用到哪些？
2. 现在这个项目中，你的多线程具体是怎么写的？是用了 ThreadPool 吗？
3. 我看到你用了 Redis，先简单讲讲你的理解，为什么它适合用来做缓存？
4. 你们的数据结构是怎么设计的？哪些数据放到了 Redis 里？用了什么 Redis 数据结构？Redis 快的底层原因有哪些？
5. 你提到 Hash，知道 Redis 的 Hash 底层具体是用什么实现的吗？
6. 哈希冲突有没有详细研究过？
7. 说一下你的数据库和缓存一致性，具体是怎么做的？
8. 你们采用了 Binlog 加 RocketMQ 的方案吗？
9. 顺序是先更新数据库，再删除缓存，对吧？
10. Redis 一般会设置过期时间，你们有没有设计过期删除策略？具体是怎么删除的？业务逻辑是什么？
11. Redis 的过期删除策略你大致描述一下？
12. MySQL 的 InnoDB 存储引擎了解吗？
13. InnoDB 和 MyISAM 有什么区别？
14. InnoDB 的事务机制了解吗？
15. MVCC 具体机制能说一下吗？
16. MVCC 是如何做到读写不互相阻塞的？
17. MVCC 和事务隔离级别有关系吗？
18. Undo Log 在 MVCC 中起什么作用？
19. 哪些情况下读写会冲突？
20. 这道合并区间题你先讲讲思路。
