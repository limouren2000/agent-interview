## 速览

- **重点**：笔试是递归判断回文串、连续重复次数最多的字符，以及非递归二叉树后序遍历。面试先问 GET/POST、Spring 注解收参、Bean 生命周期、事务和乐观锁悲观锁。接着是 Function Calling、SSE 和 WebSocket 怎么选，以及 MCP 的 Host、Client、Server。RAG 部分问切分、重叠、Rerank、多轮查询改写，以及 Embedding、Rerank 和对话模型的区别。后半是 Kafka 消费后 ES 写入成功但 Offset 提交失败会怎样，确定性文档 ID 如何保证幂等，还有 KNN 和 BM25 怎么融合、RRF，以及权限过滤为什么必须放在召回阶段。岗位是 Java 后端开发，按岗位归入 backend/。
- **难度**：数字华兴 Java 后端开发。类型、轮次、结果和面试时间均未注明。作者评论称应届生，不据此标注招聘类型。发帖日按笔记 ID 为 8 月 19 日，页面编辑于 9 月 16 日，评论有 8 月 18 日，日期有出入。
- **题量**：笔试 3 道，面试按 Java 基础、Agent 与流式通信、RAG、Kafka 与 ES、混合检索与权限分块提问。
