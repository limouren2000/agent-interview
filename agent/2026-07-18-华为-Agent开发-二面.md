# 华为某BG Agent岗位一、二面面经不丝滑offer

> 华为 · Agent开发 · 二面 · 发帖 2026-07-18 01:12 · 作者 哥特式重金属私生子 · 来源：[牛客](https://www.nowcoder.com/feed/main/detail/63f974c8a2214503bdc0ad7505cdc15b)

## 速览

- **重点**：工具调用 / MCP / Skill、手撕算法、Agent 规划、实习深挖、项目深挖。
- **难度**：中高，偏项目深挖和工程落地。
- **题量**：13 道左右。

## 面经正文

lz某92目标大二
经牛友建议改了下简历，最后被录取也是来回馈社区了。
lz的实习面试经历可谓是最长最波折的之一了。幸亏接头人比较热心，泡出来了。

4月上旬投递

有个很水的竞赛免笔试
综测两次险过

6月中旬
技术面50分钟

1. 介绍自己学过哪些专业课？
2. 科班专业题，很简单
2.1 TCP三次握手怎么进行，为什么不能两次握手
2.2 c语言中临时变量的存储区域是什么？

3. 开始拷打项目
3.1 回顾各种比赛，问了一个CTF比赛的简单问题
3.2 重点拷打我写的Agent项目。我说这是一个基于ReAct范式，加上一个魔改的RAG的项目。问我是不是全程参与实际代码实施。我说我在代码实施阶段主要是写外围服务，没有直接参与agent，但是对它的架构比较熟悉。

4. 手撕代码
求拓扑序的题。图论算法非常基本的题，但是lz因为没有背数据结构八股，所以只能根据自己的印象现场搓。面试官吐槽我的算法有点低效了，我诚实说因为没背到图论的八股（

### 反问：没准备+临场想不出来就没问。

最后惊险过了。

主管面
过了两周才二面？？？
七月初

说是主管面，但其实和一面差不多都是技术偏多。可能考虑到我大二业务经验不足，甚至没有“软素质”八股。

1教育背景介绍
2问我学了哪些专业课程，我说数字逻辑电路，COA，OS，编译原理，数据结构等等
3. C语言编译的过程（C语言八股）
4. 编译单元到目标文件的具体过程（编译原理八股）
5. 拷打项目（Computer Use Agent）
5.1 你这个项目的背景和结构？（帮助人们完成重复任务。ReAct加一个魔改的RAG）
5.2 技术拷打（感觉比技术面还要更技术，什么鬼！）
6 解释RAG, SKILL, MCP。（差不多说对了）

### 反问

我们有 mentor吗？我能向mentor寻求什么帮助了？（mentor是正式员工，会带你跟着他做。）
实习生有哪些职责？（根据分流有所不同，不会和正式员工有本质的不同。）
我还要提升些什么？（多学习一下业界知名的agent框架，比如说泄露的claude code就不错）

七月中旬offer~

最后，已严肃成为🌸孝子
