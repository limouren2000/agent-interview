# 华为线下面入池

> 华为 · Agent技术 · 校招一面二面主管面 · 结果：通过入池 · 发帖 2026-09-23 · 作者 山田リョウ · 来源：[小红书](https://www.xiaohongshu.com/explore/6ab3ac86000000000a026e1c)

## 速览

- **重点**：一面深挖深信服实习，问 RAG 和 Skill，手撕 LC 56，没写完仍过了。二面深挖 agentic RL 项目，包括奖励构造、工具和 Agent 环境、困难、GRPO，手撕 LC 2244。主管面问实习沟通与跨部门分歧。
- **难度**：华为 Agent 技术校招一面、二面、主管面，通过入池。标签同时有秋招和华为校招，按华为校招记为校招。作者称非科班、没准备 LC，三轮体验很好。
- **题量**：两轮有手撕（LC 56、LC 2244），另有项目追问和主管综合问题。

## 面经正文

投的agent技术，一波三折但结果是好的，非科班出身之前没学过算法，所以完全没准备lc手撕，只准备了llm手撕，打算碰运气
一轮技术面
面试官挺年轻的，感觉像是做开发出身，一直追问我在深信服的那段实习经历，问了很多RAG，SKILL相关的内容，这部分答的还可以，面试官反馈也不错，手撕是lc56，对于没学过算法的主包只能说两眼一抹黑，直接摊牌不好，但面试官人很好和主包讲了思路，理解了一下发现思路不难，但最终时间到了还是没写出来，这时主包已经打算回去了，但过几分钟收到了面试通过的消息，只能说非常lucky了
二轮技术面
是个中年左右的面试官，应该是做技术方向的，对我做的一个agentic rl项目问了很多，奖励是怎么构造的，怎么准备工具和agent环境，碰到了哪些困难，grpo组内优势等等这些，聊的也不错基本上都答的来，接下来又是手撕，但是题目上手后看了一轮发现思路很简单？没记错的话应该是leecode2244，按照思路写了下虽然有一些小问题但整体是对的，于是被告知通过二轮。
主管面
面试的主管很年轻，依然问的主包实习的经历，有没有遇到过沟通困难的情况，不同部门在面对同一个项目上有分歧的时候是怎么解决的这些，这块只能说如实道来，聊了半小时左右
总结一下，三轮面试体验非常好，面试官完全不压力，体验很不错（酒店也不错，茶歇随便吃，而且还有麦当劳）
