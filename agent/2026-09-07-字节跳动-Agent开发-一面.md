## 面经正文

### 一、自我介绍 & 背景部分

1. 简单介绍下你的个人背景、教育经历、实习经历，以及为什么求职 AI Agent 开发岗位？

### 项目背景

2. 讲一讲这个量化 AI Agent 项目整体是什么样的，要解决什么问题？
3. 原有系统存在哪些风险？Agent 会出现哪些异常问题？

### 权限体系设计

4. Agent 的 TOKEN 是什么，怎么获取，起到什么作用？
5. TOKEN 和权限是怎么关联的？数据库层面如何设计？
6. 你们定义的 RWBNCT 这 6 类权限 scope 分别代表什么，实际落地了哪几个？
7. 如果要对下单权限做更细粒度管控（限制交易标的、单笔金额），该如何实现？

### SSE 推流相关

8. SSE 在项目里用来做什么？推送的数据格式是什么样？
9. SSE 如何处理断连？心跳保活怎么做？
10. 客户端断网重连之后，怎么实现断点续传，不用任务从头跑？

### 幂等 / 防重复下单

11. Agent 超时重复下单是高风险问题，你们怎么实现幂等避免重复操作？
12. 幂等 key 是怎么生成的？为什么不让大模型自己生成 key？

### 限流 & Redis

13. 系统限流规则是什么？分别对哪些维度做限流？
14. 限流是如何基于 Redis Lua 脚本实现的？讲讲实现思路。
15. Redis 做缓存有什么优势？
16. 如果 Redis 宕机、缓存失效会带来什么影响？
17. 如果大量 key 同时过期，缓存击穿数据库，该怎么处理？

### 异步任务、消息队列、存储

18. 为什么长耗时的回测、下单不使用同步 HTTP，要改成异步 + SSE？同步方案遇到了什么问题？
19. 项目中 MySQL 数据库都存储哪些数据？

### 三、计算机基础 & Python 底层

20. Python 字典底层是什么结构？插入、查询原理是什么？
21. Python 字典哈希冲突如何处理？
22. Python 字典删除操作底层逻辑是怎样的？

### 四、手写编程题

23. 实现 LRU Cache，要求 O (1) 的 put、get，需要自己实现双向链表结构，讲思路尝试写代码。
24. 给定数组，求出现频率最高的 Top‑K 元素，讲实现思路，时间复杂度是多少？有没有优化方案？
