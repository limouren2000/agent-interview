1. 两到三分钟自我介绍。

2. 下游本身就有各自的业务模块/子 Agent，为什么还要在外层再建一层 Agent？你们和下游怎么划分，什么场景下必须靠外层调度才能解决（会反复让举跨模块的实际例子）。

3. 除了调度下游执行，外层 Agent 还承担哪些功能？怎么感知和路由不同的下游模块。

4. 多步任务编排是怎么设计的，模型输出的是什么结构。

5. 候选工具数量多了以后会有什么问题。

6. 如果多个工具功能本身有重复，动态筛选能解决重复问题吗，为什么不在工具注册阶段直接合并过滤。

7. 工具裁剪前后做过 token 消耗的量级评估吗？在多轮长上下文或 System Prompt 较长的情况下，少几个工具实际占比有多大。

8. 怎么评估编排和工具优化前后的效果，中间产物有没有评测，具体看哪些指标。
