# 天津某初创agent开发

> 天津某初创 · Agent开发 · 技术总监面 · 结果：已口头offer · 发帖 2026-11-11 · 作者 aevon · 来源：[小红书](https://www.xiaohongshu.com/explore/6af3c587000000001f0161a5)

## 速览

- **重点**：对 RSI（递归自我进化）和团队 Agent 的理解；开源 PR、预跑（dry run）、安全沙箱，以及假数据却连了真数据是否构成权限或跨边界泄露。投研工作台问了循环层数、依赖图（DAG）、断点、多跳查询、校验和置信度。私有部署是场景题，纠正了“私有部署等于断网”“脱敏等于解决投资意图泄露”，并追问长桥接口不能用、能不能改爬网站。
- **难度**：天津某初创 Agent 开发技术总监面，约 1 小时 20 分钟。招聘类型未注明。作者评论称已口头 offer，并称被拷打。
- **题量**：约 40 问（含反问）。

## 面经正文

技术总监面 感觉被拷打了
一小时20分钟左右

1. 你现在的状况和打算是什么？
2. 你对 RSI（递归自我进化）有什么了解？
3. 个人网站相关问题？
4. 你说的“团队 Agent”指的是哪层意思？
5. 在这件事上你有什么体感和经验？
6. 你怎么看这个开源工作的实际价值？
7. 你能举一个需要它的真实场景吗？
8. 那个 PR 的问题能从头讲一遍吗？
9. 预跑（dry run）到底运行在哪？
10. 这个项目是不是没有安全沙箱？
11. 本该用假数据，为什么直接连了真数据？
12. （反复追问）那问题到底是什么？
13. 这是不是权限问题、是不是数据跨边界泄露？

投研工作台
14. 能整体介绍一下这个工作台吗？
15. 它的循环是一层还是两层？
16. 做这个的出发点从哪来？
17. 关系是从图里抓，还是让模型直接推理？
18. 依赖图（DAG）是怎么建的？
19. 什么情况下会断点？
20. 数据不是都从同一个接口取回来的？
21. 是不是各自独立用不同方式搜索？
22. 怎样才算查询正确？
23. 多跳问题（如数据出错影响哪些股票）怎么处理？
24. 细说一下，什么叫校验？
25. 什么叫日期合理？
26. 置信度是怎么算出来的？

私有部署大考（场景）
27. 完全私有部署，你会怎么做？
28. 你会先判断什么？
29. 你判断的依据是什么？
30. 你会把这问题直接丢给工作台自己研究吗？
31. 这件事到底难在哪？
32. （纠正）私有部署不等于断网，你怎么理解？
33. （纠正）脱敏不等于解决投资意图泄露，你怎么看？
34. 要满足他，得改哪些东西？
35. 外部调用除了模型，还有什么？
36. 工具和接口依赖具体有哪些？
37. 老板说长桥接口不能用，你怎么办？
38. 老板让你直接爬网站，可行吗？
39. 除此之外，你还会做什么？

反问收尾
40.你有什么想问我的？
