## 面经正文

1. 做下自我介绍
2. 第一个项目(多智能体），看名字是不是参考过 OpenClaw？
3. 该项目是否使用过 RAG 技术，具体怎么用的
4. 这套智能体是否上线运行、部署在哪里？
5. 介绍一下对话摘要压缩中间件，如何解决上下文膨胀
6. 第二个项目（RAG），RAG 是否完整设计，落地运行
7. 完整介绍下这套 RAG 系统的全流程（从文档处理开始讲）
8. 追问，项目里使用的 Embedding 模型是什么？
9. 追问，项目里使用的 rerank 模型是哪一个？
10. 项目的大模型选用的是哪家的？
11. 第一个项目主模型使用的是哪家的？
12. 本地轻量千问模型主要是用来做什么？
13. 追问，本地显卡显存是多少G？
14. 有没有印象深刻的提示词迭代调试经验，详细说明？
15. 是否用过 dify,coze 这类低代码平台
16. 日常的 vibe coding 主要使用什么？使用的MAC还是windows
17. Claude code对接的是原生模型API还是什么？对接的哪家模型？
18. 个人籍贯信息询问
