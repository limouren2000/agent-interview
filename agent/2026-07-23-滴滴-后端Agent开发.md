### 面试问题

1. 自我介绍
2. 介绍一下你最近做的 Agent 项目
3. Agent 项目是实习项目还是个人项目？你在里面具体负责哪些部分？
4. 项目里最难的点是什么？最后怎么解决的？
5. Agent 在学术上通常由哪些模块组成？
6. 了解过哪些 Agent 设计范式？
7. 讲一下 Agent 里的长短期记忆分别是什么
8. 如果要做记忆压缩，通常有哪些方法？
9. Agent 如何减少幻觉？如果放到工业场景里，你会怎么做？
10. 多 Agent 或多异步任务场景下，怎么防止上下文污染？
11. 项目里用的是 Spring 还是 Socket？为什么这么选？
12. Spring AOP 代理在什么情况下会失效？
13. Spring 循环依赖有没有遇到过？怎么定位和解决？
14. Spring MVC 的执行流程是什么？
15. Maven 传递依赖可能会带来什么问题？怎么处理？
16. Redis 支持哪些数据结构？
17. Redis 为什么快？
18. Redis 为什么采用单线程模型？
19. Redis 单线程模型下，如果遇到阻塞会有什么影响？
20. Redis 的 `ZSet` 底层结构是什么？适合什么场景？
21. Redis 哨兵模式是怎么工作的？
22. Redis 大 Key 会带来哪些问题？会不会影响内存和性能？
23. Channel 和传统锁，比如 `Mutex`，在并发控制上有什么区别？分别适合什么场景？
24. 当 `P` 的本地队列为空或不为空时，Go 调度器是怎么调度 `G` 的？
25. MQ 一般用在什么场景？
26. 数据库事务的特性是什么？
27. `MVCC` 是怎么实现的？
28. 数据库索引的底层结构是什么？什么时候会失效？
29. 如何实现一个类似淘宝搜索框的实时商品名称模糊搜索？
30. 实时输入联想和输入完成后点击搜索，在技术实现上有什么本质区别？
31. 实时搜索一般会用什么网络协议？比如 `WebSocket`，你了解或用过吗？
32. 详细讲一下微信扫码登录的完整流程，以及背后发生了什么。
33. 微服务架构里，服务发现和负载均衡是怎么实现的？
34. 服务注册中心，比如 `Nacos`、`Consul`，是怎么工作的？
35. 服务实例如何注册和保活？心跳机制怎么设计？
36. 垃圾回收机制是什么？
37. 讲一下 `CMS` 垃圾回收器
38. 手撕代码：反转链表
