# 9.2合肥电商公司ai应用开发日常实习面经

> 合肥电商公司 · AI应用开发 · 日常实习 · 结果：oc · 面试时间 2026-09-02 · 发帖 2026-09-03 · 作者 失去 · 来源：[小红书](https://www.xiaohongshu.com/explore/6a996176000000002b010b45)

## 速览

- **重点**：RRF 融合排序的原理，以及是一开始就用还是改过来的；Coding Agent 里 ReAct 和 Plan-and-Execute 的区别与取舍；还问了对后端技术栈和模型微调的了解。
- **难度**：合肥电商公司 AI 应用开发日常实习。一位业务主管和两位技术人员一起面，约 20 多分钟，面完约 20 分钟后 HR 通知 OC，薪资约一个月 4500。
- **题量**：7 问（含追问）。

## 面经正文

1. 你了解我们公司的业务方向吗？
2. 你项目里用了 RRF 融合排序，简单讲一下 RRF 的算法原理。
3. 你一开始就用了 RRF 吗？
* 还是先用了别的融合方式？
* 后来发现效果不好才改成 RRF？
4. Coding Agent 项目里，ReAct 和 Plan-and-Execute 有什么区别？
5. ReAct 和 Plan-and-Execute 这两种模式，你是怎么做选择和取舍的？
6. 你对后端技术栈有哪些了解？
7. 你对模型底层有没有了解？包括模型微调这一类方向。

面了大概20多分钟，一个业务主管，两个技术人员，第一次见三个人一起面，有点意思，自我介绍完分别简单提问了问题，面完大概20分钟，hr通知oc，给了大概一个月4500左右吧
