# 9.21 携程Agent开发二面

> 携程 · Agent开发 · 二面 · 面试时间 2026-09-21 · 发帖 2026-09-21 · 作者 Real · 来源：[小红书](https://www.xiaohongshu.com/explore/6ab1133b000000003101f453)

## 速览

- **重点**：Agent 开发与传统后端的区别、会议室预订系统设计与实现、时间区间边界、复杂度优化。
- **难度**：中等，面试官基本只问了这道场景代码题，分类讨论即可。
- **题量**：自我介绍后以会议室预订代码题为主，并追问自动分配、边界冲突、时间复杂度和 O(1) 优化。

## 面经正文

1.请简单介绍一下自己。
2.Agent 开发与传统服务端或后端开发有什么区别？你觉得为什么需要单独设立 Agent 开发岗位？
3.代码题：请设计并实现会议室预订系统：实现bookRoom()和allocateRoom()这两个方法。
bookRoom( )用来预定会议室，传入参数roomId, startTime和endTime，同时满足以下条件时才能预订成功：
- roomId 对应的会议室存在。
- startTime < endTime。
- 该会议室在 [startTime, endTime) 内没有其他会议。
- 成功后，将本次会议加入该房间的预订记录。
allocateRoom( )用来分配会议室，传入参数capacity, startTime和endTime，候选会议室必须满足：
- 会议室容量大于或等于 capacity。
- 在 [startTime, endTime) 内没有时间冲突。
- 时间区间合法。
- capacity > 0。
如果有多个房间可用，则按照以下规则选择：
- 优先选择容量最小但足够容纳所有人的房间。
- 如果多个房间容量相同，选择 roomId 字典序更小的房间。
4.在不指定房间、只提供时间段和参会人数时，如何自动分配合适的会议室？
5.两场会议分别为 9 点到 10 点和 10 点到 11 点，它们能否使用同一间会议室？根据会议区间的边界定义，代码中的时间冲突判断需要如何修改？
6.bookRoom 和 allocateRoom 两个方法的时间复杂度分别是多少？
7.roomIds.contains(roomId) 的时间复杂度是多少？
8.如何把房间 ID 是否存在的查询从 O(N) 优化到 O(1)？
9.你对部门里目前负责的 Agent 业务有什么想了解的？
面试官相当于基本只问了这个代码题，作为场景题而言比较容易，考虑到各种不同情况分类讨论即可。
