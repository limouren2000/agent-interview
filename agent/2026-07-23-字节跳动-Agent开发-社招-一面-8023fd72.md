- **重点**：手撕算法、项目深挖。

## 面经正文

社招，发出来攒人品
前 40 分钟主要在围绕做过的项目展开，后 20 分钟media手撕
1. workflow 中的原子性在项目中怎么体现的
2. workflow 是如何搭建的，开源的还是自己搭的系统
3. workflow 中的每一个节点是如何控制的。(回答 eval 相关的
4. eval 的评判标准和结果是怎么影响后续的
5. workflow 和 agent 的 loop 各自如何设计，我们业务中的 workflow 如何往 loop 上设计
6.依旧在聊我们业务上升视频的 workflow 是如何优化设计的
7.长任务如何保证稳定性，微服务如何设计的
8，后台 pod 或者 instance 死掉了，如何保证之前还在 workflow 中的 task 继续的
9. 后续在聊 workflow 和 agent 的区别
10. agent 有设计的必要吗，在我们的业务场景下真的比 workflow 好嘛
11.聊业务
12.如何看待 agent 的自进化？
题目是大数加法，秒了。做完后问了下大数减法怎么做
总结:后续反问的时候问了下业务，确实字节这边的业务和我本身做的非常相似，所以面试官也很熟悉问的也很细，都是我在工作中遇到的问题。
