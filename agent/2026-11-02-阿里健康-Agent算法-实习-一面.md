# 10.30阿里健康Agent算法工程师实习一面

> 阿里健康 · Agent算法 · 实习一面 · 面试时间 10 月 30 日 · 发帖 2026-11-02 16:35 · 作者 玛卡巴卡_du · 来源：[牛客](https://www.nowcoder.com/feed/main/detail/4543b76d09404ce7aa4530f448fb7715)

## 速览

- **重点**：多 Agent、RAG、手撕算法、Agent 规划、实习深挖。
- **难度**：中等。
- **题量**：25 道左右。

## 面经正文

面试官挺专业的，问的很细，手撕有点逆天，核心很简单。友友们这种面一半拉我手撕然后继续问，是不是不想要我😭😭😭
1. 请先做一个自我介绍。
2. 你目前还在快手实习吗？（追问：简历上没写滴滴，你是几月份去滴滴实习的？）
3. 先了解一下你在快手这边的实习工作，你在快手主要负责什么？（追问：是给用户推荐岗位吗？第一部分是用户打标对吧？）
4. 可以举个具体例子吗？你们给用户打的是什么样的标签？
5. 负向标签（如“不要上夜班”）在业务中是怎么提取的？提取出来之后在下游推荐业务中是怎么使用的？
6. 你们的召回都是靠标签去召回的吗？
7. 从用户的多轮对话中去提取标签，每个用户的标签数量会特别多吗？是如何处理的？
8. 这些标签主要是用来做召回的，那标签有权重吗？你觉得对于召回或推荐来说，标签需要区分权重吗（比如用户说“想做保姆，不想上夜班”，“保姆”是强限制，“不上夜班”是弱限制，这种情况怎么区分）？
9. 你刚才说的通过训练学习特征贡献度/权重，是指打标模型的训练还是后续推荐排序的训练？toC 这边的推荐排序是怎么做的？
10. 简历里写的“意向初筛和多目标精排”是指哪一块的业务？
11. 你这里面用到的 DCN-V2 是个什么网络？它是什么样的结构？具体是怎么实现特征交叉的（是通过点积实现的吗）？
12. 这个排序模型是你来选型的吗？关于特征交叉的模型，除了 DCN-V2 你还调研过哪些（如 FM、DeepFM、DIN）？
13. 请介绍一下你在滴滴这边的实习工作（业务场景、多模态 VLM 端到端微调与 Decision Model 级联打标）。
14. 在滴滴的 L1~L4 四层标签体系中，基于 Decision Model（OpenJT）的分层预测 + Beam Search 具体是怎么做的？为什么选择 `32-32` 的束搜索宽度？
15. 你说的这个 Decision Model 不是生成式模型对吧？你是基于开源版本去微调的还是自己训练的？它微调时的监督任务和损失函数是怎么设计的？
16. 这种判别式/决策式模型（Decision Model），你有没有和普通的生成式基座大模型直接生成打标对比过？各自的优缺点是什么？你们线上对准确率的要求是多少？每个商品只打一个正交标签还是多标签？
17. **【算法题】搜索日志 Top-K 热门 Query 统计**：给定搜索日志列表 `records`（包含 `(user_id, query)`），要求：
* （1）对 `query` 进行归一化（忽略英文大小写、去除首尾空格、将连续空白合并为一个空格）；
* （2）同一个用户多次搜索同一归一化 `query` 只计一次（按独立用户 UV 统计）；
* （3）返回独立用户数最多的前 $K$ 个 `query`（若用户数相同按归一化后的字典序排序），并考虑边界条件（如去重后总 `query` 数不足 $K$ 个等）。
18. 你简历里的这几篇论文哪篇是已录用的？哪篇是和 Agent 相关的？请简单介绍一下第一篇论文要解决的核心问题是什么。
19. 你说的解决多 Agent 之间的“能力盲区”和“交互冗余”具体是什么意思？不同模型擅长什么以及如何协同，这不应该是 Agent 的工程框架（Harness / Workflow Prompt）层面去考虑的事情吗？为什么要内化到模型参数里？
20. 内化到模型参数之后，两个模型具体是怎么协作的？一个任务来了之后不是还要告诉规划 Agent 做什么吗，这里面到底节省了什么？能举个具体的代码任务拆解例子说明吗？
21. 在训练规划模型（Leader）和执行模型（Follower）时，是同时联合优化还是交替优化？怎么个交替法？实验是怎么设计的？
22. 你在滴滴实习了不到两个月，为什么要换实习？如果发 offer 多久能到岗？有什么问题想问我？
