# 9.17 字节剪映AI Agent开发二面

> 字节跳动剪映 · AI Agent开发 · 二面 · 结果：通过 · 面试时间 2026-09-17 · 发帖 2026-09-19 · 作者 Real · 来源：[小红书](https://www.xiaohongshu.com/explore/6aae55b70000000029010a94)

## 速览

- **重点**：Think / Plan / Action / Observation 状态、停止条件与评测、抑制循环调用、多 Agent 协同、Java GC、SSE、二叉树的直径。
- **难度**：中等，面试官比较温柔，时长较短，结束不久通过。组里服务端、客户端、Agent 都要做。
- **题量**：14 问，另有二叉树的直径算法题。

## 面经正文

1.请先做一下自我介绍。
2.项目1你的 Agent 是什么架构？具体是怎么设计的？
3.Think、Plan、Action、Observation 四个阶段分别保存什么状态？怎么影响下一轮？
4.Agent 怎么决定继续检索，还是已经可以停止并给出答案？
5.这套 Agent 的评测条件怎么设计？
6.多轮检索时，怎么避免重复查询、循环调用和上下文无限增长？
7.除了设置最大循环次数，还有没有其他办法抑制循环调用？
8.负向 Prompt 和“不要重复调用工具”这样的简单声明有什么区别？怎么验证它是否有效？
9.如果把系统放到业务中，面对简单、中等、困难问题，怎么设计整体流程以控制延迟？
10.多 Agent 协同应该怎么设计？怎么决定哪些功能放在主 Agent、哪些放在 Sub Agent，以及是否需要 Sub Agent？
11.你使用什么编程语言？
12.能介绍一下 Java 的 GC 机制吗？
13.既然有 GC，为什么还会出现内存泄漏？
14.能介绍一下 SSE 是什么吗？
15.算法：二叉树的直径，直接秒。
面试官还是比较温柔的，反问了下组里具体的业务，应该是服务端、客户端、agent都要做，属于全栈组。面试时长也比较短，结束不久就收到消息通过了。
