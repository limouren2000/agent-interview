# 百度Agent算法岗一二面面经

> 百度 · Agent算法 · 秋招一二面 · 发帖 2026-08-14 20:18 · 作者 算法打工人阿旺 · 来源：[牛客](https://www.nowcoder.com/feed/main/detail/fc3d5bfe42cd4adcbbd06c5994bbf0ce)

## 速览

- **重点**：多 Agent、RAG、记忆与上下文、工具调用 / MCP / Skill、Agent 规划。
- **难度**：中高，偏项目深挖和工程落地。
- **题量**：15 道左右。

## 面经正文

### 一面

1. Agent的核心组成模块有哪些？主流Agent框架有哪些？
2. 简述ReAct、Plan-and-Execute机制的区别与适用场景，补充其他常见规划算法。
3. 工程场景：Agent拥有海量工具、技能时，如何解决Token爆炸、工具乱选、检索慢、调用不准等问题？
4. 什么是Agentic RL？为什么Agent需要引入强化学习优化？
5. Agent如何做全方位评测？除最终结果外还有哪些评估维度？
6. 单Agent与多Agent的核心差异、适用场景。
7. Agent上下文溢出如何解决？常见上下文管理方案。
8. 翻转整数

### 二面

1. 是否阅读过OpenClaw、Claude Code源码？核心收获是什么？
2. 对比两者记忆机制、上下文管理机制的实现差异。
3.. 工具数量过多为何会导致错选？对应的优化方案。
4. 简述自定义Skill的结构，你开发过哪些Skill能力？
5. 请设计Agent完成「预订明日上海机票」的完整执行链路。
6. Agent任务停滞、重复调用同一工具、无法推进任务，如何处理异常？
7. 单词拆分
