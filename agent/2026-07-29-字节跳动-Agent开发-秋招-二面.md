# 字节 Agent 开发 二面（依旧被拷打但OC版）

> 字节跳动 · Agent 开发 · 秋招二面 · OC · 发帖 2026-07-29 18:18 · 作者 offerF助 · 来源：[牛客](https://www.nowcoder.com/feed/main/detail/e088c6af95a34bdc81edaacc26651595)

## 速览

- **重点**：Agent 架构与 Skills、Prompt 与上下文工程、评测与 Badcase 定位，再加一块工程基础和一道 TUI 场景设计。
- **难度**：中高，二面明显偏项目深挖和线上问题，不只是背八股。
- **题量**：20 道。

## 面经正文

### 架构与Agent设计

1. 你之前的Agent项目用的什么架构？LangGraph还是自研？是Master+Sub Agent还是Workflow？为啥这么选型？
2. 是单Agent还是多Agent？各个子Agent的核心任务和分工是怎么划分的？
3. 首次生成和多轮补充的链路路由，你是怎么区分和实现的？
4. Agent的Skills功能原理是啥？你是怎么设计和实现整个Skills体系的？

### Prompt与上下文工程

5. 提示词模板怎么构建的？上下文工程有啥实践经验？比如做过To Do List优化吗？为啥它能让模型更聚焦？
6. 做过查询改写吗？多维度查询改写具体是啥？当改写需要用户补充信息时，交互和技术怎么实现？
7. 什么是并行化意图识别？为什么要做？怎么实现的？

### 评测与Badcase定位

8. Agent整体效果怎么评估？没有用户反馈时，怎么做有效抽检？
9. 出现Badcase时，怎么快速定位是哪个环节出了问题？怎么判断该对哪个Agent做SFT优化？
10. Prompt调优遇到“修好一类、坏了另一类”怎么解？
11. Prompt调到极限后，优先换模型、调参数还是上SFT？为啥？

### 工程与底层基础

12. LLM推理优化做了啥？用过Continuous Batching、KV Cache、vLLM吗？线上高峰吞吐量多少？
13. 代码单测的分支覆盖率怎么统计？代码插桩的原理是啥？
14. 单元测试的Mock怎么实现？遇到AST和LSP都搞不定的代码怎么处理？
15. Python有真正的多线程吗？为什么有GIL？Lock和RLock有啥区别？
16. 简单讲讲Self-Attention原理，为啥要分Q、K、V三个向量？同一个Token在不同位置的向量一样吗？

### 场景设计题

17. 让你开发一个带TUI界面的交互式视频剪辑工具（MVP版），你怎么设计分层架构？核心功能怎么实现？

### 团队与个人规划

18. 团队规模和分工是怎样的？你负责的边界在哪？
19. 作为项目负责人，怎么定里程碑、推跨角色协作、处理阻塞问题？
20. 为什么离开当前公司？下一份工作最看重什么？
