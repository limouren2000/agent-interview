## 面经正文

你们这个agent提效平台具体是做什么的？举复杂一点的需求例子看下agent怎么实现自闭换的
你们用的模型是什么？是内部部署的吗？
这个平台每周处理多少需求？成功率多少， 是指一次性能跑通到上线，还是指人工介入后才完成？
Agent 执行一次需求大概多久？验证环节是谁来验证、怎么验证？
你们后续规划是什么？并发控制打算怎么解决？
如果我想同时用 Agent 处理 很多个文件，怎么设计？
sub-agent可以一口气开多少个？
如果把 Agent 状态放沙盒里、用户状态放外面，架构上怎么设计？优缺点？
DSH了解多少？
持久化存储会话状态有什么思路
云端 Agent ，沙盒是常驻还是用完销毁？性能上怎么优化（起沙盒速度、上下文通信）？
金融 Agent 做定时任务（如股价触达提醒）时，上下文要不要带入历史？怎么分类处理？
如果全量开放 Agent，成本和推理侧怎么扛？有没有用 DeepSeek之类的低成本模型探索？
