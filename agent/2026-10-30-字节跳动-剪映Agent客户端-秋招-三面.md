# 10.28字节剪映Agent客户端三面

> 字节跳动（剪映） · Agent客户端 · 秋招三面 · 结果：等待结果 · 面试时间 2026-10-28 · 发帖 2026-10-30 · 作者 Real · 来源：[小红书](https://www.xiaohongshu.com/explore/6ae458c0000000001b01d068)

## 速览

- **重点**：实习去留和前几轮复盘，ReAct / Agent 工作流与工具失败、扩容，用 AI 编程工具串起 Agent Loop，模型资源接入和评测标准，大数加法。
- **难度**：八股不多，面试官偏业务里会遇到的问题；手撕一开始出了点小问题后来搞定；已反问校招生期待和新人参与度，等待结果。
- **题量**：21 问 + 大数加法手撕，另有一段面试感受。

## 面经正文

1.请简单做一下自我介绍。
2.当时没有继续留在实习团队的原因是什么？
3.回顾前面几轮面试，你觉得哪些部分回答得比较好，哪些部分还有不足？
4.你提到代码题的边界条件考虑不足，具体是什么问题？
5.实习开发过程中遇到过什么问题？你是如何解决的？
6.如果现在重新做这项工作，你的方法会有什么变化？
7.你近期一般使用什么 AI 编程工具？
8.你是否使用过其他 AI 编程工具，例如trae？
9.你如何理解 Agent？
10.ReAct 的执行流程是什么？你理解的完整 Agent 工作流程是怎样的？
11.如果需要新增一个工具，你会做哪些工作？
12.如果工具执行失败，你会如何处理？
13.当工具数量越来越多时，你会如何优化？
14.请使用 AI 编程工具，实现一个包含 Agent Loop 和工具调用的简单功能，语言不限，重点是将流程串联起来。
15.你平时主要使用什么开发语言？
16.你会使用 C++ 吗？对 TypeScript 的掌握情况如何？
17.你是否自己申请过模型资源？
18.如果需要在项目中接入模型资源，你会怎么做？
19.你如何评价一个 Agent 做得好不好？
20.如果最终结果正确，但执行过程中误改了本地环境配置，这个任务算成功吗？
21.如果一个任务反复失败，你会如何定位问题？
22.算法：大数加法。
总体面试感觉还是挺好的，没有什么八股，面试官更多在结合业务中会出现的问题进行提问。手撕一开始出了点小问题，不过后来搞定了。反问了面试官对校招生的期待和新人对于Agent相关工作的参与度，我自己觉得是ok的。现在安心等待结果。
