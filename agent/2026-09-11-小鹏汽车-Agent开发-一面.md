## 速览

- **重点**：记忆与上下文、工具调用 / MCP / Skill、实习深挖、项目深挖。

## 面经正文

🗓：9.10 感觉面试官比较注重对底层模型的了解啊
1.做一下自我介绍。
2.实习主要做 Agent 哪一部分？
3.Agent 是怎么调用你开发的工具的，你的工具实现了什么功能？
4.工具是 MCP 吗？用什么实现的？
5.模型怎么知道该调用 A 工具还是 B 工具？
6.同一个问题，多次运行会不会出现工具调用先后顺序不一样？
7.为什么不用固定代码 workflow，而是用 prompt 描述流程？
8.上下文、prompt 方面你做了哪些设计，你的贡献是什么？
9.项目中遇到过哪些棘手、很难解决的问题？
10.你做过多模态大模型微调，什么场景下需要做模型微调？微调可以解决什么问题？
11.你的职业方向是什么？倾向做什么工作内容？
12.你认为AI 应用开发工作，对模型 / 算法要求高吗，是否需要算法背景？
13.Transformer 注意力机制是怎么实现的？
14.你能不能做模型底层的定制开发？
15.你的研究生方向怎么和 AI 结合的？
16.场景：预测车辆行驶过程中未来一段时间 4G/5G 网络是弱网还是强网，你的实现思路？
17.这个弱网预测适合用什么模型？千问？LSTM？Transformer？
18.简述机器学习、LSTM、大语言模型之间的关系。
19.LSTM 核心设计原理是什么？
20.编程方面掌握哪些语言：Java、Kotlin、C++、Python？
