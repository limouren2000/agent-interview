## 面经正文

周三下午参加了字节二面，非常压力之面

上来先是追问了京东的实习，每一条几乎都是问到回答不了为止，感觉面试官好像已经完全看破。特别是针对异步链路，问了非常多消息队列或者说就是Kafka的问题，从可靠传输到持久化方式，到底层具体的实现方式

1. 操作系统中的核心概念是什么？你怎么理解的？
2. 你提到了页表，能详细讲讲吗？
3. 用户态和内核态指的是什么？

看到你的简历上的agent项目，先来问几个问题：

4. 你认为 Tool 应该如何设计？哪些能力适合抽象成 Tool？
5. 模型调用 Tool 的完整链路是什么？
6. 长任务如何取消、暂停和故障恢复？
7. 你是否做过 Memory 的设计？设计上有什么经验或者心得吗？
8. 页面为什么选择 SSE 而不是 WebSocket？
9. 你觉得为什么要做查询改写？你项目当中是如何做的？
10. 在你的这个场景下，message是如何设计的？
11. 接触过 langgraph 吗？核心组件有哪些？
12. 你说你的项目中没有用到具体的框架，为什么这样考虑呢？你是如何做的呢？
13. Rerank 之后会返回几个chunk块？看你写到了评测，这块如何做的？

无手撕

整个过程下来出了一身冷汗，前面问实习的时候，只要回答磕绊或者没有到点子上，面试官就会打断

Agent部分平常的时候有在加强，感觉回答上还不错，不管是讲项目还是一些八股，都能回答上来

终于小小的感受了一把字节面试的强度，但是从面试中学到的也真不少，下来还得继续巩固一下
