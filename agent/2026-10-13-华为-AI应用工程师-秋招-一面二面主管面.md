# 华为ai应用开发入池 线下面经

> 华为 · AI应用工程师-AI技术应用 · 秋招一面二面主管面 · 结果：入池 · 发帖 2026-10-13 · 作者 kkdusir · 来源：[小红书](https://www.xiaohongshu.com/explore/6acdefc9000000000200edcd)

## 速览

- **重点**：研究生项目与 Agent 八股、企业 Coding Agent 的切块 / 存储 / 准确性、多 Agent 监督与测试用例、LeetCode 886 分组、删除链表倒数第 N 个节点、主管面宝洁八大问与华为文化 / 薪资 base。
- **难度**：校招线下面试，一面约 53 分钟、二面约 44 分钟、主管面约 29 分钟；面试官会引导和讲解，已入池。
- **题量**：三轮，含两道手撕（LeetCode 886、删除链表倒数第 n 个节点）。

## 面经正文

本人背景:双211（硕是目标院校）本科一段实习（偏运维，面试基本上没问）硕士纯干项目没有实习，代码LeetCode刷了4遍hot100

一面53分钟:面试官人一开始比较冷酷，先是自我介绍，然后问了研究生的项目细节，集中在场景和解决方法这两个方面。然后猛拷打agent项目，不过也是正常的agent八股涉及到工具和召回率这些，后面延伸到场景题。问企业怎么做一个编码coding agent，你的代码chunking怎么切，怎么存，怎么判断准不准。怎么判断agent的结果。我一开始不太懂，后来他引导我说出了准确率和召回率。然后我还提到了用另一个agent来判断，他又问了多agent的一些场景题，我说没做过，只能提供一点思路，他给我补充了很多。

一面手撕:一道我没见过的题，后面一查是LeetCode886:
给定一组 n 人（编号为 1, 2, ..., n）， 我们想把每个人分进任意大小的两组。每个人都可能不喜欢其他人，那么他们不应该属于同一组。给定整数 n 和数组 dislikes ，其中 dislikes[i] = [ai, bi] ，表示不允许将编号为 ai 和  bi的人归入同一组。当可以用这种方法将所有人分进两组时，返回 true；否则返回 false。
我当时想了2分钟。是能不能用环做，他说可以，然后写了下大致思路直接秒了，后来发现其实我忽略了奇偶环，不过无伤大雅，思路差不多就行。一面手撕花了5分钟。撕完跟我说去门口等下一轮。

二面:44分钟，自我介绍，问项目，后面只问了agent场景题和多线程的一个八股，问到不会的直接给你讲解，然后进入下一部分。拷打的主要内容是agent的测试用例怎么写，怎么用多agent进行监督。

二面手撕:删除链表倒数第n个节点，三分钟写完，问了优化方案，我随口说了引入prev，遍历完一遍，直接回头删第个n个节点（之前没考虑过，也不知道对不对）然后就过了。撕完让我出去吃饭休息下午主管面，还开玩笑说你不能在我这里休息哦，得出去休息。

三面主管面:29分钟。聊天聊嗨了，一直聊我的研究生加班出差经历和科研思路，他说一句我能讲十句，后面就是宝洁八大问里面的遇到的困难，怎么合作，怎么和甲方乙方沟通，怎么看待华为文化，经历的重大挫折，最后问了薪资和base。
