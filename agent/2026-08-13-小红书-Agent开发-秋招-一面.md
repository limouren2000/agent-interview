# 小红书 Agent 开发 秋招一面

## 速览

- **重点**：实习深挖占一半以上，Agent 八股和后端八股各一块，最后一道开放场景题。
- **难度**：中等，八股不偏，难在实习细节和指标被追着问。
- **题量**：原文编号到 28，其中 3-12 为实习追问未逐条列出，原文无 23、24。

## 面经正文

几个月没怎么打开牛客了，经历了很多很多事。最近在忙转正，然后慢慢准备秋招。

面试时间: 8.12

一点没准备，这个面试是经验包，吃晚饭秒约二面。

1. 自我介绍一下。
2. 介绍一下你这个___实习关注指标是什么？

3-12. 全都是实习相关问题，涉及Agent就狂追问，问了问数字指标，还有业务上下游，代码框架。

13. 说一下你这个项目Agent用在哪里。
14. OpenManus 是用的什么框架？
15. 讲一下你怎么理解Harness？
16. 多 Agent 并发有什么性能问题？
17. 你平时怎么控制 Agent 并发量？
18. 讲一下长时记忆和短时记忆的底层实现方式？
19. 讲一下 ReAct 的流程？
20. Planner、Executor、Critic 分别怎么做的。
21. Critic什么意思？为什么不用ReAct？
22. 上下文怎么做的？你是拆分的嘛？

25. 讲一下Redis的数据结构。
26. 每种的底层机理了解嘛？
27. 讲一下java的类加载机制
28. 场景题:  我们想要通过Agent实现对于广告投放的自我迭代，能够自我判别出哪种广告投放方式最优并执行，讲一下你的看法。

反问: 什么时候二面，有什么可以提高的地方。

发现我想到什么说什么，没有类似总分三段式之类的统领面试思想。

还是第一次面所谓Agent，感觉真是闹得麻麻的，这玩意到底有啥门槛。Agent八股我压根一点没看过也能答个差不多，感觉普通人也看不到什么新思想或者什么崭新方案。

说到底，基于一个概率性的外部组件去反复约束，去缝合各种后端思想，就开始造一堆新名词制造焦虑，闹得麻麻的。
