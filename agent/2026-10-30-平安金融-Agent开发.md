## 速览

- **重点**：虚拟列表、Web Speech API 与流程设计器、知识库召回与评测、工具调用结构与耗时、模型接口异常与超时。
- **难度**：中等，实习和 Agent 项目细节并重。

## 面经正文

平安金融 agent 开发面经
实习
1. 你实习做这个表单 做了什么 虚拟列表 表为什么选择虚拟列表
2. 语音输入webspeechapi怎么做的 你讲一下
3. 流程设计器怎么做的讲一下
4. 团队几个人 你们整个开发怎么分工的 组长怎么带你们的 怎么给你们分任务的

agent项目
1. 讲一下召回率重视度回报率幻觉 做知识库的
2. 你说后端提前写好 业务函数 你业务函数是怎么写的
3. 你说你搞了这个智能体，你接了多少工具啊，哪些工具调用多，你给我讲
4. 这些工具的query和response结构，每一次Agent平均调用用多少工具，平均耗时大概是多少
5. agent评测在实际落地也来说 不能只看通过率，需要端到端 前期跟着trace自己写trace配一轮用例回归跑完人看错误路径
6. 你调用模型接口异常处理怎么做？
回答：接口超时重试、限流、队列削峰、token长度截断、缓存热点问答、请求失败降级方案。
7. 回答超时怎么办
答：向量库查询耗时，LLM接口响应，检查队列积压，压测定位瓶颈
