# 27实习小红书AI Agent开发一面

> 小红书 · AI Agent开发 · 实习一面 · 发帖 2026-04-13 20:35 · 作者 越求职越焦虑 · 来源：[牛客](https://www.nowcoder.com/feed/main/detail/3bc7b48dd0f34f65876896052388c726)

## 速览

- **重点**：RAG、工具调用 / MCP / Skill、Agent 规划。
- **难度**：中等。
- **题量**：10 道左右。

## 面经正文

继续来分享下最近的面经~
1.介绍一下你设计的整个 Agent 架构。
2.为什么设计成主从架构？
3.讲一下完整的业务流程，Agent 在整个过程中做了哪些事情？
4.为什么在这里设计的是先调用 tool 去查商品，再走 RAG 检索商品信息？
5.你的 RAG 知识库的索引是怎么设计的？
6.你这个 Agent 的自主规划执行有没有轮次限制？
7.你在写 Prompt 方面有什么心得？可以举例说明。
8.如果在 Prompt 中明确提出 RAG 结果不要返回某种商品，但模型还是返回了，并且多次出现，这种情况可能是什么原因？
9.说说你对 Agent 和 Skills 的理解。
10.一般情况下你这个 Agent 的响应时间是多少？
