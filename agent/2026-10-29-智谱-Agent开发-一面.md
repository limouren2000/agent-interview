## 面经正文

智谱 Agent 开发一面 面完当天约二面

面试官全程没打断我，但每个回答后面都要再补一句"为什么这么选"，问得我有点心虚。四十分钟项目，二十分钟手撕，人挺好的。

1. 先讲一个你自己从零做的 Agent，别讲架构图，讲你第一天写了什么。
2. 这个场景为什么非得用 Agent，写死流程不行吗？
3. 你试过写死吗？差在哪？
4. 那你怎么判断一个任务该给 Agent 还是该写死？
5. 工具是你自己写的还是接的现成的？
6. 工具描述你怎么写的？一个工具写多少字？
7. 工具从 5 个涨到 30 个之后，模型选错的概率有没有变高？
8. 选错了你从哪发现的？日志里看得出来吗？
9. 有没有试过不给 tools 列表，只靠 messages 让它自己调工具？
10. 那它怎么知道有哪些工具可用？
11. MCP 用过吗？它跟 function calling 是替代关系还是两层？
12. 远程的 MCP 传输用的什么？SSE 有什么毛病？
13. RAG 这块，切块大小你怎么定的？
14. 定完之后测过吗？召回多少？
15. 召回不准的时候，你怎么判断是切分的问题还是 embedding 的问题？
16. 上下文超了怎么办？压过吗？
17. 压完效果掉多少，你用什么衡量的？
18. ❌ 你们评测集谁标的，标了多少条，口径是什么？
19. 手撕：手写一个 ReAct 循环，要有最大步数，工具抛异常要能兜住。
20. 如果模型连着三次调同一个工具、同一个参数，你的循环怎么处理？
