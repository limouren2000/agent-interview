11.6 网易 AI Agent应用开发 二面

线上面 全程一小时 没有一句寒暄 也没有自我介绍。

① 二面不聊概念了 你挑一个自己从头做到尾的系统 讲十五分钟
② 这个口语陪练 Agent 一次会话平均多少轮 一轮大概多少 token
③ 成本主要花在哪 是 ASR 还是大模型
④ 你说大模型占七成 那单轮 token 是怎么压下来的
⑤ 裁剪历史按什么规则裁 按轮次还是按语义完整度
⑥ 裁掉的那部分后面又要用到 怎么办 ❌
⑦ 系统设计题 支持一万人在线的多轮陪练 先说约束再画图
⑧ 峰值 QPS 怎么估的 依据是什么
⑨ 会话状态存哪 内存 Redis 还是数据库
⑩ 存 Redis 那会话粘不粘 换实例了怎么办
⑪ 一个用户两个设备同时进来 会话串了怎么处理
⑫ 流式输出中途断了 前端重连 后半段怎么续
⑬ 语音打断是怎么做的 自己上 VAD 还是用云厂商的
⑭ 打断之后模型正在生成的那半句 丢弃还是回填
⑮ 口语打分用通用模型还是专用模型 为什么
⑯ 同一段音频跑两次分数差多少 这个稳定性怎么保证 ❌
⑰ 新 prompt 上线灰度拿多少流量试 看哪个指标决定放量
⑱ 线上效果掉了 两小时内你怎么判断是模型 检索还是前端
⑲ 反问

手撕：给一批任务依赖关系 判断能不能调度 有环要报出具体环路径。追问 只返回 true false 不行 环怎么回溯出来 一千个任务并发调度 怎么保证同一个节点不被重复执行
