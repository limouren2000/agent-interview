AI Agent 测试开发实习面经

一、Agent 架构与开发

1. 介绍你的 Agent 项目及整体架构。
2. LangGraph 的 Node、Tool 如何设计？
3. Agent 为什么通过 Skill 调用 Tool？
4. 有哪些 Skill？为什么雅思检查不直接封装成 Tool？
5. 人工审批、权限校验如何实现？
6. LangGraph 如何实现中断与恢复？
7. 为什么将记忆分成三类？决策记忆有什么作用？
8. Agent 最终是什么产品形式？

二、Agent 评测

9. 20 条 Gold Case 如何构建？来自真实用户吗？
10. 项目未上线，如何构建评测集？
11. Agent 评测有哪些指标和检查点？
12. 如何测试人工审批、权限和数据库写入？
13. 如何为工厂 PMC 排班 Agent 设计评测集？
14. 如何评价生成的排班质量？
15. 缺货客服 Agent 如何评测？

三、RAG 与知识库

16. 做过文档解析和知识入库吗？
17. 官网 HTML 如何抓取、解析和切块？
18. Chunk Size、Overlap 设置多少？
19. 处理过 PDF、Excel 吗？
20. 尝试过哪些检索方案？
21. Metadata 如何构建和过滤？
22. 为什么选择 Metadata + Dense，而不是 Hybrid + RRF？
23. 小知识库为什么使用向量数据库？
24. RAG 如何评测？有哪些指标？
25. 了解 RAGAS 吗？
