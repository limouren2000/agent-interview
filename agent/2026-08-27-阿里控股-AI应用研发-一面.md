# 8.25/8.26 阿里控股ai应用研发一面

> 阿里控股 · AI应用研发 · 一面（笔试+面试） · 面试时间 2026-08-25/08-26 · 发帖 2026-08-27 · 作者 Real · 来源：[小红书](https://www.xiaohongshu.com/explore/6a900250000000001f01e975)

## 速览

- **重点**：笔试为 SQL、路径归一化和滑动窗口限流器；面试覆盖 Redis 热点与一致性哈希、JVM / GC、线程池、HTTP / RPC、MySQL 隔离与 MVCC、TP99 排查。
- **难度**：高，笔试和面试分两天，作者称已被拷打到裂开。
- **题量**：笔试 3 道，面试 19 题（部分知识点已合并整理）。

## 面经正文

前情提要：面试官开门见山地把这场面试拆成了笔试和面试两部分，笔试考察算法/设计能力，面试考察项目/八股。两场分别放在两天进行。

笔试part：
1.Sql题，给定两个表：学生成绩表s (student_id、subject、score)和学生班级表c(student_id、class)，给出sql语句：
(1)平均分小于90分的学生人数；
(2)列出班级及对应的班级总分。
2.给定2个字符串，判断是不是同一路径。其中/和// 代表的意思一样，.代表当前目录，..代表上级目录。比如:/home/a和/home//./b//../a，应该输出true。
3.实现一个具有滑动窗口的限流器，先写一个单机版，再写一个redis版。

面试part（一个一个问题列字数会超，让ai帮忙把可以合并的知识点总结了下）：
1.求职方向偏工程还是算法？
2.实习中最有挑战性的工作是什么？
3.Redis 缓存穿透、缓存雪崩、热点 Key 的定义、影响及解决方案。
4.热点 Key 如何拆分副本？一致性哈希原理和作用是什么？
5.JVM 内存结构、堆中对象、对象分代、新生代回收、GC Roots、方法区。
6.为什么采用分代回收？对象能否直接进入老年代？数组通常分配在哪里？
7.GC 什么时候触发？JVM 如何决定是否进行 GC？
8.Java 为什么需要多线程？为什么使用线程池？
9.线程池参数、核心线程与最大线程区别、线程数如何设置。
10.CPU 密集型与 I/O 密集型的判断；RPC、HTTP、长连接和连接复用。
11.Chrome 如何管理多个 Tab 的 TCP 连接？
12.HTTP 请求完整生命周期，包括 DNS、TCP、TLS、网关和负载均衡。
13.DNS 返回的 IP 是否为后端 IP？负载均衡与后端的关系。
14.Dubbo/gRPC 等 RPC 框架的核心组件及 Consumer、Provider 通信流程。
15.责任链模式和模板方法模式。
16.MySQL 四种事务隔离级别及其作用。
17.幻读、Read View、MVCC，以及 InnoDB 如何解决幻读。
18.线上接口 TP99 突然升高时，如何通过监控、日志、Trace、线程池、GC、数据库、Redis、RPC 和集群维度排查。
19.jstack 如何分析线程栈，jmap 有什么作用，如何在数千台机器中定位异常。

已被拷打到裂开，不多说了，菜就多练。
