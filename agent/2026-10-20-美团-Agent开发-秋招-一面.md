# 美团AI-Agent开发一面，面了70分钟，全程都在问我怎么证明它行

> 美团 · Agent开发 · 秋招一面 · 发帖 2026-10-20 21:22 · 作者 AIGC小白入门记 · 来源：[牛客](https://www.nowcoder.com/feed/main/detail/a826dc9c857e4351bde7dc1d43840072)

## 速览

- **重点**：RAG、记忆与上下文、工具调用 / MCP / Skill、Agent 规划、评测。
- **难度**：中等。
- **题量**：14 道左右。

## 面经正文

面试时间：10.15，美团 AI-Agent 开发，秋招一面。
晒晒
结果：进二面。

体感：范围广，但不刁。面试官像个验收方，你说什么他都接一句"那怎么保证"。

问题清单

1. 自我介绍，讲技术背景和 Agent 相关经历。
2. 挑一个最有代表性的项目，讲业务背景、技术方案、最终效果。
3. 除了这个，还参与过什么项目。
4. 为什么用 Markdown 做记忆管理？相比 RAG 有什么考虑？
5. 记忆更新时怎么保证语义匹配的准确性？匹配错了怎么处理？
6. 为什么用 Agent Teams 架构？相比 Workflow 编排有什么优势？
7. 如果线上要求全流程自动化、不依赖人工审核，你怎么设计机制保证稳定和可靠？
8. 一个 Agent 要调多个工具时，执行流程怎么设计？调用顺序怎么管？
9. 模型调用外部工具的底层机制是什么？模型怎么决定调哪个？
10. 一个 Agent 系统通常包含哪些核心模块，各承担什么职责？
11. 短期记忆和长期记忆怎么理解？各自有哪些实现方式？
12. MCP 是什么？它解决 Agent 开发里的什么问题？
13. 如果工具描述写得不好，模型选错工具，你从哪几层改？
14. 你的方案里，哪一部分是真正 impact 到指标的？

第 7 题我答得最久，也答得最虚。因为我的项目其实一直有人在后面看结果，只是没写在简历上。

复盘

面完我明白了一件事：Agent 岗面到最后，考的不是 Agent，是评测。

前面那些架构题，三层还是两层、Teams 还是 Workflow、ReAct 还是 Plan-Execute，都属于"选型题"，答得出来只说明你看过文章。真正拉开差距的是后面那句：你怎么知道它是对的？

不知道你有没有发现，几乎所有 Agent 面试都会回到同一个地方——准确率多少、误报率多少、回归怎么做的、badcase 怎么归因。因为 Agent 这玩意儿天生不确定，同一个输入跑两次结果都可能不一样，你不做评测，就等于在裸奔。

我原来觉得评测是脏活，是给算法同学打杂的。现在反过来看，评测才是这个岗位唯一的护城河。

理由很简单：模型是别人的，框架是开源的，prompt 是可以抄的，只有"我知道我这一版比上一版好在哪"是抄不走的。

所以现在再让我写项目，我会把评测那一段放到最前面写。三段话：怎么建集、怎么归因、回归怎么卡。

不会评测的人做 Agent，本质上是在许愿。
