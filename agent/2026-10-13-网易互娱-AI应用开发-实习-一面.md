## 速览

- **重点**：记忆与上下文、后端基础、实习深挖、项目深挖。

## 面经正文

10.12 面完网易互娱 AI 应用开发实习，已凉😭，趁着还有印象记录一下，攒攒人品。

1. Agent 项目深挖
- 现场画出 Agent 的整体架构和工作流程图。
- 面试官根据流程图继续追问。

2. Python 并发
- Python GIL 锁是什么？
- 异步并发和同步并发有什么区别？

3. 操作系统
- 进程和线程有什么区别？
- 僵尸进程是怎么产生的？

4. 计算机网络
- 介绍一下 HTTPS 协议及相关原理。

5. 推荐算法
- 微信推荐场景中的排序算法相关问题。

6. 算法基础
- 快速排序的原理与实现。

7. Agent Memory
- Agent 中的长期记忆是怎么实现的？
- Memory 的遗忘机制应该怎么处理？

8. 个人项目
- 深挖简历中的个人项目，围绕具体技术实现进行追问。

9. 反问环节

面试感受：

整体感觉比较看重工程基础和实际项目实现，不只是了解 Agent、LLM 的概念，还需要画Agent框架出来，解释清楚内部运行流程和设计思路。

Python 并发、操作系统、计算机网络、基础算法也都会涉及，Agent 方面会关注具体实现和 Memory 机制。

准备得不够深入，继续查漏补缺吧，希望能给后面面试的同学一点参考。
