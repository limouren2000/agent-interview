## 速览

- **重点**：实习对接与大文件上传、Agent / MCP / Skills / Prompt、多用户鉴权、前端 WebSocket、产品思维与评测标准。
- **难度**：中等，项目流程和工程细节并重，后半段偏产品对比与验证。
- **题量**：实习 4 道、Agent 项目 7 道、前端 4 道，另有一段产品思维追问。

## 面经正文

字节 agent 开发面经
实习
1. 你需求是怎么接的 你是怎么和 mentor 沟通的 你是怎么和前后端对接的
2. 你大文件分片上传怎么做的文件让 AI 解读怎么做的
3. 文件上传出现乱码怎么办？大模型返回错误怎么办
4. 你说实习做了流程审批平台 AI 提效，具体怎么做的，把某个节点 AI 提效吗

agent 项目
1. 你使用 codex ai coding 的流程是什么，你要说的熟练一点，这个流程是怎么来的，为什么不直接参考别人的流程
2. 对 agent，mcp，skills，prompt，你怎么理解 你说一下 你怎么用的
3. 你这个 agent 项目，你是怎么做出来的，从最开始是怎么做的，一问就知道了
4. 讲讲你的智能体项目框架
5. 你这个项目有没有做多用户登录 用户校验，鉴权
6. 你做 agent 项目用过什么工具 什么框架
7. 你的这个系统如果不用 AI，从零开始怎么做，数据库前后端怎么选型

专业技能
你说你写的前端，那我问你些前端的知识吧
1. web socket 啊，对比 HTTP 轮询有什么区别
2. websocket 断线重连怎么办
3. 手撕场景题吧：挺简单的 表格里面的数字怎么计算
4. 前端向后端发通信

其他瞎聊
除了使用 ai 开发，还要有产品思维，不光做出一个能用的东西，还要为什么要做他，做他到底能解决什么，好不好用。就比如你只是写一个 skill，
你在做这个一个东西之前，要有对比 指标，跟别的 已经有的，类似的东西，对比，哪个好，你的评价指标是什么
你的做法是融合了官方的和专业开发者的，那对比别人 已有的开发流程 skill，要好还是坏，为什么？
做了之后，做验证、测试、审查，你使用什么标准？还是就让 ai 自己做测试
