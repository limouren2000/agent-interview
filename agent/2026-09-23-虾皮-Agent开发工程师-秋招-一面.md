## 速览

- **重点**：一面约 1 小时 30 分钟。从自我介绍、非科班基础和哈希表切入，再问为什么选型 LangGraph、LLM、Agent、MCP、RAG、Tool 之间的联系，以及 RAG 倒排索引、电商场景、记忆与上下文、BM25、Redis 和多 Agent 编排；手撕最长公共子序列和归并排序。岗位是 Agent 开发工程师，按岗位归入 agent/。
- **难度**：虾皮 Agent 开发工程师秋招一面。标题写明秋招，按原文标注。结果未另行写明：面试官当场评价 Agent 基础可以、「过了关的」，文末又写「可惜可惜」，不据此推断最终结果。面试具体日期未注明。发帖日按笔记 ID 为 9 月 23 日 19:05（Asia/Shanghai），页面显示 09-23。封面图只是标题卡，评论区无作者补充。作者称面试官人很好，手撕写不出来时还发了资料并安慰。
- **题量**：15 项（含反问和建议），其中手撕 2 道。

## 面经正文

面试官人特别好，说话很温柔有礼貌，感觉如沐春风。时长 1h30min， 下面说说大概的问题，没有录音，纯回忆
1、自我介绍开始吟唱
2、问了下本科学没学计算机相关专业课（非科班）
3、哈希表的实现原理
4、选择一个有技术亮点的项目聊聊
5、问了一下为什么选型LangGraph，不用轻量级的自研方案？
6、llm、agent、MCP、rag、tool之间的联系
7、rag中的倒排索引怎么实现？
8、一些场景题，偏向电商类的
9、具体问了项目中的记忆系统怎么做的，上下文管理怎么管理
10、bm25 的具体实现原理
11、Redis相关的问题问了一点
12、多agent编排的必要性，为什么不用单agent➕skills做大部分问题
13、手撕：最长公共子序列、归并排序
14、反问
15、给建议：多夯实计算机基础知识（数据库、操作系统、计算机网络等）
中间其他的小问题忘记了，总体来说还是体感很好，基本上就是纯聊天，没有网传的说对于项目的拷打，可能是面试官个人风格。最后评价就是agent相关基础知识掌握不错，过了关的，但是计算机基础比较薄弱。
遇到这种面试官真的很喜欢，一直在聊天找话题，手撕写不出来还直接发个csdn给我，可惜我太菜了，然后换了一个还是撕不出来，算法题我真的不会然后还安慰我说没关系的，agent岗位对算法不是很看重。
后续问我是不是在成都呢，手里有没有别的offer，纯聊天聊了一会儿，最菜的时候遇到了最好的面试官。
可惜可惜～
