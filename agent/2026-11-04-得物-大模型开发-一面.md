# 得物大模型开发一面 挂了 11.1 下午

> 得物 · 大模型开发 · 一面 · 结果：挂 · 面试时间 2026-11-01 · 发帖 2026-11-04 · 作者 周也在coding · 来源：[小红书](https://www.xiaohongshu.com/explore/6ae958d20000000016006443)

## 速览

- **重点**：Redis 缓存问题、RAG 切分与混合检索、工具调用失败与幂等、售后话术与转人工、上下文 token、LRU 手撕。
- **难度**：中高，视频面没开摄像头，顺着售后客服项目往下追，当天下午挂。
- **题量**：17 道，另有 LRU 手撕及两道追问。

## 面经正文

下午三点面的 视频那头没开摄像头 全程顺着售后客服那个项目往下追

1. Redis 穿透 击穿 雪崩 分开说 别混一块
2. 先说下你那个 RAG 项目 文档怎么切的
3. 为什么切 512 换 256 或者 1024 会怎样
4. 向量检索召回率低 你按什么顺序排查
5. 加了 BM25 做混合检索 融合权重你怎么定
6. 上了 rerank 之后怎么证明它真的有用 看什么指标 ❌
7. 工具调用失败 或者模型吐了非法 JSON 怎么兜底
8. 重试几次 每次间隔多久 谁来决定停
9. 调用超时了 但下游其实已经执行成功 怎么办
10. 幂等键在哪一层生成 谁来传 用户连着点两次会不会建两笔售后单
11. 售后客服 Agent 哪些话绝对不能说
12. 用户重复追问同一个问题超过两次 你怎么处理
13. 命中投诉关键词直接转人工 那这轮模型还要不要回话
14. 置信度低的时候 是转人工还是先跟用户确认一遍问题
15. 用户连着问十轮 上下文窗口怎么管 token 预算怎么分
16. 系统提示词和工具定义 哪个更占地方
17. 模型返回一堆堆栈 你怎么防止它把报错当成订单内容编出来 ❌
18. 手撕 LRU 不能用 container/list 自己写双向链表节点和指针
19. 追问 get 命中之后为什么要挪到头部
20. 追问 容量满删尾节点 哈希表那边怎么同步
