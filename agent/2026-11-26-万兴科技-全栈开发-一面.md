## 面经正文

以下只整理搜集报告中已经看到的题意，不是逐字原文，也不补答案。本帖只见一面这一场，不拆文件。已读材料没有写出单独的面试日期，也没有写明结果和招聘类型。

1. 前端 Vue 和 React 都用过，讲讲两者的差别。
2. Vue 3 是怎么追踪数据变化的，为什么依赖响应式代理。
3. React 函数组件里 useEffect 怎么表达生命周期，依赖数组漏写会怎样。
4. 一条请求链路经过好几个服务，总超时怎么控制。
5. 为什么把总阈值定在 3 秒。
6. deadline 怎么从接口入口一路传下去。
7. WebClient 的超时怎么覆盖整次调用。
8. 超时之后返回什么，降级怎么做。
9. 你怎么理解 Agent 的架构，大模型和 Harness 各负责什么。
10. Harness 工程怎么兜住大模型出错。
11. 为什么把耗时任务抽象成 MCP 工具，创建/查询/取消/取结果怎么分工。
12. 限流为什么按 Token 量级而不是 QPS。
13. RAG 的完整链路讲一下，Embedding 和 Token 分别干什么。
14. 8000 Token 的总预算怎么分配，系统提示词和工具定义要占多少。
15. 怎么保证模型稳定输出结构化 JSON。
16. 原文超长怎么处理，模型超时怎么处理。
17. 流式输出为什么选 SSE 不用 WebSocket。
18. SSE 断线重连怎么保证已生成的内容不丢。
19. 用户点「停止生成」，后端怎么真正停下来。
20. 智能客服那种要交互、要取消的场景为什么必须 WebSocket。
