# 腾讯agent开发一面面试题

> 腾讯 · Agent开发 · 一面 · 发帖 2026-11-07 12:41 · 作者 吾乃韩跑跑 · 来源：[牛客](https://www.nowcoder.com/feed/main/detail/3df8a071701941d484e5a01a1b358655)

## 速览

- **重点**：记忆与上下文、工具调用 / MCP / Skill、评测、项目深挖。
- **难度**：中等。
- **题量**：10 道左右。

## 面经正文

感觉腾讯还是比较重视项目的实践过程，需要对项目有比较真实的研究和发散。
题目如下：

1、介绍项目架构。为什么组合使用 LangChain 和 LangGraph？技术选型依据是什么？
2、系统如何判断生成方案不合格？审核指标如何确定，审核结果怎样反馈到执行链路？
3、项目建设了哪些可观测能力？能否通过运行记录还原任务执行过程？
4、主 Agent 调用子 Agent 时，传递哪些上下文？内容过长如何处理，压缩机制采用自研还是框架能力？
5、实际做过哪些 Token 优化？提高 KV Cache 命中效率，还能采用哪些方法呢？
6、Skill 被折叠或移出上下文后，对缓存复用有什么影响？是否比较过保留与移除正文的实际成本？
7、模型通过工具调用执行动作，Skill 的调用机制如何实现？一个 Skill 对应单个工具还是多个工具？
8、项目使用了哪些模型？针对方案审核，是否建立了独立评测？
9、一次请求输入更短，但缓存失效导致费用反而增加，如何定位并验证原因？
10、审核 Agent 与生成 Agent 使用同一个模型，如何识别二者可能存在的共同盲点？
