# 淘天日常实习生-用户运营技术-AI应用开发工程师一面凉经

## 速览

- **重点**：RAG、记忆与上下文、工具调用 / MCP / Skill、手撕算法、Agent 规划。
- **难度**：中等偏上。
- **题量**：37 道左右。

## 面经正文

### 一、开场 & 自我介绍

1. 先做个自我介绍，并对简历上的内容做个介绍。

### 二、Agent 项目深挖

2. 这个 agent 主要实现了什么样的功能？
3. agent 主要用来做什么？它的执行链路是怎样的？
4. 说支持编写代码——你要读代码库的话，在哪读、怎么读？
5. 要改某一个项目的代码，你是怎么做的？
6. 读到代码、改完之后，代码怎么管理？
7. 写到本地之后，后续的提交（git）是怎么提交的？
8. 现在有个小需求给到 agent，它是怎么分析需求 → 做任务拆解 → 一步步实现的？
9. 举个例子：让你通过三个线程交替打印 abcabc，在 agent 里是怎么一步步实现的？
10. 需求交给模型后，模型返回的是什么？
11. 如果结合上下文、已有代码库，要新增一个实现，跟之前有什么不一样？
12. 已有接口 + 策略 A/B，现在要增加策略 C：第一步模型返回什么？第二步调什么？
13. 你用这个 agent 最多处理的问题是什么？
14. "获取知识"是联网查询还是已有知识库？
15. 本地代码库是构建成了一个知识库，还是别的？
16. 你了解 RAG 的分片逻辑吗？
17. 召回时分片不完整怎么办？
18. 还有没有其他的索引方式？
19. 除了文件分片来做 RAG 存储，还有没有其他方式？

### 三、AI 探索

20. 在 AI 方面还有其他的探索和学习吗？
21. 大概介绍一下你学到的内容（Harness）。
22. Harness 相比你 agent 里调 MCP、相比 ReAct，多了哪些能力？
23. Harness 的核心要素，相比 ReAct 多了哪些核心要素，导致它更稳定、更安全？

### 四、Java 八股

24. Java 类从字节码文件加载到内存，整个类加载过程有了解吗？
25. 类加载到内存后，各部分的分配存储（内存模型）是怎样的？
26. 对象的属性、方法分别存在哪些区域？
27. 类的卸载条件有哪些？
28. 反双亲委派模型有了解过吗？
29. 线程池有了解过吗？（核心线程、阻塞队列、最大线程、拒绝策略）
30. 最大线程数 30，第一个请求完成后第二个请求来执行——是复用第一个线程还是新建线程？
31. Java 中的锁了解吗？
32. 读写锁有了解过吗？
33. HashMap 在 Java 8 中的结构是怎么样的？
34. 红黑树的结构大概是什么样的？
35. 本地缓存了解吗？（CPU L1/L2/L3 到堆内存的性能相关逻辑）
