日常实习, 字节agent开发面经
第一次面试 问的问题挺基础的, 但是还是答得一塌糊涂.
8.05, 时长1个小时.
agent相关:

1.什么是token

2. 项目中LangGraph有什么作用?

3. LangGraph中的state保存了哪些字段?

java相关:
1.jvm中为什么要有新生代和老年代?
2. 这个springboot项目的你觉得亮点在什么地方? (我搭了并发秒杀异步削峰那一块,感觉烂大街了)
3.java中有哪些锁? 常用的是哪些(我答了synchonized, 然后那锁升级那一块答得不好, 语言组织得太烂了)
操作系统:
1.说说操作系统中的分页和分段
2. 分页和分段是怎么协作的?

计网:
http和https有什么区别?

感悟: 平常背八股的时候, 很纠结于很底层的东西, 但其实面试官问的问题不会很细, 通常是一个大方向,
但是由于平常没有对某一类问题做归纳, 习惯于一来就往底层讲解, 然后基础又不够硬, 导致讲着讲着自己卡住了,然后就很尴尬.

应该先概括性的回答, 这个东西用于解决什么问题, 大概是怎么个原理, 不要一来就深入到源码级别,
应该是引导面试官一步步深入, 而不是自己讲着讲着就乱掉了.

今后还要加强八股, 多练练怎么组织语言. 然后多面多总结 克服紧张这个问题.

手撕:  删除字符串中的重复字符, 并且要保证返回结果的字典序最小. 而且字符的相对位置不能改变

之前没有刷过, 先跟面试官讨论了思路, 后面时间不够了就没写了.
