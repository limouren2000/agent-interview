## 速览

- **重点**：项目数字口径与代价、Agent 闭环和并行工具、MCP 鉴权、评测打分与知识库、Plan-and-Execute 与 ReAct、LLM-as-Judge 与 bad case 修复、训练评测平台编排。
- **难度**：高，面试官风格细致，简历上每个数字都会追问怎么得来、口径和代价，已 OC。

## 面经正文

tl：7.14申请智能体算法岗 → 7.21笔试→ 7.31一面 → 8.5挂，转申agent harness岗 → 8.7一面→ 8.10二面→ 8.21三面→ 当晚业务负责人联系oc

面试感受是百度面试官非常专业，且面试风格非常的细致，简历上每个数字都被问到具体怎么得来的，怎么做、口径怎么算、代价是什么、剩下那 10% 为什么没解决。基本上是围绕着项目提问，通过深挖去判断项目有没有真落地，会问很多真实上线会遇到的问题，着重考察候选人是否真的具有把 agent 做成可上线系统的能力

一面 70min:
三段实习里，哪一段是你自己拍板决定的部分更多?
简历项目提问:
这个业务之前是怎么做的？你重点优化了什么?
Agent闭环的终止条件?
幻觉下降率是怎么算出来的?
门控阈值是怎么定的?
多个工具并行调度，如果其中一个特别慢或挂了，整个链路有什么影响?
延迟是怎么算出来的?
八股:
讲一下 GIL 的基本原理
MySQL 事务的隔离级别，能说一下吗?
挑一个熟悉的 agent 框架说说它替你做了什么？不用它你要自己完成什么?
手撕:
判断链表是否有环 (单向链表)

二面 80min:
实现产出里你自己真正负责哪些部分?
意图识别准确率是怎么算出来的?
注册的mcp工具大致是做什么的?
调 MCP 时有需要鉴权的场景吗?
数据集你们是怎么构造的?
结果打分不可能人工，你们怎么打分?
建知识库的时候，你的输入是什么?
每段实习都在三个月左右，为什么时间不长? 当时背景是什么?
手撕:
用最低时间复杂度和空间复杂度实现一个排序算法

三面 50min:
从你的视角，挑一个你实习过的项目，你认为想重构的部分是什么？当前的问题是什么？怎么重构?
Plan-and-Execute 和 ReAct 这两种范式本质差异是什么?
你怎么解决大量工具间互相干扰导致的路由选择问题?
怎么设计一个 To C 的 LLM-as-Judge 评分体系?
C 端线上不可能每个case都做 LLM-as-Judge，怎么办?
C 端线上有 bad case 时，你的修复再上线的流程是什么?
Agent工具输出很差，怎么定位哪个环节需要优化?
设计题:
对于一个训练 + 评测平台：训完一个 checkpoint 就评测打分，大于 60 分认为本轮有效，低于阈值就回滚到上一版本重新训练；训练和评测的周期都很长、可能跨天。让你用 agent 编排这个流程，关键设计是什么？
