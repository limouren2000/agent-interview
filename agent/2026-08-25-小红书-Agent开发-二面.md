## 面经正文

忘发了，只记得当时被问的很凶，不过面试官人好也感觉技术很强的样子。
面试时间:8.17

1. 自我介绍。
2. 你在___为什么会经历两个部门？
3. 实习有真实经历过Agent内部流程编排吗？
4—7. 问了问实习相关具体细节内容。
8. 分析师 Agent 返回的结论怎么确保正确的？
9. 结构化结论用的什么格式？
10. 介绍_____(实习agent的名字)的整体架构。
11. 介绍_____从输入到返回结果的完整流程。
12. 为什么用OpenManus这个框架？
13. 为什么不用 LangGraph 来实现这一套 Agent orchestration？
14. 多 Agent 同时执行具体争抢哪些资源？
15. 多 Agent 怎么做的上下文和状态的隔离？
16. 介绍一下你说的这个项目。
17. Workflow和你说的自治agent的区别？
18. 如果用户通过 Prompt Injection 诱导 Agent 泄露 System Prompt 或绕过既有指令怎么防范？
19. Agent 对工具调用不作限制，会产生哪些风险？
20. 怎么做去避免这些风险？
21. 为什么项目里不考虑做多Agent，或者说Mulit-Agent？
22. 假如你做了多Agent拆分，会有哪些风险？
23. 你对未来AI和写程序的趋势是怎么看待的？
24. 不打算考研吗？大概什么时候可以到岗？
25. 假设我们某些Agent将来要扩展到大量设备，同时覆盖本地 Agent 和云端 Agent，简单讲一下你的设计想法。
