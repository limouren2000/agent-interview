# 凌脉｜AI 应用开发实习面经

## 速览

- **重点**：RAG、记忆与上下文、工具调用 / MCP / Skill、后端基础、实习深挖。
- **难度**：中等。
- **题量**：37 道左右。

## 面经正文

- 面试公司：凌脉
- 面试岗位：AI 应用开发实习生
- 面试时间：2026 年 7 月 11 日
- 面试批次：实习
- 面试轮次：技术面试
- 面试形式：线上面试
- 面试时长：约 21 分钟

### 面试流程

面试从自我介绍和项目背景开始，重点深挖 RAG、MCP、模型调用、Token 计算和 Coding Agent 的工程约束。面试官更关注方案是否真正落地，以及候选人是否理解模型、工具和上下文之间的边界。

### 面试问题

### RAG 项目

1. 请做一个简单的自我介绍。
2. 文档管理与 RAG 项目主要解决什么问题？
3. 文档较长时，如何保证知识总结和回答尽可能准确？
4. 整套 RAG 链路是怎样设计的？做过哪些优化？
5. Qdrant 和 Redis 在系统中分别保存什么数据？为什么这样分工？
6. Redis 中是否可能产生 BigKey？如何通过限制文档或切片长度控制风险？
7. 系统中大约有多少文档？单个文档的大小和内容类型如何分布？

### MCP 与模型调用

1. MCP Server 是如何对外暴露服务的？
2. 使用什么框架封装 MCP Server？为什么选择 Spring AI？
3. 客户端与模型服务之间使用什么协议？
4. 项目使用过哪些模型？模型选型主要考虑哪些因素？
5. MCP Server 是否实现了鉴权？如果多人协作或对外开放，应如何控制访问权限？
6. 团队协作时，其他成员如何访问本地或远程部署的服务？

### Token 与上下文

1. 一次模型请求的 Token 用量如何计算？
2. 调用模型时是否使用官方 SDK？是否了解 Tokenizer？
3. 中文和英文的 Token 计算有什么差异？
4. 什么是 KV Cache 或前缀缓存？它为什么能够降低重复计算成本？
5. Prompt 中静态内容和动态内容应该怎样排列，才能更好地利用前缀缓存？

### Coding Agent 工程化

1. 什么是 Agent Harness？它在大模型之外负责什么？
2. 工具调用前如何校验参数，避免模型传入错误或危险参数？
3. 如何限制 Agent 的可操作工作区，防止越权访问文件？
4. 删除、覆盖等危险操作是否需要人工审批？
5. 如何识别并阻止 Agent 重复调用同一工具？
6. 如何管理上下文预算，避免历史信息无限增长？
7. 运行日志中可能包含敏感数据，应该怎样脱敏？
8. 你认为下一代 Coding Agent 的主要交互方式会是什么？
9. 使用过哪些 AI 编程工具？它们各自适合什么场景？

### 反问环节

1. 公司的核心业务是什么？
2. 团队目前在 AI 转型或 AI 应用落地方面有哪些方向？
3. 实习生进入团队后可能参与哪些类型的工作？
