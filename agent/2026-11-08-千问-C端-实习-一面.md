# 千问C端一面面经

> 千问 · C端 · 实习一面 · 发帖 2026-11-08 · 作者 代码敲不戳 · 来源：[小红书](https://www.xiaohongshu.com/explore/6af072f50000000003021fc4)

## 速览

- **重点**：产品形态和多轮对话，检索、召回与结果落地，主 Agent 和子 Agent 的分工，时延要求，数据与评测集建设，用大模型当评委的评分维度和可靠性，以及 SFT 之后的 GRPO、奖励函数和 reward hacking。
- **难度**：千问 C 端一面，按标签记为实习。代码题是股票买卖问题。
- **题量**：约 16 问，加 1 道代码题。

## 面经正文

自我介绍，讲一下相关项目和实习经历。
产品是什么形态？用户从哪里进入，输入是单轮问题还是多轮对话？
负责模块的输入、输出分别是什么？输出自然语言还是结构化结果？
上游如何检索、召回和筛选信息？下游怎样把模型结果转成用户可见的回复或操作？
主 Agent 和子 Agent 如何分工？谁负责意图识别、任务分发和工具调用？
响应速度有什么要求？输出格式、额外校验字段会不会增加耗时？
上线模型多大？训练用了多少数据和算力？
数据构建遇到过什么问题？自己设计过哪些有效策略？
如何筛选线上失败案例？筛选标准和最终评测标准是否一致？
是否参与评测集建设？规模多大，怎样算一条样本通过？
SFT效果如何评估？模型评分是主要指标还是辅助参考？
用大模型当评委，如何比较两个方案？评分维度rubrics是什么，是否根据具体对话生成？
如何验证大模型评分可靠？和人工评价的一致性怎样？
SFT 之后做了哪些 GRPO 训练？奖励函数怎么设计？
有没有出现reward hacking的现象？
强化学习数据从哪里来？和 SFT 数据是否复用？
