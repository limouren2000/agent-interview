# 10.9 小红书Agent Harness一面

> 小红书 · Agent Harness · 一面 · 结果：挂 · 面试时间 2026-10-09 · 发帖 2026-10-09 · 作者 Real · 来源：[小红书](https://www.xiaohongshu.com/explore/6ac8f8a600000000150096a8)

## 速览

- **重点**：时序知识图谱与 Slot 多跳推理、工厂模式、AI 开发工作流、Agent 会话流程与错误处理、工具调用准确性、学习方法。
- **难度**：中等，无手撕，国庆后准备不足，中间有麦克风和网络问题。
- **题量**：18 道。

## 面经正文

1.项目1主要解决什么问题？
2.在知识图谱中加入时间维度，主要解决什么问题？
3.你的方案是如何利用时间约束和 Slot 完成多跳时序推理的？
4.你的方案与基础方法或基线模型是如何对比的？
5.请介绍一个实习期间收获较大的项目，包括项目背景和核心工作。
6.你提到项目采用了工厂模式，工厂模式包括哪些类型？
7.你在 AI 使用和 AI 开发中一般使用哪些工具？
8.使用 AI 完成一个项目时，你通常采用什么工作流程？
9.除了使用 AI 辅助开发以外，你是否有用原生 AI 解决实际业务问题的项目经验？
10.你是否清楚 Agent 一次会话的完整执行流程？
11.Agent 执行过程中出现错误时应该如何处理？
12.在 Agent 设计和落地过程中，哪些节点或模块决定了 Agent 能否稳定、正确地运行？
13.如果要提升工具调用的准确性，可以从哪些方面入手？
14.在模型能力已经很强的情况下，Agent 系统还应该重点关注哪些方面？
15.你们如何解决知识检索和知识获取方面的问题？
16.拿到一个新需求或新的科研项目时，你通常如何处理？
17.面对自己不了解的知识，你通常如何学习和消化？
18.你通常使用哪些视频网站学习技术知识？
国庆玩嗨了，一点没准备，很多问题感觉答得磕磕绊绊。无手撕，面试官态度很好，但中间因为我的麦克风和网络原因耽误了一下面试节奏，不知道会不会影响面试结果。
