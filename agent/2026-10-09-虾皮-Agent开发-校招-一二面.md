## 面经正文

虾皮 Agent 开发一面、二面的问题整理，共 34 题。

一面：RAG 与评测、长期记忆、Coding Agent。
二面：需求澄清与技术设计、Agent 评测、RAG 与上下文、现场 Skill 设计。

一面

RAG 与评测
1. Agent 如何根据问题选择检索方式？向量检索找不到结果时怎么办？
2. RAG 知识库更新有哪些难点？文档局部修改时，如何考虑增量更新？
3. RAG 有没有出现过幻觉？如何处理？
4. 工具返回内容太长时怎么处理？截断或压缩会不会丢失后续需要的信息？
5. 模型网关主要承担什么作用？
6. 如何通过 Trace 定位问题？修复 bad case 后怎么验证，有没有影响其他问题？
7. 评测集怎么构建、怎么分类？评测成本如何计算？Prompt Cache 是否真的命中？
8. RRF 的全称和作用是什么？它与 Rerank 有什么区别？
9. Skill 与 Working Memory 有什么区别？两者都进入上下文，为什么还要区分？

长期记忆
10. 长期记忆如何组织？哪些信息直接注入，哪些需要按需检索？
11. 如何判断一段对话是否值得存成记忆？规则和 Prompt 分别起什么作用？
12. 关系型数据库和向量数据库在记忆系统中分别承担什么作用？保存原始对话还是提取后的记忆？
13. 用户偏好改变时如何更新记忆？如何保留历史信息并追溯原始对话？
14. 记忆抽取和召回效果怎么评测？测试数据和标注从哪里来？大量使用合成数据是否可信？

Coding Agent
15. Coding Agent 如何定位任务相关的代码？与 grep、代码向量检索有什么区别？
16. 跨语言的代码解析会遇到哪些问题？Go 的 package 和符号导出机制有什么特殊之处？
17. 工具发现怎么评测？如何衡量召回准确性和 Token 节省？

二面

Coding Agent 与需求设计
1. 从用户提出需求到编码、测试，完整流程经过哪些 Agent 和步骤？
2. 用户需求不清楚时如何澄清？怎么保证问题覆盖完整、问得准确？
3. 需求澄清后，Spec、技术设计和任务拆解有什么区别？为什么不能直接生成 Todo List 开始写代码？
4. 如果要设计一个技术设计 Agent，输入、工具和输出应该怎么设计？
5. 新系统、已有系统改造、重构和数据迁移，能否使用同一个技术设计模板？如何区分？
6. PRD Agent 和 TD Agent 的 System Prompt 应该怎么写？
7. 技术方案如何交给用户确认？用户不同意时如何修改？
8. 如何客观比较两个 PRD Agent 或 TD Agent 的质量？不看下游代码结果，怎么评价当前阶段的产物？
9. Coding Agent 的幻觉会造成什么影响？如何降低？

RAG 与上下文
10. 文档进入知识库前，如何解析、标准化和切分？
11. Agent 如何判断当前检索结果是否达标？什么时候继续检索，什么时候停止？
12. 有哪些检索策略？检索工具与检索策略有什么区别？
13. 系统上线后如何衡量质量？怎样收集真实用户反馈？
14. Agent 无限检索、反复调用工具时，如何处理？
15. Function Calling 的基本原理是什么？模型与程序分别负责什么？
16. 多轮对话超过模型上下文窗口时，有哪些处理策略？

现场设计
17. 现场编写一个会议语音转写、总结 Skill：触发条件、输入输出和执行步骤如何设计？怎样处理多人发言和口语化表达？
