# 海康威视 9.12 Agent开发 线下一面

## 速览

- **重点**：记忆与上下文、工具调用 / MCP / Skill、Agent 规划、评测、实习深挖。
- **难度**：中等。
- **题量**：25 道左右。

## 面经正文

1. 自我介绍
2. 实习项目
2.1 实习 agent 包含哪些功能，架构怎么设计的？用了哪些技术栈 or 框架？
2.2 Agentic workflow 哪些环节用到了LLM？
2.3 只是简单的 prompt + API 吗？为什么没有用上 react or plan-and-execute ？
2.4 文档处理这块是怎么做的？应该不是简单的大模型调用就能做好
2.5 手写体 or 印刷体是怎么处理的？
2.7 整个 workflow 里面用到的大模型就是这一个大模型吗？还是每个环节会有不一样？
2.8 prompt 优化是怎么做的？怎么迭代的？第一版是大模型帮你生成的吗？迭代是大模型帮你做的还是你自己人工去做的？能让大模型(自动化地)去做吗？
2.9 项目的整个过程你觉得复杂点是什么？
2.10 现在的意图识别怎么做的？
3. AI Agent 跟那个传统的那种聊天机器人本质区别是什么？
4. Agent Loop 的完整流程
5. thought - action - observation 的过程中，怎么防止死循环？(即：agent 一直没有得到它想要的结果应该怎么办)
6. 短期记忆， 长期记忆
7. Agent 的评测怎么做？是否使用过相关开源的框架？用例怎么设计？准确率 or 通过率怎么量化统计？
8. skill 和 tool 有什么区别？是否使用过业务 harness ？
9. 有没有用过 claude code 和 DeepSeek harness ？DeepSeek harness 的特点是什么？
10. 职业规划怎么样子？
11. 你觉得自己的优势是什么？
12. 反问：如果我进到了你的公司，或者说进入到你的小组之后，你觉得我现在身上所表现出的一些特性，有哪一些是你觉得做得还不够好的地方，并不能胜任工作的地方？
13. 回答：AI 时代变化很快，多看开源项目
