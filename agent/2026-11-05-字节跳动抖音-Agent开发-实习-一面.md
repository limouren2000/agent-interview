# 28届抖音Agent开发实习生一面面经

## 速览

- **重点**：开源 Agent 项目与工具调用链路、持久化与内存、MySQL 索引、Agent 评测、AI Coding 提效、三数之和。
- **难度**：中等偏高，项目问得比较多，沟通顺畅，共 1 小时 16 分钟。
- **题量**：19 道，另有三数之和手撕。

## 面经正文

整体来说项目问的比较多，但是沟通起来很顺畅，面试官声音也好听，有几个问题答的不好面试官还提醒了，总共面了1小时16分钟，力竭

附面经：
1、自我介绍、拷打实习项目
2、你的Agent项目是自己的开源项目吗？
3、这个项目是通过Vibe Coding做出来的吗？
4、在这个项目中模型负责哪些功能？除了模型的功能还有什么？
5、相比直接在ChatGPT中聊天，你的Agent多了哪些步骤和特有能力？
6、选一个你实现的工具，讲清完整调用链路
7、模型如何知道工具接收哪些参数？
8、模型返回调用请求后，程序如何处理？
9、执行结果如何返回给模型？
10、在这个项目中如何判断哪些信息需要持久化到数据库，哪些只保存在内存中？
11、数据库中主要保存哪些数据？
12、如果进行了10轮工具调用，每轮结果都很大，是否全部保存到数据库？
13、MySQL索引的原理是什么？
14、索引解决了什么问题？
15、为什么需要索引？
16、相比没有索引，查询效率提高多少？
17、是否对 Agent 的能力做过评测？
18、平常怎么用AI Coding的？
19、AI Coding生成的代码不是你想要的你怎么办？有什么提效方式吗？
20、手撕：三数之和，让先讲思路再写
