# 蚂蚁AI Lab-智能体与大模型应用实习面经

## 速览

- **重点**：多层 Agent 架构与调用关系、multi-agent 上下文共享与失败传播、开源框架二次开发、白板写 agent run 伪代码、长程任务持久化与补偿。
- **难度**：中高，对架构抠得细，爱出边界场景题，不纠结八股形式；白板伪代码作者没练过有点蒙，无手撕。
- **题量**：23 问（前 7 问未编号，其后从 8 编到 23）。

## 面经正文

📌项目架构
自我介绍，更想做工程落地还是模型训练
从架构视角讲一次服务的全流程
每一层是单个agent还是一组agent
底层执行体是独立一层，还是耦合在上层里
任务是谁下发给执行层的，调用关系具体讲清楚
执行层和顶层有没有直接交互
为什么编排层和执行层要拆开，不让编排层直接执行

📌multi-agent
8. context怎么共享
9. 资源竞争怎么处理
10. 执行失败的结果是谁返回的，怎么往上传播

📌框架与工程
11. 基于开源框架二次开发的，哪些是框架自带能力哪些是自己实现的，为什么选它
12. 核心的agentic loop是框架提供的吗
13. 项目改动点集中在哪些地方

📌白板写伪代码-蒙了，没练过

📌持久化
17. 长程任务怎么持久化，怎么保证恢复是安全且有效的
18. 场景题：动作已经在环境里生效了，checkpoint还没落盘，这时候崩了，恢复后状态对不上怎么办（考察幂等和补偿）

📌case与基础
19. 讲一个亲手解决的任务失败case，怎么修复怎么验证

21. 大模型怎么理解query并输出答案，Transformer了解多少
22. 讲讲VLM怎么工作的
23. 最近了解的前沿方案有哪些（聊到了agent检索和agent安全）
无手撕

整体感觉：面试官人很好，全程会跟你确认“我这么理解对吗”，卡住了会换角度重新问，不会让你尬在原地。
but对架构抠得特别细，层与层之间的调用关系来回确认了好多轮，讲不清楚会一直追。

爱出场景题，拿一个边界情况考。

不纠结八股形式，伪代码讲清逻辑就行，坦白不会的地方也不为难人。

另外挺看重对行业动态的敏感度，明显希望平时有追前沿的习惯，不知道是不是当时jev/dot热点出来，好几场面试都问一下前沿关注度
