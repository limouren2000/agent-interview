# 9.15 百度智能体算法一面

> 百度 · 智能体算法 · 一面 · 面试时间 2026-09-15 · 发帖 2026-09-16 · 作者 Real · 来源：[小红书](https://www.xiaohongshu.com/explore/6aaa326f000000002803554b)

## 速览

- **重点**：教师模型选型、工具 Schema、四元组与 SFT 成本、AI 辅助编码比例、Loop Engineering 与奖励函数、BGE-Reranker、百工具管理与 Skill。
- **难度**：中等，无手撕，作者称被算法组捞起来面试，是一次学习机会。
- **题量**：24 道。

## 面经正文

1.自我介绍。
2.请介绍与 Agent 和大模型相关的过往经历。
3.项目1目前主要由谁使用，主要用户是谁？
4.为什么选择 GPT-4o 作为教师模型？选择教师模型时，是否横向对比过其他模型？
5.Agent 中工具输入、输出的 Schema 是如何编写和控制的？
6.时序知识图谱中的四元组应该如何理解？
7.SFT 阶段准备了多少样本数据？数据是否全部使用 GPT-4o 生成？
8.每条训练数据大约包含多少字符或 Token？构建这些训练数据的成本大约是多少？
9.请介绍最近一段实习期间的工作。
10.实习过程中，AI 辅助编码和手写代码的比例分别是多少？
11.剩余的手写代码是否可以进一步由 AI 辅助编码覆盖？目前有什么困难？
12.与两年前的实习相比，你的编码方式和工作模式发生了哪些重大变化？
13.你是否亲自搭建过 Harness 环境？
14.请解释 Loop Engineering，并说明它适用于什么情况。
15.对于根据表单已有列推理其他评估指标的 Agent，如何搭建 Loop Engineering 环境，使推理准确率持续提高？
16.该场景下可以根据哪些指标设计奖励函数？
17.在项目3中选择 BGE-Reranker 有什么好处？是否横向对比过其他方案？
18.OCR 主要负责什么工作？
19.你是否了解 SFT 和强化学习？请介绍强化学习的技术原理。
20.当 Agent 拥有约 100 个工具时，应该如何管理这些工具？
21.如果 Agent 的任务成功率只有 60%～70%，你会从哪些方面排查原因？
22.你的职业规划是什么？
23.假设平台已有 100 个 API，如何接入千问 Agent，使用户能够通过自然语言调用平台能力？
24.Skill 提升 Agent 使用效果的具体原理是什么？
