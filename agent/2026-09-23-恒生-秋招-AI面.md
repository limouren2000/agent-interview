- **重点**：MCP 解决的痛点和交互语义，RAG、传统检索生成和模型微调怎么选，文档库每周更新该用哪种方法，以及检索结果和预训练知识冲突是什么原因。还问了 Agent 避免无限循环该设什么终止条件，熟悉的 AI 应用框架，以及 Redis 与 MySQL 商品信息每分钟更新时怎么保证一致性、缓存更新失败怎么兜底。岗位未注明，题目以 MCP、RAG 和 Agent 为主，按问题归入 agent/。

## 面经正文

牛客，应该只能用电脑？需要开摄像头，有屏幕录制

分为两个部分

第一部分：专项选择
只有一个选择题，最擅长什么语言，在python java c里面选

第二部分：专项问答
共8题，每题都有追问
- 自我介绍，谈谈岗位理解
- 过去的某个项目中最大的收获？
- 深浅拷贝的区别，在什么场景下只能用深拷贝？深拷贝如何处理循环引用，避免无限递归？
- Redis MySQL 商品信息每分钟更新，如何保证缓存和数据库的数据一致性？如果更新缓存失败，如何处理兜底？如果缓存更新失败，如何避免缓存中脏数据长期存在？
- MCP解决的痛点是什么？好处是什么？MCP如何屏蔽异构系统差异？定义了哪些交互语义？
- RAG、传统检索生成和模型微调的区别？应用场景？如果一个文档库每周都要更新，应该使用以上哪种方法？如果RAG检索到的文档和模型预训练的知识发生了冲突，是什么原因？
- agent要避免无限循环，应该设置什么终止条件？
- 最有技术挑战的大模型应用项目？难点？如何解决？
- 介绍你熟悉的AI应用框架？
- 最后两个问题有非常多的追问

共计32分钟
