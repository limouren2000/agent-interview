# 10.30 得物 MLOPS和Agent实习

> 得物 · MLOPS和Agent · 实习 · 面试时间 10 月 30 日 · 发帖 2026-10-30 15:13 · 作者 中二的西红柿起床了 · 来源：[牛客](https://www.nowcoder.com/feed/main/detail/9b098d808abd4bd3921a6c189b0daaf3)

## 速览

- **重点**：手撕算法、项目深挖。
- **难度**：中等。
- **题量**：16 道左右。

## 面经正文

全程时长：25min

1.自我介绍
2.你说在学前后端，具体包括什么？
3.前端学到哪些了？（追问：Ant Design 用过吗）
4.场景：提交数据时要记录当前操作人，后端有哪些方式拿到用户信息？（追问：埋点是基于什么拿到用户名的？）
5.讲一下 Cookie、Session、JWT 的理解
6.一个 HTTP 请求从客户端发出，到最终查到数据库里的商品信息，中间链路是什么样的？（追问：握手是谁跟谁握？具体一点）
7.做 Agent 时希望模型稳定输出 JSON，怎么做？
8.造数平台过程中最大的难点或挑战是什么？
9.valid data 是怎么样的？基于什么做的？
10.这些验证是通过自然语言 prompt 交给大模型，还是有脚本？
11.对产出数据质量的观测，你做到什么程度？
12.项目做了多久？
13.这个工作是你感兴趣做的吗？
14.有没有不是特别想接的活？有没有挣扎？
15.手撕：Python 编程题（我申请改用 C++，面试官换了一道读代码题）
换题：给一段"调用大模型 API 做代码 review"的代码，口述有哪些问题（放到生产去用会怎样）
16.反问

感想：我搜的面经不是都说得物没有手撕吗
