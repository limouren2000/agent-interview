# 小红书Agent开发实习生一面凉经，附百度Agent凉经

## 速览

- **重点**：记忆与上下文、工具调用 / MCP / Skill、手撕算法、后端基础、实习深挖。
- **难度**：中等偏上。
- **题量**：27 道左右。

## 面经正文

小红书：
1. 自我介绍
2. 实习，项目背景讲解
实习相关（可以参考）：
3. 自动切题Agent中的7步Pipeline流程是什么？
4. LangGraph设计中的3个子图Agent是怎么传递的？
5. 为什么你这边选择拆成了三个子图，而不是写成一条 Pipeline 呢？
6. 怎么搭建这个 Skills 知识进化的流程的？
7. 为什么不在Prompt中添加，而使用Skills的方式？
8. Agent 开发框架是用什么？是哪个语言？
八股：
9. （MySQL 索引的）数据结构是什么样子？有哪几种？
10. 请你介绍一下MySQL中B+树索引特点？
11. B+ 树和 B 树的区别是啥？
12. 你能举例平时用到的 MySQL 乐观锁、悲观锁的场景吗？
13. 什么情况下一般会加表锁，什么情况下会加行锁？
AI Coding：
14. AI Coding工具使用情况，使用Claude有什么习惯？
15. 总结一套AI Coding使用经验？
16. 手撕：最长递增子序列

百度：
1. 自我介绍，上一段实习相关细节询问（为什么没转正，后续秋招等）
2. 这个项目（科大讯飞实习项目）面向的业务场景是什么？是给谁用的？内部工具还是外部产品？解决的痛点是什么？
实习相关：
3. 你这个 AI Agent 的内部子图里面放了多少个节点？
4. 为什么要结合 LangGraph 和子 Agent 这种模式去做这件事？（为什么不用单一大 Agent 或纯脚本？）
5. 你这个 AI 节点的输入输出是怎么对接的？
6. 上下文（数据）是怎么传递的？
7. 用 Skill 去生成给下游的文本或文件，如果 Skill 没有达到预期（出现幻觉、路径写错等），你们怎么处理？
8. 子图Agent如果一旦跑偏了怎么办？这个节点会重跑吗？
9. 你这个人工移除出图的行为是怎么做的？
10. 在 LangGraph 的基础上，有没有做过上层的路由决策？比如由 AI 判断该走哪个节点、跳到哪个节点？
11. 有没有调研过其他 AI 框架？你觉得哪种框架可能更适合做这种长链路场景？
