## 速览

- **重点**：RAG、记忆与上下文、Agent 规划、后端基础、项目深挖。
- **难度**：中等。
- **题量**：31 道左右。

## 面经正文

面试时间: 2026.8.27

本以为秒挂，但一直泡，隔了一周终于挂了。。
非常规面经，反问做抖音电商的，猛面一个半小时，难度偏高。

1. 简单做一下自我介绍。
2. 讲一下对React的理解。
3. 描述一下最简单的 Agent Loop 是什么样子。
4. 一个 Agent 任务耗时很长、用户等不及了，怎样停止这个任务？
5. 这个取消机制你实际尝试过吗？
6. Agent 运行中不断交互的 message 大致有几类？分别是什么？
7. 用过 RAG 吗？
8. 怎样做上下文窗口和 Memory 管理？分别说短期 Memory、长期 Memory。
9. ThreadLocal 是线程安全的吗？
10. 使用 ThreadLocal 有哪些注意点？是否有内存泄漏风险？
11. ThreadLocal 在 Java 中的设计和底层数据结构是什么？
12. BeanFactory 和 ApplicationContext 有什么差异？
13. ApplicationContext、BeanFactory 的接口继承关系是什么？ApplicationContext 还继承哪些接口？
14. 项目里的分布式锁基于什么实现？
15. Redis 加锁和释放锁的原理、注意事项是什么？
16. 业务还没执行完而锁即将过期时，锁续期如何实现？
17. RocketMQ 能做延时消息吗？原理是什么？
18. 不使用 RocketMQ，怎样实现延时消息？
19. Redis 是单线程还是多线程？
20. Redis 为什么能支撑很高并发 / 高 QPS？
21. 最简单的 I/O 多路复用怎么实现？原理是什么？
22. 做过 NIO 开发吗？了解 Reactor 模式吗？
23. Spring 应用中，怎样让自建配置中心的配置优先级高于环境变量、application.yml、Spring Cloud 配置和命令行配置？
24. 配置中心通过 @Value 注入后，运行期间配置值变化，应用怎样感知并更新？
25. PropertySource 是启动时一次加载的；配置变化后怎样刷新内存中的配置？
26. 如果监听配置变更失败，配置中心与应用内存中的值不一致，怎么处理？
27. 如果配置中心宕机或连不上，怎样保证应用不挂？

28. SQL：两张表：Employee(employee_number, department_number)、Salary(employee_number, salary)。查询每个部门工资最高的员工，返回 department_number、employee_number、salary；并列最高的员工也要全部返回。
29. 三维接雨水：力扣 407. 接雨水 II。只讲一下思路。
30. JUC：实现执行器 submit(String key, Runnable task)。相同 key 的任务按提交顺序串行执行；不同 key 的任务可以并行执行；先不用处理总并发数 N 的限制。需要考虑 submit 与 worker 执行期间队列的线程安全。
31. 反问

出这三道算法有一个是给人类做的嘛？
