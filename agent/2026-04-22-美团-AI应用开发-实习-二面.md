# 美团实习 AI应用开发二面 面经干货分享

> 美团 · AI应用开发 · 实习二面 · 发帖 2026-04-22 02:40 · 作者 offer来 · 来源：[牛客](https://www.nowcoder.com/feed/main/detail/f9ee0decb50e4f7d9c1a5181449f34ce)

## 速览

- **重点**：工具调用 / MCP / Skill、后端基础、实习深挖、项目深挖。
- **难度**：中高，偏项目深挖和工程落地。
- **题量**：18 道左右。

## 面经正文

整体面试还是不错的，但是没后续了，不知道是哪里出了问题
1.实习拷打
2.项目是不是练手项目
3.做项目的时候有哪些挑战
4.分片键的选择、数据表怎么设计的
5.跳转的时候是重定向吗
6.有没有压测过，大概能达到怎样的QPS面试官中间还说了主要是关注生成速度、准确性、访问速度这些，结果最后只问了QPS
7.如果和实际已经有的一些系统类比，在实际高并发场景下，这个项目是否能支持，需要做哪些优化
8.生成ID是否也会是一个瓶颈，比如ID的容量要怎么扩充
9.什么时候需要做分库分表
10.缓存击穿做了哪些缓解措施
11.熔断降级是怎样做的?有没有可以让用户无感知的降级
12.知识库怎么构建的?
13.工具调用的具体流程
14.模型在工具调用的哪些环节发挥作用了
15.我的练手项目让大模型来写能不能完成
16.平常的科研学习受到了大模型发展的什么影响
开放性题目:
1.最近关注了什么AI发展的新技术吗?对你自己的学习有没有什么启发或者帮助?
2.科研或者做项目的时候有没有遇到什么困难，最后怎么解决的
