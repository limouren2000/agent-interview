## 面经正文

🗓9.5
1.Agent 项目功能说明，中心调度 Agent 起到什么作用？
2.Agent有没有无法完成需求的情况？有没有做系统评测？
3.通过一个实际例子，讲完整的执行流程、每一步逻辑。
4.项目底层模型选择，选型考量是什么？
5.项目有没有做模型微调 / 后训练，prompt 是怎么迭代优化的？如何验证 prompt 优化效果？

7.详细介绍整体架构、各个模块、工作流程？
8.如果遇到现有skill无法解决的问题，agent会如何处理？
9.大模型生成的内容如何与后续工具代码对接？如何约束输出规范？
10.如果 RAG 检索明明文档内存在目标内容，但召回失败，你会怎么一步步排查定位问题？
11.三个模块是分阶段开发的，每个模块你是怎么做验证、效果评估的？Bad case 怎么优化？
12.这个 Agent 是否已经落地使用？
