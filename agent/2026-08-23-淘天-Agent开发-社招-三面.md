## 面经正文

开场与自我介绍
简单介绍一下自己。
工作两年了，为什么考虑离开腾讯？
你是后端出身，后来为什么做全栈？平台前后端你都负责吗？
你们平台具体做哪些工作？
讲一下重构的背景和思路？
这个平台用什么技术栈实现的？
策略是怎么落地的？怎么把配置翻译成执行逻辑？（Lua翻译器）
预处理服务做了什么？（切片、截帧、转码）
算法模型你们不负责，那你们工程侧怎么保证高可用和稳定性？
大模型 / Agent 相关
你们在平台里用到大模型能力了吗？
你们做的 Agent 是干什么的？解决什么问题？
Agent 的架构分层是怎样的？（MCP / Skill / 知识库 / RAG）
为什么用 Agent 而不是直接做平台/API？
你现在做的 Agent 效果如何？
Skill 泛滥问题你遇到过吗？怎么解决？
上下文窗口限制对 Skill 管理有什么影响？
除了平台开发，你有没有做 AI 产品相关的工作？
你们用的是什么工具？（OpenPipe / Claude Code / CodeBuddy）
怎么沉淀部门级记忆 / 知识库？
怎么解决“经验随人走”的问题？
云端 Agent 平台怎么推进？老旧服务怎么处理？
你怎么理解“用 Agent 帮业务提效”？
你怎么看“dirty work”？（让 Agent 干脏活，人做更有价值的事）
