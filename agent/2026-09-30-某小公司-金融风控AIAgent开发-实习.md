# 小公司的agent面试记录

> 某小公司 · AI Agent开发（金融风控方向） · 实习 · 发帖 2026-09-30 · 作者 ZeroDay · 来源：[小红书](https://www.xiaohongshu.com/explore/6abcb3aa0000000018019c5c)

## 速览

- **重点**：金融风控 Agent 架构、按申请人区分 Memory、Context 过长与任务恢复、RAG / Metadata、Harness 与模型能力边界。
- **难度**：中高，项目深挖比较细，问到记忆划分、评测和底层原理。
- **题量**：16 问，另有反问。

## 面经正文

AI Agent 开发实习面经｜金融风控方向

1、自我介绍

2、你这个智能体是给什么企业/组织使用的？为什么要做这个系统？

3、介绍一下项目的主体架构和模块，可以结合一个具体例子讲整个执行流程。

4、RAG 知识库里主要存储哪些类型的信息？

5、Memory 怎么设计？
同一个机构会处理多个申请人，怎么区分不同申请人的信息？
某个申请人的任务这次没有处理完，过几天重新打开之后怎么继续处理？

6、一次连续处理多个申请人、对话越来越长时，怎么防止 Context 过长或者注意力分散？

7、有没有设计指标评估整个 Agent 的准确性、稳定性和执行效率？
比如给 10 个申请人资料，有多少能够真正完成任务？
怎么判断有没有出现死循环、一直不返回等情况？

8、RAG 的整个检索策略和处理流程是怎样的？
Chunk 怎么切？
入库后怎么构建索引？
检索策略做过哪些优化和评测？

9、Metadata 是怎么设计和生成的？
是不是切块时就给每个 Chunk 配好 Metadata？
实体类型是不是预先设定的？
检索时用于过滤的实体信息是谁生成的？
结构化信息是程序产生的还是让大模型产生的？

10、你怎么理解 Agent？一个 Agent 应该由哪些部分组成？

11、Context 应该怎么设计，才能保证多轮对话/长任务中的稳定性？
如果用户在原任务中间突然问了几个无关问题，之后又回到原任务，怎么避免这些内容干扰后续任务？

12、怎么理解短期记忆和长期记忆？分别适合什么场景？

13、结合你的项目讲一下 Memory：工作记忆、会话记忆、决策记忆分别是什么？
工作记忆是按照申请人划分，还是按照业务阶段划分？

14、你怎么理解 Agent Harness？
如果从工具调用、安全性、权限控制的角度考虑，Harness 能起什么作用？
可以结合自己的项目举例。

15、对大模型底层原理了解多少？
Transformer、编码结构、Attention / Self-Attention 这些有没有了解？

16、怎么理解大模型的能力边界？
在实际 Agent 系统中，怎么划分大模型、工具/程序和人工分别负责什么？

最后是反问环节。
