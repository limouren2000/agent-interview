# 10.12淘天AI应用研发一面

> 淘天 · AI应用研发 · 一面 · 面试时间 2026-10-12 · 发帖 2026-10-14 · 作者 Real · 来源：[小红书](https://www.xiaohongshu.com/explore/6acf187a000000001a028c66)

## 速览

- **重点**：Coding Agent 与 Codex 调用链路、KV Cache / Prompt Cache、上下文压缩、时序知识图谱与小模型选型、通用大模型翻译。
- **难度**：中高，面试官研究很深，时长不长但纠正和补充很多。
- **题量**：20 道。

## 面经正文

1.实习期间使用了什么 Coding Agent？
2.当你要求 Codex 修改一个 Bug 时，从输入需求、组装上下文，到模型推理、返回结果和客户端处理，整个流程是怎样的？
3.如果只讨论一次模型调用，客户端提交的上下文是什么结构？包含哪些关键字段？模型服务端如何处理这些内容？
4.KV Cache 或 Prompt Cache 与历史消息、上下文组装之间是什么关系？
5.使用 Codex 时，你遇到过哪些体验问题或不合理的行为？
6.除了 Codex，你还使用过哪些 Coding Agent 或其他 AI 工具？
7.使用 DeepSeek 时，你遇到过哪些问题？
8.DeepSeek 是否也会出现重复或冗余的工具调用？
9.除了重复调用工具，你还遇到过哪些问题，例如上下文压缩耗时较长？
10.上下文压缩通常是如何实现的？
11.当上下文已经达到压缩阈值时，具体会如何处理消息列表、工具结果和历史内容？
12.项目1主要解决什么问题？整体方案是什么？
13.为什么选择小模型？是否主要出于成本考虑？
14.构建时序知识图谱是否需要向量化？四元组是怎样得到的？
15.数据集中的图谱关系是否已经由他人抽取完成？
16.你认为在项目1中自己做得最好、贡献最明确的部分是什么？
17.大模型的训练数据是否包含时间信息？这些时间信息通常以什么方式表达？
18.除了科研项目，你最有成就感的项目是什么？具体有哪些收获？
19.项目3使用了什么模型？
20.为什么选择通用大模型，而不是专业翻译模型？
面试官的能力太强了，在整个面试流程中旁征博引，可以看出平时对于技术的研究非常深，大多数的时间其实我更多地是在听面试官向我输出知识，或者帮我纠正回答有误的地方。虽然时长不长，但学到不少东西，也让自己认识到之前对于agent这块的理解仍然很浅薄。
