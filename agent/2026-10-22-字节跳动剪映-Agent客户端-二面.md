# 10.21字节剪映Agent客户端二面

## 速览

- **重点**：SFT 数据构造、时间检索与知识库更新、ReAct 上下文与长期记忆、工具数量与耗时、AI 编程工具与 Token、两道手撕。
- **难度**：中高，主要深挖项目，第一道手撕较快所以又加了第二道。
- **题量**：19 问，另有无重复字符的最长子串、二叉搜索树最小差值两道手撕。

## 面经正文

1.请先做一下自我介绍。
2.请挑一个你认为最重要的模块进行介绍，实习或科研项目都可以。
3.项目1的人员构成和分工是怎样的？
4.SFT 训练数据是如何构造的？
5.训练数据中的用户问题来自哪里？
6.时间检索工具具体是如何设计的？
7.知识库中的内容过期后，应该如何更新？
8.ReAct 多轮执行时，上下文窗口不够怎么办？
9.大模型如何判断哪些信息应该写入长期记忆？使用什么格式保存？
10.记忆如何召回并提供给模型？
11.这些上下文与记忆管理方案分别有哪些优缺点？
12.项目1实际使用了记忆机制吗？
13.项目1一共提供了多少个工具？
14.整个执行过程的主要耗时在哪里？
15.Qwen2.5-7B 部署在本地还是云端？
16.为什么之前的实习时间都比较短？
17.平时使用什么 AI 编程工具？具体开发流程是怎样的？
18.一个月大概消耗多少 Token？
19.你之前提到的项目1中指标的提升是如何评测得到的？
20.手撕1：无重复字符的最长子串。
21.手撕2：求二叉搜索树中任意两个不同节点值的最小差值。
面试官主要还是在深挖项目，手撕因为第一道做得比较快所以又加了第二道。
