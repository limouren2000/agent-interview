# 9.14 字节剪映 AI Agent一面

> 字节跳动剪映 · AI Agent · 一面 · 结果：进入二面 · 面试时间 2026-09-14 · 发帖 2026-09-16 · 作者 Real · 来源：[小红书](https://www.xiaohongshu.com/explore/6aaa31d4000000002700bbb0)

## 速览

- **重点**：占位字符串替换手撕、Agent 决策路由与知识库更新、译文评价、联调排障、BM25 与向量检索并行、并发写入与断网后的 Agent 工作流。
- **难度**：中等，面试官一直在引导，已进入二面。
- **题量**：实习相关后 1 道手撕，再加 13 问。

## 面经正文

1.实习相关问题。
2.手撕：定义形如${var}的占位字符串。再给出一个字典（如{“name”:”alice”}），把给定字符串中的占位字符串部分替换为字典中对应的value，比如hello,${name}被替换为hello,${alice}。要求处理错误情况，如占位字符串中的变量在字典里不存在，占位字符串不完整等情况。同时可选做嵌套情况，即形如${name{var}}的情况。
3.请介绍项目3 中Agent 决策路由的整体框架。
4.知识库中的机构域名、术语等内容过期后，如何更新系统？
5.这个知识库过期问题在实际运行中出现过吗？
6.如果现在基于现有 Agent 基建重新实现该系统，你会如何设计？
7.若一个译文流畅但机构名称错误，另一个译文生硬但术语完全准确，如何评价这两个结果？
8.如果 AI 建议重构已有厂商适配架构后再接入新品牌，你如何判断是否采纳？
9.页面展示正常，但用户操作后持续加载时，如何定位问题并与服务端协作排查？
10.如何利用 AI 提升客户端—服务端联调和排障工作的效率？
11.BM25 检索耗时 300ms、向量检索耗时 500ms 时，串行和并行执行的耗时分别是多少？
12.哪些因素会导致并行执行耗时超过 500ms？
13.多个任务并发向同一共享集合写入结果时，加锁是否能解决所有并发问题？
14.用户与服务端断网后，服务端正在执行的 Agent 工作会自动停止吗？
15.如何将客户端在线状态检测与 Agent 工作流融合？
反问了面试官关于agent开发/agent应用相关的看法，面试官人很好，一直在引导，学习到了不少东西。
