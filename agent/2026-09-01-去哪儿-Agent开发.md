## 面经正文

面试日期   2026.8.30
1. 说一下 Java 中的 Exception 和 Error
追问： 为什么 OOM 不能靠改代码解决
2.Redis 缓存一致性问题解决方案
追问：延迟双删时间如何设置
3. 后端项目部署过程中出现了问题，你会怎么进行排查
追问：除了排查 Docker 日志查看后端应用代码错误以及 docker 容器连通性问题以外，你还会怎么排查
追问：排查是否是机器资源不足导致的失败，你会使用什么命令，重点查看哪些指标
4. 介绍一下你搭建的 Jenkins 流水线
追问：生产环境只跑冒烟测试如何确保线上不会出现问题呢
5. 微信一对一聊天，支持文本，图片，文件格式信息，要求聊天间隔 1s，你如何设计测试用例
6. charles 做弱网测试，如何判断请求发送到接收响应的时间是否小于 1S
7. 说一说你最近做的最有难度的一个项目，你在里面参与做了什么，困难是怎么样解决的（追问）
8. 说一说你最近有学习哪些 AI 工具或者大模型，你有使用它们怎么样帮助你在开发工作中。 （追问）
