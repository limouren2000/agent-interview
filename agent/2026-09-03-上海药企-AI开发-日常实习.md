# 9.3上海药企ai开发日常实习面经

> 上海药企 · AI开发 · 日常实习 · 面试时间 2026-09-03 · 发帖 2026-09-03 · 作者 失去 · 来源：[小红书](https://www.xiaohongshu.com/explore/6a995f1e000000002601819f)

## 速览

- **重点**：Coding Agent 基于什么平台或框架，和 Claude Code 架构的关系，Harness 设计，任务拆解和路径规划如何保证正确，以及相比 Codex 的优势、能否切换模型。RAG 是现成平台还是自研，多租户权限隔离，以及特殊 Prompt 能否绕过权限。还问有没有用过 LangChain、LangGraph。
- **难度**：上海药企 AI 开发日常实习，约 20 多分钟。轮次和结果未注明。岗位名是 AI 开发，题目主要是 Coding Agent 和 RAG，按问题归入 agent/。
- **题量**：12 问。

## 面经正文

1. 你的 Coding Agent 是基于什么平台或框架做的？
2. 这个项目和 Claude Code 的架构有没有关系？
3. 你的 Harness 是怎么设计的？
4. 怎么保证任务拆解和路径规划是正确的？
5. 这个 Coding Agent 做完后，有没有实际拿来开发项目？
6. 你的 Agent 相比直接使用 Codex 有什么优势？
7. 是否支持切换不同的大模型？
8. RAG 项目是基于现成平台做的，还是自己从零实现的？
9. 这个 RAG 系统主要面向什么用户、什么场景？
10. 多租户权限隔离是怎么做的？
11. 用户能不能通过特殊 Prompt 绕过权限？
12. 有没有用 LangChain、LangGraph 这类成熟 Agent 框架做过开发？

面了大概20多分钟，在介绍完项目之后简单的进行了追问，之后十多分钟就在简单的聊天，聊目前大学是否有开设ai课程等相关内容吧
