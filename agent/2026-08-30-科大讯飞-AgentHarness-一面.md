# 8.28 科大讯飞agent harness一面

> 科大讯飞 · Agent Harness · 一面 · 面试时间 2026-08-28 · 发帖 2026-08-30 · 作者 Real · 来源：[小红书](https://www.xiaohongshu.com/explore/6a94ee06000000000a009dd1)

## 速览

- **重点**：毕业论文与项目创新、SFT / GRPO 与奖励函数、ReAct 与 Workflow、Claude Code / Spec / Skills、Harness、Loop 与缓存命中、合肥地点。
- **难度**：中等偏项目和工程方法，面试官人好，体验不错。
- **题量**：35 道。

## 面经正文

1.你们毕业是否有论文发表要求？
2.请简单介绍一下毕业论文准备研究的方向，以及该方向的创新点和数据指标优势。
3.请用几句话概括项目1的核心创新点，以及相较其他方法取得提升的指标。
4.项目1是否进行了模型微调？采用的是纯 SFT，还是也进行了 GRPO？
5.与纯 SFT 相比，GRPO 带来了多少指标提升？
6.模型训练使用的是什么显卡？使用了多少张？
7.奖励函数是如何设计的？其中是否有你认为比较满意或具有创新性的设计？
8.训练过程中如何判断模型已经收敛？实际训练时主要根据 Loss 判断，还是根据训练轮数判断？
9.请介绍一下你做过的 Agent 相关工作。
10.你是否了解 Workflow 与 ReAct Agent 这两个概念？
11.你的项目是通过 ReAct 实现的，还是通过 Workflow 实现的？
12.项目2与项目3相比，哪个项目难度更高？
13.项目2采用的是 ReAct，还是其他 Agent 范式？
14.项目2选择技术栈是怎么考虑的？
15.在项目2中，你最满意的实现是什么？它解决了什么问题？你是如何解决的？
16.请介绍一下你在实习期间承担的工作。
17.请介绍一下实习中的核心工作，以及最有成就感或最有意思的部分。
18.你在实习期间使用的是哪个 AI 编程工具？
19.你是否使用过 Claude Code？通常如何使用？
20.你如何保证 AI 生成的内容符合实际需求？
21.你是否尝试过基于 Spec 或 SDD 驱动的编程方式？
22.你是否了解 TDD 和 SDD 的概念？
23.你是否使用过 Skills 提升编程效果？你使用过哪些效果较好的 Skills？
24.你如何保证代码具有可维护性，并确保交接给其他人后仍能继续开发和运行？
25.你参与过的较大项目大约有多少行代码？这些代码是否都是由 AI 编写的？
26.对于上万行由 AI 辅助生成的代码，除了保证测试通过外，如何保证代码后续仍然容易修改和维护？
27.你平时会浏览 GitHub 吗？最近是否看到过比较有意思的 GitHub 项目？你通常如何通过 GitHub 学习？
28.你是否了解 Harness，以及 Loop 等相关概念？
29.你是否研究或实践过 Harness 的错误恢复、上下文压缩和缓存机制？
30.你是否了解 Loop 和 Graph Engineering 等相关概念？
31.你如何理解 Loop？为什么 Agent 需要 Loop 和 Graph 等机制？
32.你是否了解大模型 Agent 的缓存命中机制？
33.为什么不同 Agent 框架的缓存命中率会有高低差异？
34.你的个人职业规划是怎样的？
35.对于合肥这一工作地点，你是如何考虑的？

反问了业务和工作节奏，面试官人还是很好的，面试体验不错。
