# 蔚来 AI Agent一面-三面 面经（凉经）

> 蔚来 · AI Agent · 一面二面三面 · 结果：凉 · 发帖 2026-10-17 · 作者 雪鳄鱼不怕冷 · 来源：[小红书](https://www.xiaohongshu.com/explore/6ad2f8af0000000018038727)

## 速览

- **重点**：一面 Java 八股、上下文压缩和用户隔离；二面 Mini Router、三级压缩、RAG / 评测、MCP 和消融；三面业务分工、规划和对 Agent 行业的理解。
- **难度**：三面约 30 分钟提前结束，第二天收到拒信。二面、三面面试官都没开摄像头。
- **题量**：三轮。正文按面试顺序记录；图片文字是编号后的扩写版，图 3 顶部序号显示不全。

## 面经正文

其实是一个月以前的面试了，最近一直拖着没整理

一面
先问了写后端的问题，感觉都是Java的八股
线程/进程的区别
MySql的锁机制是怎么运行的
链表的时间复杂度是怎么样的
Java的ArrayList是怎么运作的
Java的Override怎么工作的
Queue和Stack适合什么场景
然后问了写AI Agent相关的
大致介绍了简历上的两段实习经验和一段科研经验
上下文压缩的策略
用户隔离的实现
Temperature和K是什么

二面
二面问的更偏AI Agent一点，面试官没开摄像头，聊的感觉挺好的
先是介绍简历上的Agent项目的运行流程
简历项目里的Mini Router怎么实现的，怎么解决Router的Token消耗和延迟问题
简历项目里的三级上下文压缩是怎么实现的
RAG系统的Recall要是不行怎么提升，Reranker效果要是不好怎么提升
意图判断，如何给Agent分配合适的Tool
Agent评测怎么做的，介绍了下简历上的项目的做法，项目本身的测评很复杂，说了两三分钟
Redis/Postgres数据库的一致性是怎么处理的
LLM幻觉产生的原理和如何环节
上下文到了1M限制，该如何处理
Token消耗量怎么核算（项目细节追问）
Function Call / MCP的区别
MCP的具体设计（Server和Client）
消融测试（如何确认新的修改确实带来了效果提升）

三面
基本都是业务和宏观的一些理解，面试官没开摄像头
介绍项目业务之后，具体询问是谁分配工作，我参与了哪个部分，参与了多久，团队组织架构如何等等
问了一下未来的规划和对Agent行业的理解
因为很多问题没有准备过，所以30分钟就提前结束了，第二天就收到拒信了
