## 面经正文

1. 先来做一段自我介绍。
2. 详细聊一聊你的实习经历，以及负责过的项目。
3.RAG
① 讲一下你对 RAG 整体流程的理解。
② 如果 RAG 检索出来的内容相关性很差，你会怎么排查？
③ 实际做 RAG 项目时，遇到过什么问题，最后是怎么解决的？
4.Agent
① 你怎么理解 Agent 和 Workflow 的区别？
② 如果一个 Agent 需要调用多个 Tool，你会怎么设计？
③ 多 Agent 之间怎么进行任务分配和信息共享？
5.MySQL
① 哪些场景会导致索引失效？
② MySQL 索引底层采用什么数据结构？
③ 为什么 MySQL 索引主要使用 B + 树？

6.Redis
① Redis 常见的数据结构有哪些？
② 缓存击穿、缓存穿透、缓存雪崩分别怎么解决？
7. 在你平时学习或者做项目的时候，AI 大模型工具起到了什么样的作用？有没有借助它解决过实际问题？
8. 你平时是怎么评估一个模型效果好不好的？
9.MCP 底层使用的是什么协议？
10. 你认为 Skills 的本质到底是什么？
11. 如果从零设计一款 AI IDE，整体思路和方案是什么？
12.RocketMQ 出现消息积压时，你会怎么排查和处理？
13. 算法题：二叉树的层序遍历，请讲解思路并手写代码。
