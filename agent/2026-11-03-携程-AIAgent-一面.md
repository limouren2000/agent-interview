# 10.29 携程AI Agent 一面（旅游场景）

> 携程 · AI Agent（旅游场景） · 一面 · 面试时间 2026-10-29 · 发帖 2026-11-03 · 作者 周也在coding · 来源：[小红书](https://www.xiaohongshu.com/explore/6ae55b6500000000030153dd)

## 速览

- **重点**：旅游行程意图澄清、机票酒店景点用车编排与幂等、攻略切块与混合检索、效果归因和轨迹回放、LRU 与过期策略。
- **难度**：中等偏高，整场基本围着业务场景转，不太考大模型原理，最后手撕写崩了。
- **题量**：23 道，另有 LRU 手撕及过期、并发追问。

## 面经正文

本来以为是个常规应用开发岗 整场基本都围着业务场景转 反倒没怎么考大模型原理 体验还行 就是最后手撕那道我写崩了

1. 自我介绍 讲一下你做过的 Agent 项目
2. 用户说"帮我订下周三去成都的行程" 你的 Agent 第一步做什么
3. 这句话里缺了很多信息 你是先追问还是先自己猜
4. 用户没说预算和人数 你默认填什么
5. 这个任务要调机票 酒店 景点 用车四个接口 你怎么编排
6. 这四个接口之间有依赖关系吗 哪个必须先调
7. 机票接口超时了 整个任务要回滚吗
8. 订单已经创建了 后面一步失败了 这个订单怎么办
9. 重复执行会不会创建出两个订单 你怎么保证幂等
10. 涉及写操作的这几步 要不要让用户确认
11. 确认的粒度是每一步都确认 还是整体只确认一次
12. 你们的知识库是景点介绍和攻略文档 切块怎么切
13. 一篇攻略被切散了 怎么保证召回的完整性
14. 用户问"成都三日游怎么安排" 纯向量检索够吗
15. 你们上了混合检索 BM25 那一路的分数怎么和向量分数融合
16. TopK 设多少 这个数是拍脑袋还是有依据
17. ❌ Embedding 模型换了一版 你们怎么做回归验证
18. 效果变差了 你怎么判断是召回层的锅还是重排层的锅
19. 检索到了正确内容 模型还是答错了 这一层你怎么定位
20. Agent 上线之后你监控哪些指标
21. 用户投诉说 Agent 乱给他订东西 你怎么复现当时的执行过程
22. 你们有做轨迹回放吗 回放的时候外部接口怎么Mock
23. 反问

手撕
1. LRU 缓存 get 和 put 都要 O(1) 不能用现成的有序容器
2. 缓存的是行程查询结果 过期策略怎么加进去
3. 并发情况下你这个实现线程安全吗 锁加在哪一层
