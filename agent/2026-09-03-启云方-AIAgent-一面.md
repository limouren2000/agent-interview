## 速览

- **重点**：工具调用 / MCP / Skill、项目深挖。
- **难度**：中等偏上。
- **题量**：18 道左右。

## 面经正文

问12分钟问题，画执行流程图并讲解探讨40分钟，问的很底层

1、平常使用哪些编码工具？

2、在 VS Code 里具体接过哪些 API？

3、为什么选择 Codex / CoderX 这类 API？之前使用 DeepSeek 的情况是怎样的？

4、如果后续项目主要使用 TypeScript 技术栈，能否接受？

5、你是怎么理解 Agent 的？

6、做 Agent 开发，主要是在做哪些事情？

7、你提到“通过语言调用工具”，具体是怎么理解的？

8、以“查询天气工具”为例，用户说一句自然语言后，工具是怎么被触发的？

9、工具调用是否需要提前注册？需要定义哪些信息？

10、工具调用是依靠关键词 / 触发条件 / 意图识别来决定的吗？

11、模型决定调用工具以后，工具调用信息到底返回在哪里？

12、模型是不是返回一段普通文本，然后从文本里通过正则等方式解析出工具调用？

13、工具调用是否是结构化输出？

14、如果是结构化输出，具体体现在哪里？是不是类似约定好的 JSON 格式 / 固定字段？

15、模型返回的文本内容和工具调用信息是什么关系？是否属于两个独立的数据块？

16、“语言调用工具”中的“语言”和真正的 tool call / function call 到底是什么关系？

17、工具调用到底是模型“通过语言直接调用”，还是模型生成结构化调用请求，由外部 Agent Loop / Runtime 真正执行工具？

18、手画场景题：系统中有 Agent Loop、模型、工具、文件系统，用户发送“帮我写一个贪吃蛇小游戏”之后，下一步会发生什么？整个执行流程是怎样的？
