# 去哪儿旅行27届AI应用开发工程师（全栈）一面面经

> 去哪儿 · AI应用开发 · 秋招一面 · 发帖 2026-09-16 17:06 · 作者 Harry00 · 来源：[牛客](https://www.nowcoder.com/feed/main/detail/4f433b51ce454d40a609dc85400c85c2)

## 速览

- **重点**：RAG、手撕算法、后端基础、项目深挖。
- **难度**：中等。
- **题量**：8 道左右。

## 面经正文

9.16 面的去哪儿旅行 AI应用开发工程师（全栈），线上技术面，整体大概 46 分钟。
整体流程差不多是：
- 自我介绍 + 项目经历
- 选一个项目深入聊，主要问项目是怎么设计的、遇到过什么问题、哪些是自己的思考
- 结合去哪儿机票业务做了一个简单的系统设计题
- 中间有一段订单创建代码，让找问题
- 还有一道比较基础的手撕题，写完会追问时间复杂度
- 后面问了最近在学什么新技术，以及对新技术的理解
- 最后是反问环节
个人感受是，这个岗位虽然叫 AI应用开发工程师（全栈），但实际面试里后端工程能力挺重要的，不只是问 Agent、RAG、大模型这些，也会看业务建模、数据结构、订单库存一致性、代码基础和工程思维。
面试官整体比较耐心，会根据你的回答继续往下追，所以自己主动提到的技术最好能继续讲两三层。
反问时了解到，团队主要做机票 To C 后端，工程占比会比较大，校招生进去一般会先熟悉业务、查问题，再逐步接需求；技术栈偏 Java / Spring、Redis、分布式和 MQ。
整体体验还可以，给后面准备这个岗位的同学做个参考
