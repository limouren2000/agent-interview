## 面经正文

飞书视频面的，没找到录音键，下面全靠回忆整理，后面想起再补。

开场

先自我介绍。面试官顺口问是不是大三、学校有没有 Agent 相关课程，平时常用什么 coding 工具。氛围不算压力面，但后面追问挺密。

项目一：Agent Runtime

先让讲整体流程。接着问为什么不用现成框架，而是从底层 Runtime 自己做。然后揪着三个 Agent 之间怎么通信、输入输出怎么流转。

框架这块问得挺深：是不是基于 LangGraph、为什么选它、具体怎么搭的；LangGraph 怎么做中断恢复，差点没反应过来是在问 checkpoints；底层状态流转怎么实现、知不知道 reducer。

上下文管理也没放过：压缩策略是什么、什么时候压、阈值怎么定；如果旧信息已经被摘要掉了，后面还要用怎么办。

Task DAG 给了一个场景：ABCDE 里 BCD 依赖 A 并行跑，E 依赖 BCD，如果 D 崩了有没有恢复机制。还问了 CAS 锁在数据库里的实现原理。

比较有意思的是，面试官说他们希望 Agent 尽量自发恢复，而不是全丢给用户审批，影响体验，问有没有设计思路让 Agent 自己从失败里恢复。

Benchmark 追问

benchmark 怎么评成功率、隐藏测试是不是固定 case、最终结果怎么测；single-agent 怎么构建；Tool Call 减少但 Token 消耗增加，原因体现在哪；任务具体有哪些、有没有难度区分。还追问多步骤长任务里，用 harness 是不是会比 single-agent 更省 token。

项目二：检索链路

文档拆分用的什么拆分器；为什么用 Redis 做向量检索，ES 也能做向量检索知不知道；文档来源是哪、是不是网上找的。面试官确认：是不是原有入库方式加 AI 生成语料，重心放在检索召回链路学习上。

评测问了 Hit@1 提升之外还做过哪些指标；让解释 Hit@k、Recall@k、MRR，并说哪个最有代表性。

手撕 &amp; 反问

手撕是删除链表倒数第 N 个节点，ACM 模式。最后反问组内业务和是否涉及 AIGC。

面完 20 分钟左右收到二面通知，字节效率确实快。整体感受是，没准备过的追问会突然连到项目细节，临场反应和架构记忆都很吃。
