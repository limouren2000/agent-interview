# 腾讯日常实习agent开发一面面经

> 腾讯 · Agent开发 · 日常实习一面 · 发帖 2026-10-03 · 作者 屁瓜 · 来源：[小红书](https://www.xiaohongshu.com/explore/6ac1c263000000000a020b3d)

## 速览

- **重点**：HTTP / HTTPS、缓存与系统分层、版本兼容、权限体系、Java 本地 AI Agent、MCP / Skill、日志分析与异常告警。
- **难度**：中高，偏项目深挖和工程落地。
- **题量**：23 道。

## 面经正文

1.请先做一下自我介绍。
2.你这个生活服务平台，从用户在页面点击，到后端处理、数据库存储，再到结果返回，整个数据流向是怎样的？
3.你可以简单讲一下 HTTP 协议吗？
4.HTTPS 主要解决什么问题？为什么要使用 HTTPS？它和 HTTP 有什么区别？
5.你们后端是直接访问 MySQL，还是中间还有 Redis、消息队列等？整个系统的层次是怎么构建的？
6.如果出现缓存雪崩，你会怎么处理？
7.如果系统以后除了优惠券，还需要接入优惠包等其他业务形态，你会怎么设计，支持不同场景的接入？
8.如果 APP 的 1.0、2.0 等多个版本同时存在，但后台只有一套服务，你会怎么处理不同版本的兼容问题？
9.如果 2.0 版本的数据库增加了字段或者新表，怎么保证 1.0 版本还能正常运行？
10.如果不同服务的登录体系、权限要求和权限粒度都不一样，你会怎么在当前系统中支持？
11.如果要设计一套完整的角色权限体系，包括普通用户、商家、超级管理员等角色，你会怎么设计？
12.你这个 Java 本地 AI Agent 是怎么一步一步搭建起来的？
13.如果已经进行了很多轮对话，中途从模型 A 切换到模型 B，怎么保证上下文和任务还能继续？
14.为什么需要 MCP？MCP 主要解决什么场景和问题？
15.MCP 在 Agent 的生命周期中什么时候加载、发现并注册工具？
16.你怎么理解 Skill？为什么会出现 Skill？它主要解决什么场景？如果接入你的编程助手，要怎么装载？
17.怎样让大模型更好地识别用户意图，并正确触发对应的 Skill？
18.如果 Skill 后续会不断增加、更换，除了写在 System Prompt 里，还有什么方式可以让模型正确找到和使用 Skill？
19.如果让你设计一个多业务方接入的日志分析与异常告警系统，你会怎么设计整个系统？
20.在日志分析阶段，不同业务场景的业务逻辑和错误含义不同，怎么利用大模型针对不同业务进行分析？
21.如果要接入 10 个、20 个业务方，不同业务的 Skill 应该由平台方来写，还是业务方来提供？
22.如果业务方把代码库也接入系统，你会怎么结合代码库去分析和定位日志中的异常？
23.如果一个业务由四五个微服务、多个代码仓库组成，一个异常可能跨多个仓库，怎么分析这些仓库之间的关系？同时，如果代码量达到十万行、目录嵌套七八层，怎么解决检索效率和定位困难的问题？

这次面试体验很好，面试官很年轻很健谈，对于问的问题给了很好的反馈启发，对于磕绊的问题也很耐心地解释和引导，和上次字节面试体验完全不同。
