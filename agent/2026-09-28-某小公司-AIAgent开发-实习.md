# 小公司的面经记录

> 某小公司 · AI Agent开发 · 实习 · 结果：已过 · 发帖 2026-09-28 · 作者 ZeroDay · 来源：[小红书](https://www.xiaohongshu.com/explore/6aba4252000000001501229f)

## 速览

- **重点**：Todo 与 Research Agent、Tool / Skill 约定、雅思成绩 Skill、官网检索与 RAG 构建、Amazon 找商家开放场景题。
- **难度**：以项目深挖为主，几乎不问传统八股和算法；后来评论已过。
- **题量**：12 问（编号有 1-4、6-12、14，缺 5 和 13）。

## 面经正文

AI Agent 开发实习面经，整理一下这场面试中面试官实际问到的问题。整体以项目深挖为主，没有怎么问传统八股和算法。

项目深挖

1. 你项目里的 Todo（待办）模块设计目的是什么？它在整个执行链路中是怎么执行的？Research Agent 和 Todo 之间是怎么交互的？
2. Main Agent 从一个 Goal 进来并拆分以后，是不是会形成几个 Todo？具体的 Todo 是怎么执行的，是通过工具自动执行，还是有些需要人工操作？
3. 介绍一下整个 Agent 的工具层设计。可以挑几个比较重要的 Tool / Skill，说一下具体是怎么设计的，以及输入输出是怎么约定的。
4. 以“查询用户雅思成绩”为例，这个 Skill 具体是怎么写的？执行流程是什么？数据是从外部网站查询、用户自己提供，还是你们自己的数据库里已经有？
6. Research Agent 需要查询学校官网、入学要求等外部信息，你具体是怎么通过 Research Agent 查询这些信息的？
7. 学校官网这些信息源，是直接编排到 Skill / Prompt 里面，还是放在一个单独的数据源里进行查询？
8. 如果 Research Agent 要去某个学校官网检索政策，它具体是怎么执行的？涉及浏览器控制、Browser Automation、Web Search，还是其他方式？访问官网以后又是怎么抓取具体信息的？
9. 介绍一下 RAG 知识库。数据源是什么？从数据输入开始，到最终完成知识库构建，整个流程是怎么样的？
10. Chunk 是怎么切分的？固定块大概多大？Overlap 设置了多少？
11. Embedding 用的是什么模型？为什么选择这个模型？
12. 这个项目从七月份开始做，大概开发了多长时间？最后有没有交给别人实际试用？

开放场景题

14. 假设现在有一个业务需求：从 Amazon 根据用户需求寻找商品，再从商品找到背后的商家，并自动获取商家的官网、地址、邮箱、Facebook 等公开信息。如果要构建一个 Agent 来完成整个链路，你认为其中可能存在哪些痛点、难点或者卡点？
