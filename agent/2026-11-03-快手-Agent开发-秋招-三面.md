# 快手三面

> 快手 · Agent开发 · 秋招三面 · 面试 2026-11-03 · 发帖 2026-11-03 · 作者 远山 · 来源：[小红书](https://www.xiaohongshu.com/explore/6ae99e9f000000001a02139a)

## 速览

- **重点**：先拷打实习，再问 MySQL MVCC、数据库与 MQ 的一致性、并发任务调度，以及 Agent 工具参数校验、模型大批量调用、大规模评测执行、中途重启恢复和无效循环判断。最后有一道螺旋矩阵。
- **难度**：秋招三面，偏场景题和交流，作者觉得面试官级别比较高，问题并不简单。结果未知。
- **题量**：9 问加 1 道螺旋矩阵手撕。

## 面经正文

千等万等，终于等来了快手的三面，昨天约面，毫不犹豫的把时间选到了今天，眼看马上都要开奖了，这个时候真是一点都不想拖着流程了

三面总体来说感觉偏向场景题和交流，面试官应该是级别比较高的大Boss了，整场下来基本上是以漫谈的形式交流，问我问题，但是问题可真是一点也不简单啊

上来就是拷打实习，大概问了十几分钟，看样子他有更想说的

具体问题部分：

1. MySQL 的 MVCC 底层是怎么实现的？为什么它能让读写操作尽量不互相阻塞？

2. 你正在做的一个服务需要同时更新数据库和发送 MQ 消息，你怎么保证这两个操作的一致性？

3. 如果要设计一个支持大量并发任务的调度系统，该怎么管理任务状态、失败重试和资源分配？

4. Agent 调用工具的时候，怎么保证模型生成的参数正确？工具调用失败以后应该怎么处理？

5. 假设突然线上一个接口突然从 200ms 变成 5s，但服务器 CPU 和内存都正常，你会怎么定位问题？

6. 你使用的内部平台假设每天需要调用模型生成上百万条数据，你会怎么控制并发、调用成本和失败重试？

7. 现在有一批评测任务，每个任务都需要执行完整的 Agent 流程。如果同时运行几千个任务，你会怎么设计执行架构？

8. 如果一个长时间运行的任务执行到一半，服务突然重启了，你会怎么恢复任务？怎么保证已经完成的操作不会重复执行？

9. 如果一个 Agent 连续调用工具十几次都没有完成任务，你怎么判断它是在正常执行复杂任务，还是陷入了无效循环？

最后面试官笑着简单聊了两句，出了一道螺旋矩阵结束了

不知道还能不能有后续，上次被字节真是吓怕了
