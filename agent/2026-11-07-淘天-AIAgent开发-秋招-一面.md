# 秋招 淘天 AI Agent / 大模型应用研发 一面面经

> 淘天 · AI Agent开发 · 秋招一面 · 发帖 2026-11-07 19:18 · 作者 雾已散声宜慢 · 来源：[牛客](https://www.nowcoder.com/feed/main/detail/6d45897f57b0484eb9863bc991993866)

## 速览

- **重点**：RAG、记忆与上下文、Agent 规划、评测、实习深挖。
- **难度**：中等。
- **题量**：25 道左右。

## 面经正文

面试方向： AI Agent / 大模型应用研发

部门： 业务技术下的会员技术团队

### 一、开场与自我介绍

1. 介绍一下你的学习经历、实习和项目经历。

### 二、本体化与能力开放

2. 能力开放和本体化项目里，你主要负责什么？

3. 这套能力到底给谁用？具体使用场景是什么？后面准备扩展到哪些领域？

4. 本体化和普通 RAG 有什么区别？把文档写完整，再用 RAG，效果差在哪里？

5. 你们是把所有资料都本体化，还是只做部分核心能力，其他内容仍然用 RAG？建设和维护成本怎么考虑？

6. 效果提升究竟来自“本体结构”，还是来自你们投入了大量人工整理？

7. 你说本体化可以做强 Schema 校验，但普通 Tool Calling 和接口本身不也能校验参数吗？

8. 本体现在靠人工维护，还是已经有自动抽取和更新机制？

9. 原来很多人各自维护文档，现在会不会变成少数人维护整套本体？维护门槛和人力成本如何解决？

10. 你主要在做本体和配套数据整理，还是也负责上层 Agent 的构建？

11. 你看过哪些本体化资料和行业实践？如何判断某个业务对象应该成为本体？本体之间的关系怎么确定？

### 三、个人项目：航旅故障排查 Agent

12. 这是你自主完成的项目吗？介绍一下整体架构。

13. 三层架构就是三个 Agent 吗？每一层都调用大模型吗？用一个具体场景讲一下执行过程。

14. 如果最后没有定位到故障，Agent 怎么知道是哪一层出了偏差，并在执行过程中纠正？

15. Planner 和 Executor 的工具集合是什么关系？Planner 如果不知道执行层有哪些工具，怎么制定可执行的计划？

16. 为什么一定要固定拆成三层？为什么不直接使用单 Agent 的 ReAct 主循环？

17. 自适应 RAG 和混合检索优化具体做了什么？为什么需要混合检索？

18. 个人项目不是企业生产系统，简历里的故障排查效果指标从哪里来？

19. 从零构建一个 Agent，需要哪些关键组件？要解决哪些关键问题？

20. System Prompt 应该怎么组织？如果要加入当前时间，可以直接放在第一行吗？

21. 工具返回的信息太长，无法直接放进上下文，有哪些处理办法？上下文压缩怎么做？

22. 聊天工具里的 Session / Message 是怎么存储的？你了解具体的数据结构吗？

23. Agent 请求用户授权，或者向用户追问时，执行流程怎么暂停？用户回复后又怎么继续？

24. 你对 Agent Memory 有哪些系统性的了解？

25. 记忆的时效性、衰减和更新怎么处理？
