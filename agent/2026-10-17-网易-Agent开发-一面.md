# 网易agent开发岗一面

> 网易 · Agent开发 · 一面 · 发帖 2026-10-17 03:34 · 作者 offer辅助达人 · 来源：[牛客](https://www.nowcoder.com/feed/main/detail/bad72b1323274ad5b172039f48bfa4b1)

## 速览

- **重点**：多 Agent、RAG、记忆与上下文、工具调用 / MCP / Skill、Agent 规划。
- **难度**：中等。
- **题量**：31 道左右。

## 面经正文

1. 做个自我介绍，重点介绍Agent相关项目经历。
2. 你的Agent项目整体架构是什么？核心模块有哪些？
3. 项目中用了哪些框架（如LangChain、Coze）？为什么选这个框架？优缺点是什么？
4. 项目最大的技术挑战是什么？怎么解决的？有什么落地效果？
5. 你提到的Coze，拖拽式编排与Agent原生模式有何区别？你如何设计节点？
6. 解释Agent的核心范式（ReAct、Plan-and-Execute、反应式等），区别与适用场景。
7. 什么是Agentic Loop（感知-规划-行动-记忆闭环）？各环节作用是什么？
8. Agent如何防止死循环？有哪些终止条件设计？
9. 上下文管理与记忆机制怎么做？Working/Short-Term/Long-Term记忆如何分层？
10. 如何解决Agent的幻觉问题？有哪些校验与反思机制？
11. 什么是MCP？和Function Calling的区别？优缺点？
12. Tool调用流程是什么？如何设计Tool的description以提升调用准确率？
13. 工具调用失败如何处理？重试、降级、参数修正策略？
14. RAG的核心流程？Chunking策略、Query Rewrite、Rerank怎么做？
15. RAG检索内容与模型知识冲突时，如何处理？
16. 工具过多导致上下文过长，怎么优化？
17. 设计Agent的System Prompt核心原则？包含哪些关键信息？
18. 如何用Few-shot、CoT提升输出稳定性？怎么避免格式混乱？
19. Prompt如何做鲁棒性优化？反例提示、Schema校验怎么落地？
20. Multi-Agent适用场景？为什么拆分多个Agent而非单Agent？
21. 多Agent如何分工（角色设计）？协作流程与通信机制？
22. 如何避免多Agent幻觉放大？交叉验证与状态同步怎么做？
23. 设计一个全自动化AI漫剧创作Agent，整体架构、核心节点、关键流程？
24. 漫剧Agent如何保证人物设定、画风前后一致？用什么技术方案？
25. 设计一个“可进化”的游戏BOSS战Agent，能学习玩家打法并动态调整策略，架构怎么设计？
26. 如何设计实验验证Agent效果（如漫剧质量、游戏AI体验），而非单纯提升难度？
27. 若要快速上线Agent MVP，保留哪些核心功能？如何做功能取舍？
28. 用过哪些AI Coding工具（Cursor、Codex、Claude）？解决过哪些实际问题？
29. 开发中如何用AI提升效率？如何避免AI生成代码污染主分支？
30. Agent部署时遇到哪些问题？性能优化、并发控制怎么做？
31. 当用户反馈Agent“很蠢”时，如何定位问题（可解释性）？ 牛客AI配图神器#
