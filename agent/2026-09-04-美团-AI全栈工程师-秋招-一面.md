# 美团AI全栈工程师一面

> 美团 · AI全栈工程师 · 秋招一面 · 结果：挂 · 发帖 2026-09-04 · 作者 BiscuiTAT · 来源：[小红书](https://www.xiaohongshu.com/explore/6a9a95280000000027009eb2)

## 速览

- **重点**：面试前 AI 场景题、少量 MySQL / Java 线程池八股、知识库或图书问答架构、vibe coding 与 AI review 能力。
- **难度**：八股很少，开放性比较大，面试体验像聊天；作者后来称回简历筛选。
- **题量**：4 部分，面试前另有两道 AI 场景题，面试中共三道场景题。

## 面经正文

1.面试开始前一个小时左右就发了题目（ai场景题），可以做到面试开始前半个小时，其实时间到了可以直接进会议间继续做，面试开始后，面试官可能也会要求你继续做然后他看一下。

2.八股最少的一集，问了一点点mysql，java线程池还有一些题目有点忘了，真的特别少，面试官也不会打断我的“en...”。

3.后续基本就是ai场景题（加上面试前的两道一共三道），比如问你如何用ai设计一个自己的知识库/图书ai搜索问答架构。整体就是面试官会看你用agent，整体的协作过程。以及你的理解。总之就是考验你vibe coding以及用agent完成任务的能力，感觉开放性比较大。

4.学习过程中的一些难点，以后可能基本ai写代码的话，怎么保持coding能力之类的也是开放性问题。

总结：

今天面试官整体给我的感受就是在聊天，或者像是和学长交流的感觉，他会考察你，但是给你反馈的体验又很好。中间mysql的一个好像是排查问题还是什么的点，我有点卡壳紧张，就说可能平时接触得实际场景不多，他说没事，我换一个问题就好（论为什么会在面试时爱上面试官，嗯开玩笑的）。然后在和面试官交流和反问的过程中，对于美团的这个AI全栈好像看重的是review能力，察觉ai输出的错误的能力（还有防止过度设计等等），不能无条件用ai、相信ai，原话“不能为了用ai而用ai”。总之就是有目的得用ai，用好ai。感觉是这个意思。

和昨晚同样的岗位不同的体验，嗯，八股也少。今天的面试官真不错，回答开放性问题时会先肯定，再引导或者换个问题。没过也无所谓。

决定了，这周点外卖不用闪购用美团了🥳🥳。
