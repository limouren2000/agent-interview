网易 agent 开发面经
agent 八股
1. 如果你的向量检索检索不到你想要的信息怎么办
2. agent 从用户输入问题 到返回回答，agent的执行流程是怎样
3. rlhf 你写了 这个是什么干什么的 dpo 呢

项目
1. 项目动机 出于工作难过需求？还是就是自己想做？还是从基础项目体现 ai 意识？
2. 讲一下你项目里的的智能客服，你的智能客服是怎么做的
3. 如果你的智能客服回复异常，不精准乱说话怎么处理
4. 你第一个项目是干什么的 没太看懂
5. 你的数据库是怎么设计的 在什么情况下会建立索引 在什么情况下需要使用缓存
6. 你做数据库 用的什么字段呢 存储哪些数据表里的每个字段为什么这么设计？讲一下 MySQL 的事务隔离
7. 最后，你说你做过前端，讲一下你对 vue 了解 聊一下你对 vue 的一些知识吧

实操
1. 你怎么去修 bug，两个都会问 ai 写了代码 有问题 你要做什么动作

后端 基础
1. 项目高并发做过吗，了解
2. Python 闭包讲一下，包用过哪些库，主流的库
3. 计网 HTTP，TCP、UDP
4. Git 有什么命令，各种 git 操作熟悉吗
