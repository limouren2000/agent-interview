## 面经正文

体验无敌，自我介绍阶段对面全是说话声和杂音，不知道是在开会还是干啥，持续了十分钟大概，后面稍微好一点
手撕，本来说写伪代码就行，写完又要求写真代码，重复耗时
期间面试官还离开了几分钟，看来是真挺忙的
1. 项目解决什么问题、方案是什么
2. 用什么框架做的（答没上框架，纯 Python）
3. workflow 里的 agent 节点做什么（深挖项目）
4. agent 有哪些 tool（答检索+聚类）
5. 聚类怎么实现（答文本 embedding 向量化后跑聚类算法）
6. 为什么不把检索结果直接作为上下文给模型（答当时的场景对可用模型有限制 ......）
7. 手撕带 TTL 过期的 LRU（LC146 变体）。先讲思路（链表+哈希、节点带剩余过期时间），写了伪代码，又被要求写真实代码。但是也没让我跑，看了几眼觉得 OK 就过了

### 反问

1. 如果进去主要做什么？答是做生图生视频基础设施上的事情，以及基于生图生视频能力在上层做营销、短剧这类场景的开发
2. 岗位写的后端 Agent，实际偏传统后端更多，还是偏 Agent 的工作更多？答后端和 Agent 都有。现在做营销场景会用 Agent，有时候是工作流调模型能力来完成事情，但不是“为了做 Agent 而 Agent”，更多是看业务场景用什么方式更合适，再做决策。
3. 这次面试有什么可以改进的吗？答你的项目，你们有没有很认真地对比过两种方案的优劣，再来做决策？我们这边做很多探索性业务，没有成熟方案可以直接复刻，所以会比较看重分析、调研、甚至做实验的能力
