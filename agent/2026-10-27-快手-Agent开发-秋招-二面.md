# 快手二面

> 快手 · Agent开发 · 秋招二面 · 面试 2026-10-27 · 发帖 2026-10-27 · 作者 远山 · 来源：[小红书](https://www.xiaohongshu.com/explore/6ae09ca50000000035018346)

## 速览

- **重点**：追问 Agent 项目，Harness 差异和 DeepSeek Harness，Codex 与 Claude Code 的上下文压缩，记忆系统设计，百万级去重和内存受限，CPU / Full GC 排查，进程间通信和协程，以及模型训练、监督训练、rollout 和世界模型。
- **难度**：秋招二面，以实际业务和场景题为主。作者觉得面试官态度好、问得深，偏工程优化。结果未说明。
- **题量**：17 问加 1 道两两反转链表手撕。

## 面经正文

今天参加了快手二面，二面的面试官我觉得挺好的，整场下来句句有回应，态度还是很不错的，但是全程主要以实际业务和场景题为主

1. 追问我自己的 Agent 项目。
2. 现在市面上的这些 Harness 你觉得有什么差异化吗？还是都差不多？
3. 听你提到了 Deepseek Harness，详细讲一讲。
4. Codex 的上下文压缩机制是什么？和 claude code 有什么区别？
5. 记忆系统让你来做会怎么做？
6. 现在有一个场景题：有一个百万级别量级的数据表，里面有很多重复数据，现在需要你做一个去重，该怎么办？
7. 听完你的思路，再加一个条件，如果机器的内存很小该怎么办？
8. 现在有一个其他人写的代码或者说外部的服务，出现一个问题就是 CPU 占用很大，你会怎么去排除？
9. 如果出现了 Full GC 的情况，你会怎么排查？
10. 现在有一个6核的 CPU，你会怎么去查看他计算进程占用的量（这个问题说实在的没有很理解）
11. 你在学校里有没有接触过进程间通信的实验，有哪些方式？你认为哪个更好？
12. 共享内存的方式有什么优缺点？
13. 携程你了解吗？你觉得他解决了什么问题？
14. 模型的整个训练过程你了解吗？
15. 你提到了 Agent 的监督训练，这个是怎么做的？（讲了一个看过的开源项目，天呐，差点没圆回来）
16. 你提到的这一个 roll out 是怎么设置的？奖励的方式是什么？
17. 那再讲讲你提到的那个世界模型监督训练是怎么做的？

手撕：两两反转链表节点

感觉这场面试问的挺深的，面试官比较着重针对工程优化方面进行提问，值得好好复盘一下
