# 亚信大模型应用开发二面

> 亚信 · 大模型应用开发 · 电话二面 · 发帖 2026-11-09 · 作者 鱼摆摆不能再摆 · 来源：[小红书](https://www.xiaohongshu.com/explore/6af18749000000003300f4c2)

## 速览

- **重点**：全栈理解、RAG 与数据清洗、Coding Agent 上下文管理；项目里 TinyBERT、并发 P95 和 prefill 优化；数据安全、内容安全，以及在 hidden state 上加分类头。
- **难度**：上午一面、下午二面，二面是电话面，偏项目经理或部门主管，注重场景和自己的思考。
- **题量**：场景题 6 道、项目 3 道、其他 4 道，另有反问。

## 面经正文

上午一面 下午二面 电话面
二面应该是项目经理或者部门主管 问题会深一点 比较注重场景和自己的思考

电话面

面试流程：

首先自我介绍

提问（几乎全是场景题）：
1. 怎么理解现在的全栈开发？
2. RAG搭建流程（从数据沉淀到最后优化）？
3. 如果有十万条数据，数据条数多了怎么维护RAG系统？
4. 怎么搭建数据清洗pipeline?
5. 有没有了解过龙虾类产品，包括像Codex、CC，他们各自有什么上下文管理策略？
6. 如果让你设计一个Coding Agent，你会怎么做上下文管理？

提问（结合项目）：
1. tinybert输入是多少？模型的上下文不够时会怎么做？
2. 线上并发能跑到多少？P95多少？
3. 对于模型推理，prefill阶段做过哪些优化？（说了一个输出的时候只输出0/1，其他的忘了）

提问（其他）：
1. 有没有了解过数据安全，比如企业内部训练了一个模型，怎么防止用户提问可能诱导一些内部信息？
2. 有没有了解过内容安全呢？
3. 如果要做安全的话，觉得是Guard类模型还是Bert类模型好，一个慢一个快。
4. 有没有做过把大模型保留全部Decoder主干，扔掉原来的LM头，在hidden state上加分类头

反问：觉得我的简历有没有什么问题。
答：看以后要做什么方向，要做Agent的话，可以多去了解一下架构底层，比如像DeepSeek最近的Super Agent，包括一些云沙箱虚拟化啥的。如果要做安全的话，可以多去了解一下数据安全和内容安全，目前客户还是认这两块。
