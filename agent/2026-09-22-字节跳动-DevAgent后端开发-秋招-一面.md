# 字节跳动 Dev Agent 后端开发 一面

> 字节跳动 · Dev Agent后端开发 · 秋招一面 · 结果：感谢信 · 面试时间 2026-09-09 · 发帖 2026-09-22 · 作者 在河 · 来源：[小红书](https://www.xiaohongshu.com/explore/6ab22e9d000000003a022446)

## 速览

- **重点**：Agent 难点与记忆压缩、手写 React 循环、RAG 切分与检索、成本 / 速度 / 效果的影响因素。
- **难度**：约 1 小时，隔天收到感谢信。
- **题量**：12 问（含手写 React 循环）。

## 面经正文

9.9 面的 1h 隔天感谢信
1：自我介绍
2：你在做这个 agent 项目的时候遇到的最大的难点是什么？
3：agent 记忆是怎么设计的？上下文压缩具体是怎么做的？
4：长期记忆是怎么保存的？大模型怎么知道什么是长期记忆，怎么知道如何保存长期记忆。
5：手撕：手写一个 React 循环。
6：你这个 RAG 项目的主要流程是怎么样的？
7：如何保证大模型的输出质量？
8：如果关键信息刚好被切分了怎么办？
9：检索过程是怎么样的?具体采用了什么检索方式
10：你觉得 RAG 这个东西会有什么问题？
11：你认为影响做一个 agent 需要考虑哪些因素？
12：那就你说的成本（token消耗）、速度（运行时间）和效果（成功率），这些又受哪些因素影响呢？
