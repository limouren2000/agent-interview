## 速览

- **重点**：记忆与上下文、工具调用、项目深挖。
- **难度**：中等。
- **题量**：20 道左右。

## 面经正文

本人硕5年，社招面试阿里p7

### 一、个人经历与职责

1、简单介绍一下自己，以及做过的 Agent 项目。
2、你在团队里是什么角色？目前主要负责 Agent 开发吗？
3、你会写前端吗？之前有没有做过前端开发？
4、看你的项目主要使用 Java，为什么以 Java 技术栈为主？有没有用过 Python 等其他技术栈？

### 二、项目架构与技术选型

5、展开讲一下最近做的 Agent 项目，包括完整的技术方案和整体架构。
6、为什么选择 Neo4j 来实现这套方案？
图数据库在这里承担什么职责？是不是通过不同节点之间的关系进行查询，再由不同节点对应不同的工具调用？
7、现在已经有 LangGraph 这样的图式 Agent 运行时框架，为什么没有选择它，而是采用当前方案？
8、这个项目最大的技术难点是什么？有没有遇到比较有挑战性的问题？

### 三、工具调用与执行反馈

9、调用工具时，有没有出现过选错工具，或者本来不需要调用工具却调用了的情况？
10、整个执行链路里，有没有反复推理、观察反馈和重试的过程？
比如工具调用的参数传错了，如果直接拒绝执行，是不是意味着这次请求就失败了？
有没有让模型观察错误、接收反馈，再尝试纠正的过程？

### 四、知识图谱与领域建模

11、图谱是怎么建设出来的？整个建设过程大致是什么样的？
12、建模阶段是由领域专家来做吗？有没有采用一些方法论，比如本体（Ontology）？
13、实体和关系的抽取，是人工完成，还是交给大模型完成？
14、你提到大模型会“辅助提取草稿”，具体是什么意思？这个过程是怎么做的？
15、在这个过程中，语义消歧是怎么处理的？

### 五、上下文与状态管理

16、项目里有没有遇到过上下文溢出的情况？你们是怎么解决的？
17、你提到会用结构化对象承接上下文，这个对象的主要结构是什么？包含哪些字段？
也就是说，会把原来的上下文信息转成结构化状态来传递，对吗？

### 六、新技术与方案对比

18、最近讨论比较多的 Agent 新框架、自学习方向，你了解过吗？
平时会关注哪些新开源的框架或者模型？
19、新框架内置的 Trace 插件，与独立的可观测平台有什么区别？
20、你刚才提到的新技术，具体会用到哪些场景？
