## 面经正文

面试时间：8月1号
最近 Agent / 大模型方向的岗位讨论挺多，感觉不同公司的考察方向差异还是挺明显的，但是主播已经凉凉
整理了一下面试过程中涉及的问题：
（1）平时怎么使用 AI coding？
（2）如何保证 AI coding 生成代码的质量？
（3）AI 幻觉产生的原因是什么？
（4）DeepSeek、OpenAI 这类模型 API 有哪些接口？
（5）如何解决模型回答的事实性和忠实度问题？
（6）Skill 和 MCP 有什么区别？
（7）Skill 有哪些特性？
（8）个人agent项目深挖
（9）手写题（二选一）
A：Python 实现一个装饰器，用于打印 log。
B：ACM 模式：输入若干组（售价、售出、买入），输出售价最低的前 4 个，并要求售出和买入都不为 0
整体下来感觉这一轮项目深挖占比比较高，很多问题都是围绕 Agent 的实际流程继续往下展开
