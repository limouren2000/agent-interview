## 速览

- **重点**：一面深挖 Agent 项目，问后端同步一致性，ReAct 循环与评测，Skill / MCP，RAG 拆解以及 HyDE、Step-back、RRF，还有 Python GIL；二面问 Decision Model 与 Personal Agent、上下文压缩，手撕多线程顺序打印 ABC；三面是主管面，问 AI Coding 习惯、自研 Agent 相对开源框架的价值，以及桌面办公 Agent 趋势。
- **难度**：实习。一面一个多小时，作者觉得强度明显高于其他公司；二面约半小时，几乎不问简历、追问原理；三面一开始以为是 HR 面。结果均未说明。
- **题量**：一面问题很多，无手撕；二面约 20 问（图片原编号从 5 跳到 10）加 1 道手撕；三面教育背景、工具、项目和行业趋势若干，无手撕。岗位名是 AI 研发，但题目明显是 Agent / LLM / RAG 方向，故放入 agent/。看不出是暑期实习还是日常实习，故标为实习。
