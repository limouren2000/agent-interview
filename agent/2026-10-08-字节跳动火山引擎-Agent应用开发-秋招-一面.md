## 面经正文

八股拷打，问了很多计网和操作系统，反问发现团队业务偏基础设施，对基础要求比较高
面试官人很好，全程和善，说得不够细的地方也在引导说明，体验很好[赞R]
面试完第二天约二面

火山引擎-Agent 应用开发工程师-一面
1. 算法：LRU缓存（Hot 100）
2. 场景题：设计简单的异步系统（不使用MQ等中间件），实现数据的存取，说明清楚从发起请求到数据存储和获取的全过程如何设计。
3. 项目拷打
• 说明实习的Agent项目中你主要参与的部分，包括方案选型、Skills设计、接口设计、从请求到处理的全链路等
• 你认为Agent开发和传统前后端开发有哪些区别？
4. 八股
• 说明进程和线程的区别
• 进程和线程创建和切换上下文的开销有哪些区别？
• 进程间的常用通信方式（IPC）有哪些？在终端输入ls指令属于哪种？
• 操作系统的内核态和用户态有何区别？
• 说下 TCP 的 3 次握手，并分析下为什么不用 2 次或 4 次？
• 说下 TCP 的拥塞控制机制
• 说明 TCP 和 UDP 的区别，如果想用 UDP 实现可靠传输怎么处理（提醒了解 HTTP3）
• HTTP 的常见状态码有哪些？了解 429 是什么吗？
• HTTP 接口的 POST、PUT、PATCH 有何区别？
• POST 接口本身不幂等，那如何业务需要幂等处理，怎么设计接口处理？
• 了解 Go 语言和其中的协程吗？
• Redis 是单线程还是多线程的？为什么？
• I/O 多路复用中的 epoll 是什么？
• 了解过零拷贝吗？
• Redis 的数据持久化机制有哪些？
• 既然 Redis 有数据持久化机制，为什么还要用数据库，不直接用 Redis 存储数据？
• 除了它是 NoSQL 数据库外，为什么即使有些场景需要 NoSQL 数据库，也不选择 Redis？
• MQ 的消息积压如何处理？
• 在后端设计时，如何保证能监测到 MQ 积压问题？
