# 深信服Agent开发实习生一面二面，长时间被吊着，最终被横向掉了

> 深信服 · Agent开发 · 实习一二面 · 发帖 2026-09-02 10:42 · 作者 杰尼龟准备秋招中 · 来源：[牛客](https://www.nowcoder.com/feed/main/detail/14b2c379ae434062a009aefea9fc5df9)

## 速览

- **重点**：多 Agent、RAG、工具调用 / MCP / Skill、手撕算法、实习深挖。
- **难度**：中高，偏项目深挖和工程落地。
- **题量**：28 道左右。

## 面经正文

### 一面

1. 自我介绍
2. 面试官介绍当前岗位的场景（AI Agent平台开发，Harness工程工具（类似于superpowers这种），Agent数据分析）
实习相关：
3. 介绍金蝶实习时如何和前端/其他部门做接口对接，具体遇到什么问题？
4. Agent工具过多时你是怎么处理的？比如接口数量太多怎么解决？
5. 最终的效果怎么样？准确率达到了多少？咋么测评？
6. 这个（自动切题Agent）端到端的业务逻辑是什么？用户到底想做什么？整个数据流和功能效果是什么？
7. 处理流程可以讲一下吗？整体链路是怎样的？
8. 开发过程中使用的是什么工具/框架？
9. 开发过程中有没有碰到什么问题？（讲实际的场景的，怎么解决）
10. （金蝶实习）公司有什么AI Coding的方法论来保障生产质量？
11. 这套方法论你们是如何研究的？
12. 除了这些项目之外，还有哪些能够拿得出手的亮点事情或项目？
13. 我们部门有三类工作（AI Agent开发平台、Harness工程工具、Agent后端数据分析），你对哪一类更感兴趣？并说明理由
14. 反问

### 二面

1. 自我介绍
2. 在金蝶实习中，做的最核心、最有价值的一个工作是什么
3. 能详细说明一下吗？业务层面是什么样的？技术层面核心怎么做？架构是怎么样的？
4. 动态工具注册中心是怎么做的？动态注入是怎么去注入的？
5. 你这个工具调用和 MCP、LangChain 的 Tools/Skills 有什么比较大的区别？
6. 现在 100 多个工具，AI 想调用的时候，能找到自己想要的接口吗？怎么保障？
7. 如果出现当前已给工具无法解决的问题时，怎么去解决的？
8. 工具检索是如何做的？
9. 这个过程（工具注册中心的构建）中有什么难点吗？
10. 你对整个多 Agent 架构熟悉吗？
11. 你们这种做 Agent 的框架，和 AutoGen、CrewAI 这些有没有特别大的差异？
12. 在金蝶实习过程中，团队氛围怎么样？
13. 两段实习中那一段实习学到的东西最多，都学到了什么？
14. 手撕：无重复字符的最长子串

一两周之前面的了，昨天突然给我发感谢信。怎么说能，还是有点无语，二面面完后告诉我过了，然后说5个工作日内会有HR联系我谈薪资待遇这些。然后还和我说了，让我如果手里面有其他的意向的话可以先放一下，可以优先考虑他们的。结果就是后续大概率是先把我们稳住，然后这几天一直面，然后找到更好的。（虽然我认为这不是什么问题，但是你别告诉我过了，然后又让我缓其他意向），幸好当时刚离职，手里面也没有其他结果，不然说不定真被他耽误了
