项目一

R-Code 是你自己做的，还是在实习单位做的？是你从头到尾手写，还是使用 AI 辅助开发的？

你当时使用的具体是什么模型？最开始给 AI 的 Prompt 是什么？整个开发过程中大概修改了多少版、和 AI 交互了多少次？

你是阅读了 Claude Code 的源码然后重新实现了一套吗？做 R-Code 的初衷是什么，是为了改善现有 Coding Agent 的不足，还是单纯为了学习和复现？

评测的 50 个真实仓库任务具体是什么类型的代码、来自哪里？这些任务的代码规模怎么样？

这些测试任务具体是什么、怎么验证你的 Coding Agent？你说的“官方测试”具体指什么？
你怎么确认这 50 个任务涉及长任务和长上下文问题？怎么判断它们一定需要上下文压缩？

你怎么证明自己实现的上下文管理机制确实解决了这些问题？

你提到工具调用次数和 Token 消耗下降，这些数据是怎么比较出来的、对比基线是什么？

开启 Session Memory 之后，内部具体做了哪些事情？为什么这些改动能够减少工具调用次数和 Token 消耗，具体原理是什么？

有没有分析过具体案例，为什么有些任务下降得多、有些下降得少？有没有分析 Token 具体在哪些环节减少，以及哪些上下文内容被压缩了？

有没有使用 Claude Code 或 Codex 在相同的 50 个任务上进行对比？它们分别能完成多少？

剩余失败任务是无法解决，还是你没有继续优化？对这些失败任务是否都进行了具体分析和分类？

你限制了多少次修改或修复机会？这个限制不能调整吗？如果调整修复次数，实验结果会发生什么变化，有没有测试过？

你说有环境问题和修复问题，具体的修复问题是什么？

在项目迭代中遇到的问题，你具体是怎么解决的？

项目二

这个东西现在有没有实际用户？它是一个团队共同完成的项目吗？

在这个团队项目中，你主要负责哪些工作、具体解决了什么问题？刚才介绍的整套工作流都是你搭建的吗？

你说把自由 ReAct 改成确定性 DAG，这个确定性编排具体做了什么？

意图识别具体是怎么分类的、如何确定用户想做什么？意图判断是模型完成的，还是使用了其他规则？意图识别出来后有哪些不同类型，这些类型是怎么划分的？

完成这些改进之后，你怎么评价系统变好了还是变差了？

你简历里写的 Hybrid Retrieval 是什么意思，具体怎么实现？

如果检索出来的内容相似度很低，或者用户问的问题完全不在知识库中，系统会怎么处理？没有检索到有效依据时，系统会不会自己构造答案，如何保证回答有依据？
项目三

你最近在做的是什么项目？这个多模态客服项目是给公司做的，还是自己做的？

合作公司是否提供了一些业务文档或数据，用来构建这个系统？

你的多模态客服 Agent 具体包含哪些模态？图片数据需要进行哪些处理？

你在这个项目中主要负责什么工作？你说优化了长工具调用链路中的信用分配问题，具体是怎么优化的？

你怎么理解 Agent、Skill 和 MCP？它们分别是什么、有什么作用？

你最近主要在学习或者研究什么？你未来到底想做什么方向，对什么技术或工作比较感兴趣？
你在校期间有没有获得过什么奖励或荣誉？你怎么评价自己的学习能力？

你对海康威视有了解吗？
