## 面经正文

前两个月面的，体验还不错，面试官很真实直接从做过什么入手
agent八股，有没有真做过，项目实操，后端，技术栈基础

然后哪些人有亮点 就是体现你有 探索欲 就是ai新闻 新模型新框架 不只是看过 有没有尝试过 尝试过你有什么思考 你自己的理解是什么
然后这个岗位 也是说有培养 对于你这种26届或者一年经验的
非常好hr 和面试官 知无不言

agent全栈开发面经 - 深圳游戏中厂
非常好的一次面试
自我介绍 实习都没问你 直接问你项目
1. 问你 ai工具使用情况 使用多少token
2. 上来先问你你哪个项目参与度高 就是都知道都是ai开发的 就问你做过什么项目的 就是实操项目的重要性 你有没有真实的做过 思考过

agent八股
1. 记忆与上下文管理
如果有多个用户 多个会话 这个怎么管理 有几种方案 你采用的是什么
上下文过长了 你怎么办 压缩 怎么压缩 如果有之前的关键信息压缩掉了怎么办
记忆 上下文 怎么判断上下文长度 是看字节呢 还是看token呢 字节数是判断不准确的
2. 知识库
你切片怎么切的 用的什么工具 切片有几种方案 你用的什么方案 你说按固定长度切按语义切 有什么区别 如果说 有的切得长有的切得短 会怎么样 怎么解决
你写了你这个知识库检索率多少多少 怎么得出来的
3. agent项目
然后你这个智能体 用的什么模型 有没有设置切换模型、调整思考深度的功能，使用模型默认参数
4. function call
然后问你 function call 是什么
问你 skill 用过哪些 官方的别人的 和你自己做的 skill 包含哪些东西 skill 的结构 skill应该怎么去用

项目实操
你这个项目基本都是ai开发的对吧 那你自己在项目中参与度最高的部分是什么 你参与了什么东西
这就是你真的实操一个项目的重要性了 你扯了你的项目 明确输入输出 mvp什么的
你最近一次学习陌生东西 不管是语言还是框架还是业务 你是怎么学习的 借助ai具体怎么交互 然后没有ai的时候你是怎么学习的 你上学除了学校的课程 你还学习了别的没有 你就说你学习怎么做项目啊 说你实习啊
