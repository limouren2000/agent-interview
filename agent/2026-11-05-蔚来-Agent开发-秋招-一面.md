# 蔚来 agent一面 10.26

> 蔚来 · Agent开发 · 秋招一面 · 面试时间 10 月 26 日 · 发帖 2026-11-05 11:27 · 作者 27测绘少年不会梦到offer学姐 · 来源：[牛客](https://www.nowcoder.com/feed/main/detail/7cb3b6f122474ea9b860f923a1bd8c0e)

## 速览

- **重点**：评测、实习深挖、项目深挖。
- **难度**：中等。
- **题量**：21 道左右。

## 面经正文

1. 请做自我介绍。
2. 你有三段主要实习经历，对吗？
3. 研究生导师是否要求你在实验室工作？实习机会是自己找的吗？
4. 寒暑假实习期间，实验室工作如何安排？导师的要求是否有所调整？

5. 这个性能优化具体怎么做？效果怎么评估？
6. 为什么让调用方管理内存池或提供 Buffer？如果用户把容量需求配置给框架，由框架维护，是否也可行？
7. 除了框架不了解业务的 Buffer 大小，还有哪些理由支持当前方案？
8. 调用方提供的内存如果被提前释放或复用，框架如何避免继续写入、产生错误？
9. 你所说的“兼容性”具体指什么？新能力要求客户端适配，与旧客户端无感升级之间如何取舍？
10. 这个项目是你独立负责，还是与同事共同设计和决策？
11. GC 压力具体体现在哪些指标或现象上？
12. 简历中的“跨层生命周期管理”是什么意思？
13. “容量不足时回退”是什么意思？是否会继续走原有分配路径？
14. Buffer 管理、减少拷贝等机制分别带来多少收益？有没有单独测试各项贡献？哪一项作用最大？

15. 改动量较大的 PR，代码主要是手写还是 AI 辅助完成？
16. 面对大量 AI 辅助生成的代码，怎样做 code review？
17. Review 之后，怎样保证代码长期可维护、质量不下降？
18. API 命名、README、兼容性等要求，是人工检查，还是写进 prompt、规则文件和开发流程？
19. 你的 AI 开发流程是否包含多轮“生成—Review—修改”，或不同模型之间的交叉 Review？
20. AI 辅助开发时，测试如何保障？
21. 是否从创建项目、设计功能时，就规定可测试性和每个功能需要配套的测试？
