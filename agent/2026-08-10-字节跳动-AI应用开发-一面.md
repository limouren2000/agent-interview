## 速览

- **重点**：多 Agent、RAG、记忆与上下文、Agent 规划、项目深挖。

## 面经正文

面试时间：8月6号
面试岗位：AI应用开发
整体面试体验还挺好的，面试官沟通比较平等，没有特别强的压迫感，前面主要是了解个人经历和项目，后面会根据项目细节不断追问

### 面试问题

1.自我介绍
2.为什么选择 AI 应用开发方向？
3.项目相关介绍
4.平时如何学习大模型及 Agent 领域的前沿技术？日常使用哪些 AI 编程工具？
5.你如何理解 Agent 系统？可以拆解一下 Agent 的核心模块吗？
6.Tool 的设计原则是什么？哪些能力适合抽象成 Tool？如何设计 Tool 的参数 Schema 和错误码？
7.Memory 有哪些类型？分别如何实现？短期记忆和长期记忆在工程中如何进行存储、过期管理和去重？
8.ReAct 和 Plan-Execute 架构分别适用于哪些场景？如何避免 Agent 出现无限循环或者多个 Agent 之间互相推诿任务？
9.多 Agent 协作系统如何设计？Agent 之间的通信机制和状态共享如何实现？
10.请完整介绍一下 RAG 的整体流程。
11.Chunk 的切分大小如何确定？重叠度如何设置？是否尝试过不同参数，并进行过效果对比？
12.当向量召回结果不准确时，通常优先排查哪些问题？有没有尝试过关键词检索 + 语义检索的混合检索方案？
13.Rerank 通常如何实现？排序过程中的特征权重如何进行分配？
14.RAG 和微调应该如何选择？在实际工程项目中如何组合使用？
15.如何优化 RAG 系统，降低整体延迟以及 LLM 调用成本？
16.在项目中遇到过最大的 Bad Case 是什么？如何定位问题，并解决大模型幻觉问题？
17.大模型调用出现超时或异常时如何处理？Agent 系统的稳定性、监控和可观测性如何建设？

准备方向还是要更加贴近实际项目，之前准备的时候会刷一些八股和概念，但现在面起来感觉很多问题都是结合经历展开的
