# 小厂AI应用开发面试

> 小厂 · AI应用开发 · 发帖 2026-11-07 10:23 · 作者 不失业 · 来源：[牛客](https://www.nowcoder.com/feed/main/detail/c9dd06bab88247348a5c42fd89646f3b)

## 速览

- **重点**：RAG、记忆与上下文、工具调用 / MCP / Skill、Agent 规划、评测。
- **难度**：中等。
- **题量**：26 道左右。

## 面经正文

### 一、技术问题

1. 在 RAG 项目中，你们如何排查和缓解大模型的幻觉问题？
2. 当 RAG 系统的上下文过长时，你会如何进行压缩？
3. 假设 Agent 调用了一个会修改文件的工具，工具执行完成后、结果尚未持久化时进程被终止。恢复后，如何判断工具是否已经执行，并避免重复执行？
4. 你们的 Checkpoint（检查点）是如何存储的？
5. 保存对话状态时，你们存储的是完整对话内容，还是指向原始内容的引用或指针？
6. 你提到的三级上下文压缩，分别在什么条件下触发？
7. 如果上下文压缩边界落在工具调用与返回结果之间，或者工具仍在执行，你会如何处理？
8. 请介绍知识库系统的完整链路，包括离线构建和在线查询两个阶段。
9. 如果准备入库的文档中包含提示词注入内容，你会如何处理？
10. 你提到在 306 条攻击任务上实现了 0% 的攻击成功率，这个指标是如何定义和评测的？
11. 你是否统计过正常任务的通过率和误拒率？分别是多少？
12. 你们如何实现检索结果的重排序（Rerank）？
13. 你平时是否使用 GitHub？项目是否已经上传？
14. 你最近关注过哪些能够辅助 AI 编程或 Vibe Coding 的开源项目？它们如何帮助你的开发工作？
15. 你平时主要使用哪些 AI 编程工具？
16. 你如何利用AI来拆解需求

### 二、非技术问题

1. 你目前居住在哪里？
2. 你目前是否已经毕业？预计什么时候毕业？
3. 你上一段实习是否从六月份开始？
4. 你上一段实习结束的具体原因是什么？
5. 你上一段实习的薪资是多少？
6. 你在上一段实习中主要负责哪些工作？
7. 你平时有哪些兴趣爱好？
8. 你是否制定过个人职业规划？未来半年到一年希望达到什么目标？
9. 你希望加入什么类型的公司，从事什么方向的开发工作？
10. 你期望的公司类型与我们公司的业务存在一定差异，为什么仍然选择应聘我们公司？
