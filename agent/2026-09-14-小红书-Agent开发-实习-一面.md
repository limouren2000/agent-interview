### 一、端侧 RAG / 函数 token 项目

具体 system prompt 有多长？里面包含哪些场景类型？单轮工具调用大概涉及多少条工具选择？
你提到“模型底子不足影响参数填充准确率”，具体卡在参数传递、上下文推导还是数值记忆？目前是谁在测、怎么测的？
用户体感上有什么影响？有没有真实用户数据，还是只用线程数模拟不同手机性能？

schema 是怎么设计的？是否包含名称、描述、参数定义、类型、枚举值、使用示例？参数约束为什么偏宽松？

Agent 任务规划是怎么做的？生产场景是不是先识别意图，再推导工具依赖？函数执行报错后如何多步推理和重新规划？主流模式了解吗？
你说的 “IG” 具体指什么？应用场景是什么？
检索为什么用父子索引？父块 1024、子块 256 的设计逻辑是什么？

TOP K 截断依据是什么？相关性分数和上下文长度怎么权衡？低分文档怎么处理？
