# 阿里淘天agent开发 日常实习 一面

## 速览

- **重点**：多 Agent、记忆与上下文、工具调用 / MCP / Skill、Agent 规划、后端基础。
- **难度**：中等。
- **题量**：16 道左右。

## 面经正文

继续来分享下最近的面经~欢迎友好讨论，信息共享
1.实习拷打
2.你们这个对抗式状态机是什么？
3．你认为状态机和流式的workflow的区别是什么？分别什么时候用？
4.你们这个工作流是解决什么问题的？用户是谁？
5. 那你们这个工作流延迟是不是很高啊？怎么解决的？
6.你写的减少token消耗，体现在哪里？
7. 你在华为还做了什么，mcp和skil做出来主要是怎么使用的？
拷打自己的agent项目
1.你这个组件可插拔是什么意思？
2. 你的多个Agent之间的是怎么处理输入的？你用的这种动态上下文具体是什么数据结构？
3. mcp和skill的区别是什么？
4.你的工程中是如何处理上下文的？
5.你的RAG工程中是如何处理分块的？
6.你的react范式是怎么做的？这种React和COT的区别是什么？你认为二者分别是在什么情况下使用。
7. 你认为多agent和单agent各自适应的场景是什么？
8. 有没有用过langchain，你认为它的优点是什么？
9.你了解过prompt 工程，context工程，harness工程，他们的区别是什么？
Ai coding
写一个高并发分发优惠券的系统，要求对不同人群进行分类，配有不同的优惠券分发方案，要求模块采用继承架构设计，要求考虑边界条件，最终要求一个完整的系统，有main函数做一个demo展示系统功能。并且含有完整的边界约束测试。最后要有使用说明Readme文档。
