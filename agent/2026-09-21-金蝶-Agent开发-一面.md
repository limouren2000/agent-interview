# 金蝶 Agent开发 一面

## 速览

- **重点**：实习深挖、项目深挖。
- **难度**：中等。
- **题量**：6 道左右。

## 面经正文

9.21
1.自我介绍：这个排名是百分之多少？这些竞赛比赛是你主导的吗？比赛是偏硬件还是偏软件的？

2.实习：为什么选这家公司？这个做的是个什么？有用到AI吗？

3.项目一：简单介绍一下项目？这个项目是学习的吗？你们团队几个人？说一下你的这个工作具体是什么？切分策略是怎么设计的？详细说说这个引用溯源到页面高亮具体怎么实现的吗？

4.项目二：简单介绍一下项目？说一下这个Agent怎么设计的？为什么用LangGraph而不是用LangChain？这里有哪些工具？

5.反问

没有问技术更多是问项目，就问了20分钟不知道有没有后续了，等结果吧。
