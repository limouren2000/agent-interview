## 速览

- **重点**：ReAct / Plan 模式与缓存、记忆冲突、代码库 RAG、Spring Bean 与动态代理、Kafka 幂等、MySQL 隔离级别与幻读。
- **难度**：约 40 分钟，隔天挂。
- **题量**：24 问。

## 面经正文

9.9 面的 40min 隔天挂
1.自我介绍
2.你刚刚提到 agent 有 react 和 plan 模式，大模型是怎么判断要用哪种模式的？
3.不同的模式，对于执行效果或者 token 消耗来说有什么影响吗？
4.那你知道 agent 缓存吗，对这个有什么影响呢？
5.那不同的模式的提示词具体是什么样的？
6.你的上下文和记忆模块具体是怎么设计的？
7.如果遇到对话中用户的前后内容冲突怎么办？
8.有了解过其他 agent 的记忆设计模式吗？
9.你这个代码库 RAG 功能的意义是什么？别的 agent 一般是怎么查找代码的？
10.代码 RAG 的话，每次修改或新增代码都得重新向量化吗？这在对话中会不会引发什么问题？
11.为什么没有实习？
12.讲一个最能体现你 Java 工程能力的项目
13.这个项目里面用到 Springboot，具体体现在什么地方？
14.Spring Bean的机制你了解吗？
15.那 Spring Bean 是怎么进行动态注入的？
16.有哪两种动态代理方式？有什么区别？有什么限制？
17.kafka 这一块，你如何保证一个消息不会被重复消费呢？例如对于一个超大文件的切分，一个已经切分过的块在 kafka 断线重连后还会被再次切分吗？
18.你这个项目中用的是Spring MVC 架构，体现在什么地方。
19.那你认为这种架构有什么优势呢？
20.对于 MySQL 有了解吗？
21.你提到的事务，有哪几种隔离级别，分别解决了什么问题？
22.读已提交为什么会出现不可重复读？
23.读已提交是怎么解决幻读问题的？在什么情况下会出现幻读？
24.了解 SQL 的调优和慢 SQL 的优化吗？
