# 字节agent开发面经

> 字节跳动 · AI Agent后端开发 · 实习一面 · 结果：二面挂 · 发帖 2026-10-11 · 作者 Ljleo · 来源：[小红书](https://www.xiaohongshu.com/explore/6acb1d8f0000000002029388)

## 速览

- **重点**：多 Agent 架构与冗余、任务冲突与依赖数据结构、失败重试与数据闭环、MySQL 表设计、TCP / HTTPS / 中间人攻击、手撕三数之和。
- **难度**：一面总的来说不难，层层递进追问到支支吾吾为止；作者评论称二面挂了。
- **题量**：项目深挖四类追问，另有计算机基础和三数之和手撕。

## 面经正文

🎯 流程
自我介绍

🔍 项目深挖
• 架构拷问：项目多少人？核心架构是你主导的吗？为什么做成多级/多 Agent，而不是更简单的方案？怎么证明不冗余？
• 细节拷问：核心模块的输入输出是什么？任务冲突怎么决策？依赖关系具体用什么数据结构表示？能不能覆盖复杂依赖？
• 容错拷问：失败后局部重试还是全局重规划？判断标准是什么？会不会死循环？上层一开始分错了怎么发现？
• 效果拷问：数据闭环怎么做的？性能提升体现在哪？为什么不多开几个？

面试官风格我觉得以下特点：
1. 层层递进追问，答虚了能看出来
2. 爱问“为什么不用更简单的方案”
3. 要求讲到数据结构级别的具体
4. 专攻失败场景和边界情况

三、个人背景与计算机基础
专业
计算机基础方面有了解吗？
了解 MySQL 的索引吗？
假设要把测评数据闭环的数据落到一张表里，这张表的字段、主键、索引分别怎么设计、为什么这样设计
计算机网络里 TCP 的三次握手、hppts、中间人攻击

四、手撕
三数之和

字节一面二面流程都很工整，就是这四个part，项目会连续问，问到答得支支吾吾为止哈哈哈。
一面总的来说不难，可能是组里新人面的
