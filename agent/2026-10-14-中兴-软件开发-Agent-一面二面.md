# 中兴软件开发面经（已被调剂）

> 中兴 · 软件开发-Agent · 一面二面 · 结果：调剂回软开 · 发帖 2026-10-14 · 作者 VENI VIDI VICI · 来源：[小红书](https://www.xiaohongshu.com/explore/6acf7fef000000000a026a88)

## 速览

- **重点**：一面问学习情况、项目分工，按简历追问技术八股，并问 Agent 八股、场景题和 Python 八股。二面把业界方案（Anthropic）和实习经历对比，问项目改进、对 jv 的看法，以及平时用的 coding Agent，后半段是成绩、规划、Base 地和薪资等综合问题。
- **难度**：中兴软件开发 / Agent 一面、二面。一面超过 1 小时，二面约 50 分钟，招聘类型未注明。作者称投递地没有 HC，先被换成 IC 开发工程师，后又调剂回软开，阶段变回投递成功。
- **题量**：一面约 9 问加反问，二面约 15 问加反问。一面的具体八股题面未列出。

## 面经正文

一面：1v2
面试官挺礼貌的，语气也很平和。

1. 自我介绍
2. 学习情况：学制、学了什么专业课、论文
3. 项目及分工
4. 简历里写的一些技术的八股（感觉这部分是一直追问到不会为止）
5. 个人博客里的一些东西
6. 意向 Base 地、家庭住址
7. Agent 八股、场景题、Python 八股
8. 怎么获取一些新的技术进展
9. 反问
时长：1h+

---

过了 2 天约二面
（是两位面试官交替问的，所以是技术和个人问题穿插）

二面：1v2，综合面
看起来是 1 技术 1 HR，不过 HR 那位好像也挺懂技术的，同样是比较温和有礼的面试官。

1. 自我介绍
2. 业界方案（Anthropic）和实习经历的对比
3. 当前项目用户反馈，有什么改进的思路
4. 问了一下前些日子出来的 jv，看法
5. 奖学金、学习成绩、读研的考虑和规划、读研期间的收获
6. 对行业未来的看法
7. 平时用什么 coding Agent、模型
8. 未来的职业规划
9. 个人的优缺点，怎么弥补
10. 和同伴的关系、人际交往等等
11. Base 地
12. 有无其他 offer
13. 家里对于工作地点的看法
14. 期望薪资，有无 npy
15. 反问
时长：50+min

---

这个岗位我投的 Base 地和我家乡都没 hc 了，结果 HR 直接给我换成 IC 开发工程师了。后来我说接受其他 Base 地，现在又给我调剂回软开了，但是阶段变成（1. 投递成功）了，心已死了反正(◞‸◟)
