# 11.6 阿里云 Agent 平台 二面 沙箱和安全被追了半小时

> 阿里云 · Agent平台 · 二面 · 面试时间 2026-11-06 · 发帖 2026-11-09 · 作者 周也在coding · 来源：[小红书](https://www.xiaohongshu.com/explore/6af141a2000000003602ff79)

## 速览

- **重点**：自研 Agent 运行时与 LangGraph 的边界、沙箱环境（Docker / Wasm、冷启动、预热、网络与清理）、工具权限与提示注入、流式 tool_call 拼装、多租户调度手撕。
- **难度**：高，全程没开摄像头且有回声，语速快，沙箱和安全被追了半小时，四十分钟只把两个点讲完整。
- **题量**：26 道，含多租户任务调度手撕及追问。

## 面经正文

全程没开摄像头 声音是从会议室免提里漏出来的 有回声 他语速快 我一句话还没讲完下一个问题就上来了 四十分钟我大概只把两个点讲完整🥵

1. 你们这套 Agent 运行时为什么自己写 不用 LangGraph 说清楚边界在哪
2. 一个普通服务框架加上循环调用 跟你的运行时差在哪
3. 代码执行这个工具 你跑在什么环境里
4. 为什么选 Docker 不选 Wasm 你这个判断依据是什么
5. 沙箱冷启动多久 这个数你能接受吗
6. 用户等三秒才看到第一行字 你会从哪几个地方抠时间
7. 沙箱池子怎么预热 池子多大 按什么指标定这个数
8. 沙箱里要联网装依赖吗 网络怎么放出去
9. 有人写了死循环 你怎么发现 多久杀掉
10. 沙箱跑完 磁盘上留的文件谁清 你怎么保证清干净
11. 你的工具是有权限分级的吧 分几级 这个级别是谁定❌
12. 风险等级是模型自己标的 还是服务端算的
13. 如果是模型标的 它被提示注入以后把删库标成只读 你怎么防
14. 审批通过了 参数被人换掉 你靠什么发现
15. 换了参数重新发一次请求 这条链路从哪里拦得住
16. 审批记录里存了哪些字段 为什么是这几个
17. 工具从二十个涨到八百个 你怎么让模型选对
18. 先检索再给 schema 那检索没召回到正确工具 你怎么兜
19. 工具描述谁维护 改一版怎么保证线上不下线
20. 流式返回里 tool_call 的 arguments 是分片来的 你怎么拼
21. 拼到一半 JSON 不合法 你直接报错还是等下一片
22. 一个租户的沙箱会不会被另一个租户复用 残留怎么处理
23. 计费按 token 还是按沙箱时长 两边都算怎么对账
24. 手撕 写个多租户任务调度 每个租户最多 N 个并发 租户之间轮转
25. 某个租户一直占着 多久把它挤下去 挤下去的任务状态怎么记
26. 队列满了新任务进来 拒绝还是排队 你选哪个

二面没有自我介绍 上来就问我上一家那套运行时是谁设计的 我说完他就开始拆
