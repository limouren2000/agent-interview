- **重点**：RAG、记忆与上下文、工具调用 / MCP / Skill、Agent 规划、评测。

## 面经正文

7.6面试的，做B端的小公司，虽然公司人少，但是面试官很专业啊，问的问题也让我学到了很多👍
1. 先整体介绍一下你的本地 Coding Agent 项目，从输入任务到最终修改代码，中间完整链路是怎样的？
2. 你的 Agent 支持不同模型后端吗？如果接入多个模型服务，你会怎么抽象请求格式、响应结构、错误码和重试逻辑？
3. 你项目里的工具系统是怎么做的？比如一个新工具从定义、注册、被 Agent 发现，到最后被调用，完整流程是什么？
4. 如果工具调用失败，比如文件不存在、命令超时、权限不够，你的 Agent 是直接报错，还是会做恢复和重试？
5. 你提到做了多轮任务中的上下文治理，可以举一个真实场景吗？比如代码改到一半上下文越来越长，你是怎么处理的？
6. 上下文压缩之后，你怎么判断压缩没有破坏当前任务？有没有什么校验标准？
7. 任务摘要、文件摘要、过程笔记这些压缩产物，你是怎么生成和维护的？如何避免关键信息被压掉？
8. 如果压缩后的摘要里遗漏了关键约束，导致后续 Agent 做错了，你会怎么发现并修正？
9. 如果长期记忆里保存了过时的文件摘要，后面 Agent 又拿它做判断，这种污染怎么处理？
10. 如果模型把错误结论写进了记忆，比如误判某个函数作用，后续任务一直沿用这个错误，你怎么做纠错？
11. 多轮执行中，Agent 可能反复读同一个文件或重复调用同一个工具。你是怎么识别重复状态的？
12. 你怎么看 RAG、Memory 和 Context Engineering？这三者分别解决什么问题？在你的 Coding Agent 里是怎么配合的？
13. 你对 Agent Harness 怎么理解？它和单纯调用 LLM API 的区别是什么？
14. 你的 Agent 有没有评测体系？你怎么设计 benchmark、case、指标？怎么判断一次改动真的让 Agent 变强了？
15. 如果 Agent 在执行代码修改时生成了错误 patch，你怎么做回滚、验证和再尝试？
16. 你平时用什么 AI ？一个需求给到你，你通常怎么用 AI 辅助完成开发？
17 你在使用AI的过程中，会怎么拆需求、读代码、让模型改代码、跑测试和review 结果？
18. 如果让你把这个本地 Coding Agent 做成团队内部工具，你会怎么处理权限、安全和审计？比如文件读写、命令执行、敏感信息泄露。
19. 如果 Agent 需要在一个大型代码仓库里完成跨模块修改，你怎么让它先理解架构，而不是一上来就乱改？你会设计哪些检索、规划和验证步骤？
问的真的很深，事后复盘我让AI以面试官的视角，输出了一些回答思考，也在这里记录一下吧
