# 小红书AI应用开发面经

> 小红书 · AI应用开发 · 校招 · 结果：挂 · 发帖 2026-09-21 · 作者 多吃碳水啵 · 来源：[小红书](https://www.xiaohongshu.com/explore/6ab0c2670000000036029603)

## 速览

- **重点**：Skill、ReAct 与 Plan-Execute、记忆、Claude Code 架构、进程线程协程与 Python 内存、RAG 切片与知识库更新、两数之和追问、retry 装饰器与工具调用失败。
- **难度**：30 分钟，氛围很好；两数之和有多轮追问，retry 写了一半，作者评论称挂了。
- **题量**：八股 8 题，手撕 2 道（含多问追问）。

## 面经正文

整个面试30min，面试官很年轻，进来先做了个自我介绍并且说了一下面试流程，才让我自我介绍，后续面试过程氛围也比较好，先问了问实习和项目的难点以及所做的工作，然后问了一些八股，最后有两道手撕。

八股部分：

1、对skill的作用和理解

2、react和plan-execute的区别以及使用场景

3、记忆机制的理解

4、claude code架构讲一下

5、进程、线程、协程的区别，python里为啥多线程处理cpu密集型任务效果不好，如果都是IO密集型，python里异步和多线程用哪个。
6、python和C++里的内存管理机制和垃圾回收（这个完全没了解过，没答上来）

7、rag切片策略，追问场景题：文档不断更新，知识库怎么维护，如何在海量chunk里找过期、冲突、错误的chunk进行更新。

8、工具调用有哪些方法

手撕：

1、两数之和（是的，真的是两数之和）。一分钟写完之后，追问：1）全部都是正数怎么减少复杂度 2）如果要给出所有可能的组合，在数组有重复数字和没有重复数字两种情况下，分别怎么做3）如果提供更大的空间，有没有办法用更多的空间换时间 4）完全不遍历能不能解决（这个感觉是坑，面试官问我的时候笑了。我想了一会，面试官笑的更开心了，问我是不是没有，我才恍然大悟）

2、实现一个retry（fn，max_times=3）函数，对一个函数重试3次。若成功则返回结果，最大重试次数失败抛异常。（之前被问过装饰器，刚好复习了一下，写了一半还是没撕出来，给面试官讲了一下，本质上就是实现一个装饰器，然后大致讲了一下怎么写）。

追问：agent开发中，这个重试应该你比较熟悉，那实际中怎么处理工具调用失败，有哪几种情况，分别怎么处理。

总结：氛围非常好的一次面试，感觉到了面试官对待候选人的态度是平等交流互相尊重的，虽然有一两道题自我感觉答的不好，但总体面完还是挺爽的
