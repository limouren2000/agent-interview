## 面经正文

以下为已核到 5 组主问题的内容整理，只保留问题含义，不是逐字原文。

第一组：自我介绍，并讲清真正负责的 Agent 项目。追问为什么要用 Agent 而不是固定 Workflow；如何限制模型越界；项目采用了什么机制；实际数据或问题是什么。

第二组：Agent 与普通 LLM 聊天产品有何区别、由哪些部分组成。追问计划步骤里哪些由模型决定，哪些应当固定。

第三组：RAG 的离线链路和在线链路；召回效果如何测量和改善；重排之后延迟会如何变化，以及效果与延迟如何权衡。

第四组：上下文压缩时哪些信息可以删，哪些必须保留；工具调用与返回结果不能拆开。

第五组：模型如何选择工具并生成参数；工具数量增多时如何筛选；一次提供多少工具。

第六组：封面称还有一组主问题，但正文和已加载的四张图中未见，这里留空，不补写。
