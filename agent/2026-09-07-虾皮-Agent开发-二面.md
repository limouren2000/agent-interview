## 速览

- **重点**：时序知识图谱与 RAG / Agentic-RAG、System Prompt 与 AGENTS.md、上下文溢出、Skill 优化、实现带 Schema 校验和防重复调用的 Agent 循环。
- **难度**：中等，面试官迟到且反馈很少，作者称体验不好。
- **题量**：17 问，另有 run_agent 代码题。

8.项目底层是否通过 RAG 实现？
9.如何判断 RAG 的召回质量？
10.传统 RAG 的方式本身是否存在不足？还有哪些优化空间？
11.你了解 Agentic-RAG 吗？
12.System Prompt 和 AGENTS.md 的差异是什么？
13.多轮对话导致上下文窗口溢出时，大模型通常会采取哪些处理方式？
14.一个好的 Skill 应具备哪些特点？应从哪些方面衡量？
15.如果接手团队中一个函数多、功能复杂，包含 A、B 等多个功能的 Skill，需要对其进行优化，你会如何处理？
16.你会使用 Python 吗？
17.代码题：请实现 run_agent(question, tools, max_steps=10) 的内部 Agent 循环，模型调用可直接使用 llm.chat()。该函数需要支持工具调用参数的 JSON Schema 校验，需要限制最大循环轮数；工具调用或执行发生异常时，不应直接抛出异常，而应将错误信息作为observation 返回给大模型，以便其继续决策和调用工具；同一工具以相同参数连续调用达到 3 次及以上时，应终止循环，避免陷入重复调用。
18.你在全栈开发方面做过哪些事情或准备？你为提升全栈开发能力做了哪些学习和实践？
