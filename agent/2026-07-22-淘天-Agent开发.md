## 速览

- **重点**：记忆与上下文、后端基础、项目深挖。
- **难度**：中等。
- **题量**：10 道左右。

## 面经正文

面了淘天AI Agent岗位，知识层有RAG、记忆架构、算法等...面试官也不错，看的是你的技术落地  整体体验下来感觉不错，架构设计、技术决策是重点。HR环节正常，真诚交流即可。岗位务实，注重高并发电商场景下的AI工程化，就是有点难

### 面试问题

1.自我介绍
2.在淘天高并发、高可用的电商场景下，将一个实验性质的 Agent Demo 改造
为能支撑 “双十一” 级别流量的生产系统最大的架构挑战是什么?你会如何应对?
3.技术选型探讨:在构建 Agent 的编框架时，你会选择 LangChainLlamalndex这类开源框架，还是选择自研?请对比利弊并阐述你的理由。
4.如何控制 Agent 的 “自主性”边界?例如在明确的退换货规则场景下，是让Agent 严格遵循规则引擎，还是允许其有一定自主推理空间?如何设计安全护栏(Safety Guardrail )?
5.Agent可能产生“幻觉”(Hallucination)或生成不合规内容。在工程层面，有哪些机制可以在生成前后进行控制和拦截?
6.如果业务方希望为 Agent 增加 “通过商品图片找同款”的多模态能力，你的后端架构需要进行哪些改造和扩充?
7.你如何保持自己的技术敏锐度并学习一项新技术(例如一年前出现的某个新Agent 框架)?请描述你完整的学习路径和方法。
8.当你和团队成员在技术方案上产生严重分歧时(例如选用 A数据库还是 B 数据库)，你会如何处理以推动项目前进?
9.你如何看待 Al Native 应用与传统软件工程在开发模式、团队协作上的差异?一个优秀的 AI应用研发工程师应该具备哪些独
特的素质?
10.你最近读过的一本技术书籍是什么?它给你带来的最大启发或思考是什么?
