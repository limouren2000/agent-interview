# 天津小厂agent开发日常实习面经

> 天津小厂 · Agent开发 · 日常实习 · 结果：通过 · 面试时间 2026-09-01 · 发帖 2026-09-01 · 作者 失去 · 来源：[小红书](https://www.xiaohongshu.com/explore/6a96d66c000000002603b130)

## 速览

- **重点**：上下文管理、无关内容如何压缩，以及长期记忆与最新指令冲突、如何自动判断该不该写入长期记忆。Skill 的渐进式加载和选择调用；代码知识库怎么切分，长方法怎么处理。RAG 检索链路，BM25 和 Embedding 配合，以及逻辑相关但语义不相似时怎么检索。还问了 Redis 和分布式锁。
- **难度**：天津小厂 Agent 开发日常实习，约半小时，已通过。作者称有好几个点被问穿，HR 当即通知过了。
- **题量**：22 问，后两问为毕业和实习时长。

## 面经正文

1. 你的上下文管理机制是怎么做的？
2. 你怎么判断哪些对话是“无关内容”、可以被压缩？
3. 能不能结合具体场景说明，哪些内容保留、哪些内容压缩？
4. 长期记忆和用户最新指令冲突时，怎么处理？
5. 用户一句话怎么判断是临时需求，还是应该写入长期记忆？
6. 普通用户不会主动声明“存长期记忆”，系统具体怎么自动判断？
7. 你的 Skill 是怎么渐进式加载的？
8. 只加载 Skill description 后，怎么判断该加载哪个 Skill？
9. Skill 底层具体是怎么选择和调用的？
10. 有没有使用 LangGraph 之类的框架？
11. 你的代码知识库是怎么切分的？
12. 如果一个方法特别长，还按整个 Method 切吗？
13. 长方法继续切以后，和原来“按方法维度保存”怎么协调？
14. 你的 RAG 检索链路是怎么做的？
15. BM25 和 Embedding 是怎么配合的？
16. 用户搜“数据权限”，但代码里只有 `RBAC`，怎么检索到？
17. 如果两个概念不是语义相似，只是逻辑相关，向量检索怎么办？
18. 比如“维 C”和“水果”这种关系，怎么检索？
19. Redis 在项目里具体用了什么？
20. Redis 分布式锁 / 全局锁怎么实现？
21. 你什么时候毕业？
22. 你能实习多久？
整体面试半小时，有好几个点被问穿了，不过面试完hr当即通知过了,可能是因为学校原因或者缺人吧，感觉答的一般，被拷打晕了
