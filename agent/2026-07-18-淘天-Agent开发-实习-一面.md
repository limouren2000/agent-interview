# 阿里淘天agent开发一面面经（50分钟）

> 淘天 · Agent开发 · 实习一面 · 发帖 2026-07-18 03:06 · 作者 搬砖界泰斗 · 来源：[牛客](https://www.nowcoder.com/feed/main/detail/b5000060cf85482097b87621f8cbaccd)

## 速览

- **重点**：工具调用 / MCP / Skill、Agent 规划、实习深挖、项目深挖。
- **难度**：中等。
- **题量**：10 道左右。

## 面经正文

前30分钟闲聊，后20分钟问项目，全程无八股
1.自我介绍
2.聊创业经历，打工与财富自由
3.讨论美股，币圈，以及我的交易策略，收益和对冲的体现在哪
4.未来职业规划是什么
5.简历里agent项目为什么要用Multi agent，单agent不可以吗
6.这个项目你认为的技术亮点在哪——skill热插拔
7.描述skill热插拨的流程
8.为什么用进程池+RPC+注册中心实现热插拔
9.面试官提出oss实现热插拔（具体咋实现忘了），问我这样可不可以（就回了也可以）
10.session里的临时文件存主服务还是skill进程服务，要不要删，删什么时候删
11 .反问环节，问这个实习岗是干啥的

总体感觉项目挖的不深，技术，项目细节拷打不如字节，三个项目就问了一个，大部分时间都在聊非技术相关内容
