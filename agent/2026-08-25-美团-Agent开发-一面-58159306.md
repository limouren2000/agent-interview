# 美团Agent开发一面 日常

> 美团 · Agent开发 · 一面 · 发帖 2026-08-25 20:18 · 作者 阿顺在coding · 来源：[牛客](https://www.nowcoder.com/feed/main/detail/58159306df52463ab75d72daa80d66df)

## 速览

- **重点**：多 Agent、RAG、记忆与上下文、手撕算法、Agent 规划。
- **难度**：中等。
- **题量**：23 道左右。

## 面经正文

1.自我介绍
2.你当时为什么会想到做这个智能运维 Agent 项目？
3.简单描述一下你是怎样构思这个系统运转流程的，以及中间技术或中间件选型的依据是什么。
4.为什么使用 RAG？现在模型的上下文窗口已经很大，为什么不直接把原始文档都交给 Agent，让它自己查询？这两种方式有什么区别？
5.如果有十篇甚至更多文档，或者让 AI 阅读信息量更大的代码仓库，比较“用 RAG”与“把文件交给 Agent、让它通过 grep 等操作自行检索”，在不考虑 token 消耗时，两者各有什么优劣？
5.从原始文档到最终检索、合成答案，RAG 中间有切块、索引、存储、检索、排序等很多步骤。哪些步骤对你构成了挑战，并会影响最终效果？
6.如果你的 Markdown 文件没有标题，要怎么切分？
7.混合、多路检索中，关键词检索有什么优缺点？向量检索又有什么缺点？
8.chunk 可能有一两百字，但 query 可能只有三到五个字，怎样把短 query 与长 chunk 向量化后比较？你有没有对比过长 query 和两三个字的短 query 在向量召回上的差异？
9.除了压缩以外，对长 query 还会做什么处理？
10.你怎样确认 RAG 的产出有没有出现幻觉？
11.测评只能说明有较高概率答对，人和 AI 都做不到百分之百正确。对于剩余 1% 或 2% 的错误，怎样识别？有没有考虑给模型的最终产出增加检测机制？
12.你平时会用 AI 写代码吗？你怎样判断 AI 写的代码对不对？
13.一个 Agent 和多个 Agent 协作完成同一件事，你以前实际使用过多 Agent 的协作方式吗？
14.你提到使用 Plan-and-Execute；它和 ReAct 相比，你的选择依据是什么？
15.你觉得 Agent 和 Harness 分别是什么？二者有什么区别？Harness 做了哪些事情，能让 Agent 更好地执行任务？
16.上下文管理也是 Harness 的职责，比如上下文过长时，哪些内容该送、哪些不该送，哪些该裁剪，以及 System Prompt 中哪些该写。你在项目里是怎么做的？
17.你了解模型的 Prompt Cache 吗？
18.Milvus 和自己手写一套余弦相似度检索相比，有什么区别？
19.Milvus 内部的存储、检索等机制是怎么实现的，你看过吗？
20.如果有三万个协程和三万个线程，在同一颗 8 核 16 线程的 CPU 上运行，它们在调度上有什么区别？
21.你平时用 AI 写代码，对 Vibe Coding 和 Spec Coding 这两个概念有了解吗？
手撕：1.个有序链表合并为升序链表 5min秒，面试官说觉得我不错说来道难的，？？
2.最长有效括号 讲了思路，实在是没写出来
