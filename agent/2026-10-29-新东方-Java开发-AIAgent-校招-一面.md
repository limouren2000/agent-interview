# 新东方Java开发工程师（AI Agent方向）一面

> 新东方 · Java开发-AI Agent · 校招一面 · 发帖 2026-10-29 18:23 · 作者 upc · 来源：[牛客](https://www.nowcoder.com/feed/main/detail/be13a125168546249689fa406527859a)

## 速览

- **重点**：后端基础、实习深挖、项目深挖。
- **难度**：中等。
- **题量**：21 道左右。

## 面经正文

面试时长：50min

1. 自我介绍
2. 毕业年份？接下来是想找实习还是留用？
3. 接下来学校的安排是怎么样的？
4. 你的求职方向是怎么样的？具体想从事的业务方向？为什么？
5. 本科是数学专业为什么选择跨计算机？
6. 那你过去开发出哪些比较满意的产品？
7. 读研为什么又学软件开发？哪些是课上教的哪些是自学的？都包括哪些技术？
8. 选一个最能体现的学习能力的项目讲一下？
9. 你刚刚提到的哪些技术栈，选一个我们深入的聊一下？
10. mysql中你觉得难点在哪？索引重点讲一下？
11. 索引的底层结构是什么？为什么要用B+树索引结构？聚簇索引和非聚簇索引的区别是什么？
12. 主键在设计的时候如果发生重排序会怎么样？
13. 为什么不采用指针存储来规避重排序的性能损耗？重排序时数据拷贝是否会导致变慢？
14. 聚簇索引叶子节点同时存主键和完整数据的好处是什么？为什么不把主键存一个表再存一个指针呢？
15. 非聚簇索引是否支持范围查询？
16. 现在有一个联合索引a，b，c，非聚簇索引存储结构是什么样的？每个节点存的是什么？
17. a = 1，b > 2，c = 3这个查询条件怎么在索引树中查询？
18. springboot的自动装配原理？具体使用过哪些starter？需要在main函数加特定注解吗？
19. Spring Boot自动装配的底层扫描原理？

### 反问

1. 校招生从事业务方向
2. 面试流程与推进周期
