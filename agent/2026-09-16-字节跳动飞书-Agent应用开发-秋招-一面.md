## 速览

- **题量**：算法 1 道、实习 7 问、八股 5 问、SQL 1 道。

## 面经正文

总时长 1h 左右，感觉中间的实习和八股部分还好，字节还是喜欢考计网和操作系统，很多应用层的东西AI都能做，反而更看重底层基础了[扯脸H]

字节跳动
Agent 应用开发工程师一面
1. 算法：求剩余空间最小值（非Hot100），像“最大子数组和”改编
2. 实习拷打
• 实习的 Agent 项目做了哪些工作？
• 项目中的 ReAct 架构如何实现的？
• 主流 Agent 架构有哪些，如何选型选择 ReAct 的？
• ReAct 如何防止死循环调用？
• 你对 ReAct 有何理解，如何防止 Agent 执行任务过程中跑偏？
• Agent 架构中的 Prompt 设计有哪些经验？
• 如何体现 Agent 能力，保证 Agent 制作的内容达到之前人工工作的质量？

3. 八股
• 输入 URL 访问网页的网络过程是怎样的？
• 说明 HTTP 和 HTTPS 及其区别？
• URL 由哪些部分组成？
• 说明堆和栈的区别？
• 访问服务器，除了 IP 地址，还需要获取什么信息？

4. SQL题
• 场景：学生选课系统，学生选课，老师开课
• 约束：一个学生可以选择多门课，一门课会有多个学生来选择，一个老师只能教一门课，一门课可由多个老师来教
